# Mission: 量化交易(Quantitative Trading)

## Why
用户想**亲手构建一套属于自己的量化交易系统**——从数据采集、策略信号、回测,到执行与风控的完整链路。以 Crypto 市场为第一战场(数据开放、门槛低、7×24 运行),最终扩展到传统股票市场与 AI/ML 量化策略。核心驱动力是工程实现能力,而非仅仅理解理论。

## Success looks like
- 能独立搭建一条 Crypto 数据管道:从交易所 API 拉取行情并清洗成可用数据集
- 能用 Python 实现一个交易信号,并在历史数据上做出**诚实的回测**(含手续费、滑点、前视偏差防护)
- 能读懂并评估一个策略的表现指标(收益、回撤、夏普比率),判断它是真信号还是过拟合
- 能把一个策略从回测推进到**纸上交易(paper trading)**,再到小资金实盘
- 逐步扩展:传统股票量化 → 把机器学习正确地用于金融预测

## Constraints
- 技术背景:会编程(需确认主力语言,默认 Python),数学一般(统计/概率需边学边补)
- 工程导向:偏好动手搭系统,而非纯理论推导
- 学习方式:中文讲解;代码与注释用英文;每节课短小、单一目标、可快速完成
- 编辑器 Cursor,终端 zsh

## Out of scope(暂不涉及)
- 高频交易(HFT)/ 做市 / 底层撮合引擎——超出个人系统范畴,后期视兴趣再定
- 期权/衍生品定价的深水区数学——先打好现货与趋势/统计套利基础
- 手动主观交易(discretionary trading)——本使命聚焦"系统化、可回测"的方法
