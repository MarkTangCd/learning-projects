样本外验证配方

让回测数字不再是"事后挑出来的"。配 L6。

前提

一段带时间索引的 price,一个能给 df 加 strat_ret_net 的回测(回测配方),和一套参数网格。

配方:train 上搜、test 上验一次

# ① 按时间顺序切(绝不随机打乱 -> 会数据泄漏)
split = int(len(price) * 0.7)          # 前 70% train,后 30% test

def score(net_returns):                # 从某段自己的净收益重建成绩单
    r = net_returns.dropna()
    eq = (1 + r).cumprod()
    return {"sharpe": sharpe(r), "cagr": cagr(eq), "mdd": max_drawdown(eq)}

# ② 每组参数:整段回测,再切成 train / test 两张成绩单
rows = []
for fast, slow in GRID:
    net = backtest(sma_crossover_signal(price, fast, slow))["strat_ret_net"]
    rows.append((fast, slow, score(net[:split]), score(net[split:])))

# ③ 只用 train 挑冠军;再看它的 test 成绩 = 诚实的未来估计
winner = max(rows, key=lambda x: x[2]["sharpe"])   # 按 train 夏普
tax = winner[2]["sharpe"] - winner[3]["sharpe"]    # 过拟合税(落差)

三条纪律

纪律为什么
① 按时间切,不随机打乱随机会把未来 K 线混进 train = 数据泄漏(前视偏差)
② 调参只在 train 上做样本内表现必然好看,对预测未来无价值
③ test 只碰一次回头看 test 再改策略 = 数据窥探,test 被污染成样本内

读落差

traintest诊断
好崩过拟合 —— 别上实盘
好也稳(略降)可能真信号 —— 可进 paper trading
一般一般诚实但无 edge

永远拿 test 段的买入持有做同款对比。过拟合税 = 样本内 − 样本外,越大水分越多。

升级:滚动前进 walk-forward

单次切分只赌一次 regime 运气。walk-forward 滚很多刀、把每段样本外拼起来,摊平运气。配 L7。

TRAIN_BARS, TEST_BARS = 365, 90   # rolling 1 年调参 / 下 1 季验收

# 每 fold:固定长度 train 窗口前移一个 test 长度,test 段永不重叠
start, oos = 0, []
while start + TRAIN_BARS + TEST_BARS <= len(price):
    tr = slice(start, start + TRAIN_BARS)
    te = slice(start + TRAIN_BARS, start + TRAIN_BARS + TEST_BARS)
    best = max(GRID, key=lambda p: sharpe(nets[p][tr]))  # 只在 train 上挑
    oos.append(nets[best][te])                           # 冠军的未见 test 段
    start += TEST_BARS

oos_curve = pd.concat(oos)          # 拼接成连续样本外曲线 -> 给它打分
读什么怎么判
拼接样本外 vs 买入持有跨牛熊还跑得赢躺平,才算有 edge
参数漂移每 fold 选的参数乱跳 = 没有稳定最优 = 危险信号
别过拟合到 walk-forward 本身 反复调 train/test 长度和网格直到曲线变好看,只是又一层数据窥探。walk-forward 抬高门槛,不消除过拟合。大规模用 vectorbt 自动化。
