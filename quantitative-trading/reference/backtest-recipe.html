向量化回测配方

一份 position 列 → 一条诚实的收益曲线。无循环,纯列运算。配 L4。

前提

一张带时间索引的 df,含 close 列,和一列 position(0/1,已 shift(1) 防前视偏差)。

四步配方

FEE = 0.001   # 单边成本:手续费 + 滑点粗估

# ① 资产每根收益
df["ret"] = df["close"].pct_change()

# ② 策略收益:只在持仓时吃到涨跌
df["strat_ret"] = df["position"] * df["ret"]

# ③ 扣成本:position 变化 = 一次换手
df["trade"] = df["position"].diff().abs()
df["strat_ret_net"] = df["strat_ret"] - df["trade"] * FEE

# ④ 复利成曲线(起点 1.0)+ 基准
df["equity_net"]  = (1 + df["strat_ret_net"].fillna(0)).cumprod()
df["equity_hold"] = (1 + df["ret"].fillna(0)).cumprod()   # 买入持有

读数

total_net  = df["equity_net"].iloc[-1]  - 1     # 策略含成本总收益
total_hold = df["equity_hold"].iloc[-1] - 1     # 及格线
trades     = int(df["trade"].sum())             # 总成交笔数

三条诚实纪律

纪律怎么落实
① 不用未来信息position = signal.shift(1);丢掉未收盘 K 线
② 扣掉交易成本trade × FEE,含手续费 + 滑点
③ 和"躺平"比永远对比 equity_hold(买入持有)

画图(可选)

# pip install matplotlib
df[["equity_net", "equity_hold"]].plot(figsize=(10, 5))
这个配方的简化假设(要心里有数) 按收盘价即时成交、成本固定、无部分成交/无资金约束、无爆仓/保证金。够用来快速筛选策略,但实盘前需用 freqtrade / vectorbt 等引擎做更真实的验证。
