量化术语词汇表

这是全课程的"官方术语表"。每节课的用词都以此为准;学到新词就回来加。

信号 Signal
把行情数据映射为"买/卖/持有 + 目标仓位"的决策逻辑。系统的大脑。见 L1。
策略 Strategy
一套完整的交易规则,通常 = 信号 + 仓位规则 + 进出场条件。口语里常与"信号"混用。
信号族 Signal Family
一类共享核心假设的信号。两大基本族是趋势/动量(赌延续,如 SMA 交叉)和均值回归(赌拉回)——相反的赌注。谁对取决于 regime。同一族里换参数 ≠ 换族;SMA 单族无 edge 时,该换族而非继续调参。见 L12。
均值回归 Mean Reversion
价格围绕某均值摆动、偏离后倾向拉回的假设。规则:异常便宜(z 很负)时买、回到均值时走。震荡市吃香、单边趋势市翻车(逆势接刀)。趋势信号的反面。见 L12。
z-score / 标准化 Z-score / Standardization
把"现价离滚动均值几个标准差"算成一个数:(close − rolling_mean) / rolling_std。把不同价位、不同波动的市场放到同一把尺子上,让"贵/便宜"可比。均值回归信号的度量。
ffill 状态机 ffill State Trick
把"进场后持有到出场"这种有状态规则向量化的套路:只在进/出场那几根标记 1/0、中间留 NaN,再 .ffill() 前向填充("保持上次决策")。无 for 循环表达持仓状态。
市场状态 / Regime Market Regime
市场当前的"性格":趋势市(单边上涨/下跌)vs 震荡市(区间来回)。同一信号在不同 regime 表现天差地别——趋势信号吃趋势市、均值回归吃震荡市。见 L14。
Regime 过滤 Regime Filter / Switching
一个"路由器"信号:先判断当下 regime,再决定开哪个子信号(趋势市→SMA,震荡市→均值回归),让互补的两者各打各的天时。本身不发明下单逻辑,照样吐 position 列。风险:多子信号=大过拟合面,须钉死子信号、只调 regime 旋钮,且样本外必须打赢各零件单飞。见 L14。
Efficiency Ratio 效率比(Kaufman ER)
量化"当前有多像趋势":|净位移| / 总路程(window 根内)。ER→1 单边趋势,ER→0 来回震荡。纯 pandas 可算,regime 过滤最简单的检测器。
奥卡姆剃刀(量化版)Complexity Must Pay Rent
每加一个参数/一层机器,都要在样本外换来可测的提升,否则复杂度就是负债。组合信号打不过它更简单的零件单飞 = 该砍掉。防的是"看起来更聪明"的自我催眠。
回测 Backtest
在历史数据上模拟运行策略,估计它过去本会有的表现。诚实的回测必须计入手续费、滑点,并防前视偏差。
前视偏差 Look-ahead bias
回测中用到了"当时根本拿不到的未来信息"(例如用当天收盘价决定当天开盘的操作)。最隐蔽、最致命的回测错误。
过拟合 Overfitting
策略"背下"了历史数据里的随机噪声而非真实规律,历史曲线极美、实盘立刻失灵。曲线越完美越可疑。样本内夏普高得离谱是典型信号。见 L5。
收益曲线 Equity Curve
把每根 K 线的净收益复利累积(cumprod)得到的资金曲线,起点通常归一到 1.0。回测的主输出,一切成绩单从它压缩而来。
最大回撤 Max Drawdown, MDD
收益曲线从任意历史高点跌到之后最低谷的最大跌幅(≤0)。衡量"痛感"——你要忍受的最难熬一段。(equity/equity.cummax()−1).min()。见 L5。
夏普比率 Sharpe Ratio
风险调整后收益:每承担一单位波动换来多少超额收益。mean/std × √年化因子。全行业最通用的策略尺子。<1 平庸,>3 存疑(疑似过拟合)。
波动率 Volatility
收益的标准差(std),衡量颠簸幅度。夏普的分母;同样收益下波动越小越好。
CAGR 复合年化增长率
把总收益摊成"平均每年"的复利速度,让长短不一的回测可横向比较。equity[-1]**(1/年数)−1。
年化 Annualization
把"每根 K 线"的统计量换算成"每年"的可比数。日线 crypto ≈ 365,传统股票 ≈ 252,4h 线 = 365×6。用错因子,夏普/CAGR 全错。
滑点 Slippage
你期望的成交价与实际成交价之间的差。市价单、流动性差、行情剧烈时尤其大。回测忽略它 = 自欺。
手续费 Fee / Commission
交易所对每笔成交收取的费用,常分 maker(挂单)/taker(吃单)两档。高频策略对费率极敏感。
执行 Execution
把仓位决策变成真实订单并管理其生命周期(下单、部分成交、撤单、持仓对账)。"系统"与"实验"的分水岭。
风控 Risk management
凌驾于所有环节之上的守门机制:最大仓位、单笔/单日止损、急停开关。目标是"活到能赚钱的那天"。
急停 Kill switch
一键停止所有交易/撤销所有挂单的机制。行情异常或系统出 bug 时的最后保险。
样本内 / 样本外 In-sample / Out-of-sample
样本内 = 调参时用过的数据(表现必然好看,对预测未来无价值);样本外 = 从没碰过的数据,是对"上线后表现"的诚实代理。见 L6。
Train / Test 切分 Train/Test Split
把时间序列按时间顺序切成前段(train,调参)+ 后段(test,验收一次)。绝不能随机打乱——那会把未来 K 线混进 train。
数据泄漏 Data Leakage
训练/回测中用到了当时拿不到的未来信息。随机打乱时间序列、用未来数据填充、跨切点标准化都是常见来源。前视偏差的更广义说法。
数据窥探 Data Snooping
反复查看 test 结果再回头改策略,使 test 悄悄变成样本内。诚实做法:参数在 train 上锁定后,test 只跑唯一一次。
过拟合税 Overfitting Tax
样本内表现 − 样本外表现的落差。落差越大,原"漂亮回测"里的水分越多。判断真信号 vs 过拟合的核心量。
滚动前进验证 Walk-forward
train→test 窗口一段段往前挪,反复"调参→样本外验收",把每段样本外拼成一条跨多市场的连续曲线,摊平 regime 运气。单次 train/test 的稳健升级版。见 L7。
Rolling / Anchored 窗口
walk-forward 的两种 train 窗口:Rolling=固定长度、整体前移(只记近期);Anchored/Expanding=起点不动、窗口不断扩张(累积全部历史)。
参数漂移 Parameter Drift
walk-forward 里每个 fold 选中的"最优参数"来回乱跳。说明没有跨市场稳定的最优——所谓最优只是各段噪声。漂移越大,策略越不可信。
纸上交易 / 干跑 Paper trading / Dry-run
用真实实时行情、模拟资金下单,不投真金白银。回测与实盘之间的必经桥梁,专门抓回测看不见的工程 bug(时区/断网/状态错乱)。见 L8。
事件循环 Event Loop / Tick
实盘的运行方式:每隔一段时间执行一次 tick(poll→signal→compare→act),一次只处理一根 K 线。与回测的整列向量化相对。
未收盘 K 线 Forming Candle
实时拉到的最后一根 K 线,当前周期还没结束、数值仍在变。用它算信号 = 前视偏差的实盘版。做法:df.iloc[:-1] 丢掉它,只用已收盘 K 线。
状态持久化 State Persistence
把持仓/现金/入场价等写入磁盘,使断电重启后账户不丢。实盘是"有记忆的循环",回测则每次重算。
幂等 Idempotency
同一操作执行多次,结果与执行一次相同。两处用到:①信号层——只在"目标仓位≠当前仓位"时下单(L8);②执行层——断网重试不下重单(L10),靠一把幂等钥匙。
幂等钥匙 / clientOrderId Idempotency Key
你在下单前自己生成、随单交给交易所的 id,交易所保证同一把钥匙最多执行一次。必须是交易意图的纯函数(如 symbol-side-bar_ts),绝不能含 time.time()——否则重试时钥匙变了,幂等失效。断网重试的安全底座。
标记市值 Mark-to-market
任意时刻账户价值 = 现金 + 持币 × 现价。你的实时净值,盈亏随行情逐刻变动。
Maker / Taker
Maker=挂限价单为市场"提供"流动性(费率低/有返佣);Taker=用市价单"吃掉"现有挂单(费率高)。
K 线 OHLCV / Candle
一个时间段内的开(Open)、高(High)、低(Low)、收(Close)、量(Volume)。最常用的行情数据结构。
限价单 Limit Order
指定价格挂单:成交价有保证(不超过你的价),但成交本身没保证——可能一直挂着。你是 maker。见 L9。
市价单 Market Order
立即按当前盘口成交:成交有保证,但价格没保证——吃穿盘口就是滑点。你是 taker。
部分成交 Partial Fill
status=open 且 0 < filled < amount:你的价位上流动性不够,只成交了一部分。真实持仓 = filled,账本记事实不记意图。剩余量三选一:等 / 撤 / 追。见 L11。
订单有效期 Time in Force (GTC/IOC/FOK)
下单时声明的存活规则。GTC=一直挂到你撤(默认);IOC=立刻成交能成的部分、剩余量交易所原子地自动撤;FOK=全额立刻成交否则整单取消。IOC 结构性消灭撤单/成交竞态。
追单 Chase / Repricing
撤掉(或让 IOC 自动撤掉)未成交量,用更激进的价格重发,用价格换成交确定性。必须有界(限腿数 + 限价格带 + 市价兜底),否则等于一张专挑差价成交的慢动作市价单。每条腿一把独立幂等钥匙。见 L11。
撤单/成交竞态 Cancel/Fill Race
撤单请求在路上时订单可能又成交了一块——cancel 返回成功 ≠ 之前没成交。纪律:撤单也要回读,终态 filled 才进账本。IOC 腿的终态常为 canceled/expired 但 filled>0:status 说单子的结局,filled 说钱的去向。
订单状态 Order Status
ccxt 统一订单的生命周期终态:open(挂单中,含部分成交)、closed(全额成交)、canceled(撤单/超时);被拒为 rejected。下单后须 fetch_order 回读,不能假设。
对账 Reconciliation
用交易所返回的真相(filled/average/fee)校准你以为的成交,而非用下单前的假设价记账。SEND → READ BACK → RECONCILE 的第三步。
已实现滑点 Realized Slippage
市价单实际成交均价(average)与下单前参考价之差,常用 bps 表示。回测里被固定滑点近似,实盘里逐单量出。
名义价值 Notional
一张订单的市值 = amount × price。风控闸门的核心度量:设上限挡住 fat-finger(多打一个零)。
风控闸门 / 急停 Risk Gate / Kill Switch
任何订单发出前必须通过的前置关卡,有权拒单(名义上限/最小额/急停)。急停=一个开关,打开即秒拒一切新单,是策略发疯时的红色大按钮。见 L9。
测试网 Testnet / Sandbox
交易所提供的真实撮合、假钱环境。ccxt 用 set_sandbox_mode(True) 切入。接真钱前把执行 bug(时区/精度/端点/鉴权)全撞一遍的地方。
稳健性检验 Robustness / Cross-asset Replication
把整台已验证的机器原封不动搬到另一个资产/时段上再跑一遍,一个参数都不为新数据重调。查的是策略是否只拟合了原数据的具体波纹。纪律:一旦为新资产调参,就把 asset #2 也过拟合了,检验作废。见 L15。
形状判决 Shape, not Number
换资产后绝对数字(Sharpe/CAGR)必然不同,不可直接比。看的是相对排名有没有保持:组合是否仍 > 各零件单飞、> 躺平。形状保持 = edge 泛化;形状破 = 原来那次多半是过拟合。
多重检验 Multiple Testing
试的参数组合/资产越多,纯靠运气蒙出一条样本内漂亮曲线的概率越大。是回测过拟合的根源。对抗它:样本外 + 换资产的诚实复现,并如实计入试过多少次。
回测过拟合 Backtest Overfitting
在足够多的尝试里,总能找到一个在历史上完美、却对未来一无所知的策略。样本内越漂亮、旋钮越多、试得越多,越可疑。López de Prado 等的核心警告;换资产/样本外是主要解药。见 L15。
双边信号 / 做空 Two-sided / Short
把仓位从 {0,+1}(空仓/做多)放开到 {−1,0,+1}:下跌里做空而非干坐。打穿"只做多"在熊市的天花板(最好只能少亏)——熊市能真赚,可能首次正 Sharpe。回测天生支持(position*ret 自动取反)。见 L16。
永续合约 Perpetual / Perp
无到期日的合约,现货做不了空时用它做空。价格靠资金费率锚定现货。做空的载体 = funding 成本的来源。
资金费率 Funding Rate
持有 perp 每隔几小时多空之间互付的费用,让 perp 价格贴住现货。是让做空/持仓不免费的碳税:回测里按 |position|·funding 每 bar 计提。热门行情可飙到 ~0.3%/天,能把薄的做空 edge 吃光——做双边策略必做 funding 敏感性。见 L16。
空头挤压 Short Squeeze
熊市里的暴力反弹专治做空:价格急拉逼空头平仓、进一步推高。做多最多亏 100%,做空理论上亏损无上限。双边策略"永远在市场里"=在震荡/反弹里被反复扫损(whipsaw)的新风险。
波动率拖累 Volatility Drag
几何收益(CAGR)总 ≤ 算术均值,差距随波动放大。所以会出现"Sharpe(基于算术均值)为正、CAGR(几何)却为负":每 bar 平均略赚,但大起大落把复利吃回负。读成绩单要同时看两者。
信号→执行闭环 Signal-to-Execution Loop
把已验证的信号(大脑)接上执行管路(手)的一次决策循环:收盘K线→目标仓位→仓位差→风控闸门→幂等下单→回读对账→账本。使命里"回测→纸上交易"那一步的实现。串起 L8 三纪律 + L9 闸门 + L10 幂等 + L11 回读 + L12–L16 信号。见 L17。
纸上交易 / Dry-run Paper Trading
真实行情 + 真实信号 + 假钱,跑完整管路。验的是管路(下单/对账/幂等/时区/精度/竞态),不是 edge 会不会赚钱(小样本证明不了)。真钱进场前把执行 bug 全撞一遍的地方;工业机器人(freqtrade)把它做成实盘的一个开关。见 L17。
仓位管理 / 下注大小 Position Sizing / Bet Sizing
回答"下多大",与"赌哪边"(信号)是独立的一层。风险瞎子(固定名义/满仓)在崩盘里会过度暴露。纯叠加在 position 列上,不碰信号。见 L18。
波动率目标定量 Volatility Targeting
把仓位缩放到让策略预期波动钉在固定目标:weight = target_vol / realized_vol(截断到杠杆上限)。危险时缩、平静时放。是风险旋钮——几乎不改 Sharpe(信号属性),只缩放你承担的回撤/收益。按能扛的最大回撤反推目标,不按最大 CAGR(那是把风控偷换成过拟合)。见 L18。
Kelly 判据 Kelly Criterion
最大化长期复利增长的最优下注比例。致命前提:假设你确切知道自己的 edge。edge 估计有噪声时(实盘常态),全 Kelly 会过度下注、一把归零 → 实盘用分数 Kelly / 波动率定量。edge 越薄越不确定,下注越要保守。
向目标再平衡 Rebalance-to-target
每根 bar 算一个目标敞口(=信号×权重×资本),和当前持仓比,只交易差额——而非全进/全出。vol 定量削回撤靠的就是它:持仓中波动一涨就减仓,只在入场定大小会漏掉这份保护。见 L19。
不动区间 No-trade Band
再平衡差额小于阈值(最小下单额/自设带宽)就不动,避免为几毛钱的漂移反复交易被手续费 churn 死。太窄=churn,太宽=偏离目标。见 L19。
配给资本 Allocated Capital
划给某个策略的那一块钱,仓位管理对着它算(不对着全部身家)。真实组合里钱分给多策略/多资产。附带好处:单量小、稳落在风控闸门内,闸门作为独立硬后备永不撤除。
永续合约 Perpetual Swap / Perp
没有到期日的期货,用资金费率把价格锚在现货附近。用 USDT 抵押保证金,不真正持有币。关键能力:允许负持仓 → 能原生做空、能上杠杆——现货物理上做不到的两件事。ccxt 里交易对写作 BTC/USDT:USDT,测试网在 testnet.binancefuture.com(与现货测试网两套账户)。见 L20。
带符号持仓 Signed Position
perp 上你持有的不是币余额(≥0),而是一个带符号的数:+=多、0=平、−=空。flat 时的卖单=开空(建立负持仓、"欠"币),不是"卖掉手里的币"。心智从"我有多少币"切到"我的持仓是正是负"。fetch_positions() 读回这个符号=L9"读回对账"在 perp 上的样子。见 L20。
只减仓单 reduceOnly
标记一张只能缩小持仓、绝不会反向开新仓的订单。平仓永远是持仓符号的反方向:平空=买、平多=卖。用它平仓可保证"手滑买过头变开多"不会发生;风控上平仓单可豁免名义上限(减风险的动作永远该放行)。见 L20。
资金费率 Funding Rate
perp 持仓的"碳税":每 8h(3 次/日)按标记价 vs 现货指数的偏离,在多空之间收付一次。费率>0 → 多头付空头;<0 → 空头付多头。L16 里它是模拟的一笔成本,perp 上是真的、会随持仓真扣。edge 薄时它能把双边收益吃归零(L16 实测 3bp/天即归零)。见 L20。
杠杆 Leverage
恒等式 杠杆 = |名义| / 起始保证金。关键:杠杆只出现在保证金那一侧,不在盈亏公式里。固定名义拧杠杆,每 $1 价格变动的盈亏分毫不变——变的只有被锁的保证金和爆仓距离。所以杠杆不是加速器,是解除"名义 ≤ 本金"约束的准入许可。风险的正确变量始终是名义。币安 v3 接口已不返回 leverage 字段,须用恒等式自己推。见 L21。
起始 / 维持保证金率 Initial / Maintenance Margin Rate
起始保证金率 = 起始保证金/|名义| = 1/杠杆(开仓要锁多少)。维持保证金率 mmr = 维持保证金/|名义|(不被强平的最低线,实测小仓 0.400%)。mmr 按名义分档跳升——仓越大 mmr 越高、爆仓越早,这才是"大仓更危险"的真正机制。见 L21。
强平价 / 爆仓价 Liquidation Price
保证金被亏到只剩维持要求的那个价。逐仓空头 P = P₀·(1+1/L)/(1+mmr),多头 P₀·(1−1/L)/(1−mmr)。推导中仓位大小 q 被约掉:爆仓价与仓位大小无关,只由杠杆和 mmr 决定——大小决定伤害,杠杆决定死线。20x 逐仓 ≈ 4.6% 反向波动即归零。见 L21。
交易日历 / 年化常数 Trading Calendar / Annualization
crypto ~365 bar/年(7×24),股票实测 251.4 bar/年。sharpe = 均值/标准差 × sqrt(bars_per_year),填 365 跑股票 → 夏普恒定虚高 sqrt(365/252)=1.204(+20.4%,与策略与标的均无关);CAGR 同向虚高但机制不同(years=bar数/365 把 10 年当 6.9 年)。关键:它不抛异常。不会崩的错误常数比会崩的危险得多。纪律:实测日历,别写死。见 L23。
隔夜跳空 Overnight Gap
前一日收盘 → 当日开盘的价格变动,市场关闭、物理上无法交易。实测十年:SPY 隔夜占收益 62%,KO 占 92.5%(其盘中累计为 −3.2%)。含义:signal.shift(1) 在 crypto 上=「收盘算信号、按收盘成交」(成立,永不收市);在股票上信号收盘后才算得出,最早次日开盘成交——换仓那天的进出场价被推到跳空另一侧。同一行代码在两个市场表达的不是同一个假设。见 L23。
幸存者偏差 Survivorship Bias
你今天能列举出的标的,已经全部通过了"没倒闭"这道筛子。实证:向数据源索要 SIVBQ(硅谷银行)/ LEHMQ(雷曼)/ ENRNQ(安然)全部返回空。用幸存者做的回测天然继承一条未来信息,对"专买跌惨了的便宜货"这类策略伤害最大。解法:带退市记录的数据库(CRSP/Norgate),或接受并写下该偏差。crypto 更严重(死掉的币远多于退市公司)。见 L23。
选择方差 Selection Variance
从 N 个带噪声的估计里挑最大的那个,这个动作本身制造方差——你挑中的往往不是"最好的参数",而是"噪声最眷顾的参数"。walk-forward 消灭了前视偏差(每 fold 只用训练窗口选参),但没有消灭选择方差。实测:7 个 fold 里 2 个,样本内冠军是样本外最差的参数族。见 L22。
参数高原 / 尖峰 Parameter Plateau / Peak
训练期高分只有两种来源:踩在真实结构上,或者运气好。区分方法=看邻居。邻居也好 = 高原(结构);邻居全差 = 尖峰(噪声对齐)。因为参数一定会漂,高原上漂一格还在高原,尖峰上漂一格摔下悬崖。稳健选法:挑训练期邻域均值最大的格子,而非点最大值——同样只用样本内信息,只是换了个抗噪统计量。见 L22。
参数集成 Parameter Ensembling
不挑单一冠军,而是把网格里多组参数等权平均(或 top-k 平均)。关键限定:集成只降低"你拿到哪个参数"的方差,它不改变均值。均值为正 → 更可靠地赚;均值为负 → 更可靠地亏(实测 SOL:k 越大越差,−0.98 → −1.54)。所以"永远做集成"是错口号。实测三资产唯一全部改善的是高原选法,不是盲目平均。见 L22。
波动率拖累(再访) Volatility Drag, revisited
几何收益 ≈ 算术收益 − σ²/2。实测 BTC 双边组合:算术 +13.39%/年,年化波动 52.1% → 拖累 13.57% → 几何 −0.06%。夏普量算术、CAGR 量几何,所以"夏普 +0.26 而一分不赚"完全可能——这是"读全三列"的硬理由。拖累是 σ 的二次函数,所以 L18 的 vol 定量削它是超线性的:压到 20% 波动后 CAGR −0.1% → +7.0%,信号一个字没改。见 L22。
全仓 / 逐仓 Cross / Isolated Margin
逐仓:为单张仓位划出孤立保证金,亏光即止,损失被关在笼子里。全仓:整个钱包给所有仓位垫背,小单几乎打不爆(实测 $57 空单爆仓价 559 万),代价是真爆时赔的是全部。结论:爆仓价不是仓位的属性,是「仓位+抵押品」的属性。测试网默认全仓——"我的爆仓价好远"是全仓在顶,不是安全。见 L21。
成交假设 Fill Assumption
回测里"信号变成成交价"用的那条规则。收盘算信号按当根收盘成交在 crypto 成立(永不收市),在股票是物理不可能——诚实版是次日开盘,且延迟须重算为 shift(2)(收益区间起点提前了一根 bar;留 shift(1) = 亲手引入新前视)。实测:跳空对信号是无偏噪声(20 格 10 好 10 坏,面板均值 ≈0),不改期望只放大方差,换手是唯一放大器;主流框架(backtrader)默认就是次日开盘,同根成交的开关叫 cheat_on_open。见 L24。
预注册 Pre-registration
在打开判决数据之前,把假设、样本、方法、判读阈值和每格对应的行动登记在案,然后只跑一次、结果照收。锁的不是参数(walk-forward 已锁)、不是选参方差(高原选法已压),是最后一个自由度:裁判本人。区分两种合法活动:生成假设(看数据找模式,L12–L21)与检验假设(先押注后看牌)——混用才是罪。模板见 预注册清单。见 L25。
研究者自由度 Researcher Degrees of Freedom
每个"事后才做"的决定(挑哪个指标、算不算这只票、阈值取多少)都是一个岔路口;看过结果的人会不自觉走向让结果好看的那条。危险在于不改任何数字——数据全诚实,被扭曲的是"哪个数字算数",所以代码审查抓不到,只有时间顺序(判据在前、数据在后)能证明。心理学复现危机(100 项研究仅约 1/3 复现)的主因,也是"回测好看、实盘归零"的流程根源。见 L25。
多重检验账本 Multiple-Testing Ledger
一份清单:判决数据被"看"过几次、每次改变了什么决定。独立性的可执行判准是问决策:有没有旋钮因这些数字而改变?没有 → 选择层干净;见过相关数字 → 软污染,如实记录(它削弱预测的盲度,不摧毁检验)。L22 的 0.67 无法做多重检验修正,正是因为这本账没记——看过多少次已数不清。见 L25。
三态判读表 Three-state Verdict Table
预注册的核心交付物:支持 / 反驳 / 含糊(可加"惊喜"),每格阈值是数字,每格接一个行动。两条硬规则:写不出行动的判据是装饰;四格里不允许出现"再试一次"。含糊格的默认行动 = 按「不上钱」处理。见 L25。
收益归因 Return Attribution
把净收益按恒等式拆给署名的来源:净 = 多头贡献 + 空头贡献 − 成本(position 拆正负两半分别乘收益,逐 bar 相加,合计须与实际分毫不差——差一分就是有凶手漏网)。是"尸检"的第一刀:先问每一分亏损是谁签收的,再谈为什么。实测 L25 反驳:SPY/AAPL 主凶是空头(−11.7%/−18.0% 每年),KO 主凶竟是成本。见 L26。
反事实阶梯 Counterfactual Ladder
一列回测,每级只改一件事(净→零成本→拔掉空头→买入持有),于是每个级差就是那件事的价格。读法两条:①级差定价(SPY:成本 0.37 个夏普、空头 0.90 个);②最后一级的剩余最扎心——长平版仍远输买持 = 择时本身在赔。警告:除顶层外每级都是判决后的新回测 = 生成假设,好看之处须新数据才算数。见 L26。
水下时间 Time under Water
equity 从峰值跌落到重新收复之间度过的时间(AFML 第 14 章的标准统计量)。与回撤深度互补:深度量"多疼",水下时间量"疼多久"。它是区分气候的关键刀:BTC 2021-23 最深回撤 378 根 bar 跌落、窗口内未收复(长熊);SPY 同期最深一次 23 根跌完、97 根收复(V 型)。长熊喂饱趋势空头,V 型绞杀它。见 L26。
气候特化 Regime Specialization(课程用语)
一台机器的 edge 只在它出生的那种市场气候里启动——机器没坏,是"它会的那件事"换了地方发生。证据链(L26 三刀闭合于 XOM):同一根做空扳机,BTC 老家扣动后次 bar −7.6bp(有肉),美股五票全为正(送钱);五票里唯一有长熊的 XOM,恰是唯一空头赚钱、唯一回撤浅于买持的。精化后的假设:保护跨气候,不跨市场——检验须用新数据(如 2000-02、2008)。见 L26。
横截面策略 Cross-sectional Strategy
把提问方向从"什么时候涨"(时序,L3–L26 全部)转成"谁比谁强":同一时刻对全体标的排序,做多最强的一篮、做空最弱的一篮。三个缺一不可的词:同一时刻(横截面而非时序)、排序(相对而非绝对——熊市第 1 名可能是 −30%,照买)、两腿等额(市场共同涨跌在相减中抵消)。技术核心是 rank(axis=1):在一行之内比较,权重取决于同侪而非自身绝对水平。见 L27。
面板数据 Panel Data
行是日期、列是标的的宽表。同一张表两种读法:竖着走一列 = 时序,横着走一行 = 横截面。转置本身不带来新数据,改变的是提问方向。fetch_panel 是 L23 那个 6 行 yfinance 转接头的批量版。见 L27。
美元中性 / beta 中性 Dollar / Beta Neutral
多空两腿等额(权重和 = 0)⇒ 市场共同因子在相减中抵消。实测(30 只道指成分,2016–2026):单拿多头篮 beta +1.10、单拿空头篮 −1.13、价差 −0.04。最常见的误用:把它当"低风险"——价差年化波动 21.6% > 市场 17.1%。beta 归零只消掉市场共同那一份,不消掉特质风险;是换赛道,不是买保险。旧风险"赌错方向",新风险"赌错名次"。见 L27。
12-1 动量 / 短期反转 12-1 Momentum / Short-term Reversal
横截面排序最经得起复现的排序键:close.shift(21)/close.shift(252)−1 —— 过去 12 个月涨幅,但跳过最近 21 天。跳过不是装饰:最近一个月里住着短期反转(刚涨完的容易回吐),方向与动量相反,不砍掉会互相稀释。出处 Jegadeesh & Titman (1993)。见 L27。
特质风险 Idiosyncratic Risk
剥掉市场共同因子后,每只票自己剩下的那份波动(财报、诉讼、CEO 发疯)。多空对冲消不掉它,而且每条腿只装 6 只票时它被浓缩了——这正是中性组合波动反而高于市场的原因。推论:波动率目标(L18)在横截面里不是可选项,是必需品。见 L27。
结构性数字 vs 名单依赖数字 Structural vs Roster-dependent(课程用语)
读任何回测数字前先问:它靠什么撑着? 收益依赖名单——今天的道指成分是活到今天的赢家,被踢出去和死掉的不记账(L23 幸存者偏差),所以被向上污染。beta≈0 是结构性的——来自 long − short 等额相减的代数事实,换任何一篮子都成立。幸存者偏差污染收益,污染不了 beta:L27 因此只交付一个数字。见 L27。
