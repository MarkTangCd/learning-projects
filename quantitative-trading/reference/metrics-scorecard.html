策略成绩单速查

一条 equity 曲线 → 三个能读懂的数字。配 L5。

前提

一个回测过的 df(来自 向量化回测配方),含 equity_net、strat_ret_net、ret、equity_hold。

三个指标

BARS_PER_YEAR = infer_bars_per_year(df.index)   # 实测,别写死(见下方"年化因子")

# ① 最大回撤:从历史高点跌到之后谷底的最大跌幅(≤0,越接近 0 越好)
roll_max = df["equity_net"].cummax()
mdd = (df["equity_net"] / roll_max - 1).min()

# ② 夏普比率:每单位波动的年化收益(无风险利率按 0 简化)
r = df["strat_ret_net"].dropna()
sharpe = r.mean() / r.std() * (BARS_PER_YEAR ** 0.5)

# ③ CAGR:复合年化增长率(把总收益摊成"每年")
years = len(df) / BARS_PER_YEAR
cagr = df["equity_net"].iloc[-1] ** (1 / years) - 1

怎么读

指标它回答方向粗略基准
最大回撤 MaxDD能不能拿得住(痛感)越接近 0 越好−50% = 账户腰斩过
夏普 Sharpe值不值得拿(风险调整)越高越好<1 平庸 · 1–2 不错 · 2–3 很好 · >3 存疑
CAGR多快(年化速度)越高越好永远与买入持有对比
铁律 永远和 买入持有的同款三数并排看。夏普更低、回撤更深却只换来相近 CAGR 的策略,是自找麻烦。而样本内夏普高得离谱(>3),先怀疑过拟合,拿没见过的数据验证。
年化因子怎么定:实测,别写死(L23) 写死一个数,换市场就静默出错:365 跑股票,夏普恒定虚高 sqrt(365/252)=1.204(+20.4%),而且不抛任何异常。改成从数据的 DatetimeIndex 推断,三道闸门缺一不可:
  1. 数 bar,别量间隔。 股票日线的 bar 间隔也是一天 —— 量间隔会给股票算出 365。年化要的是"一年几个观测",所以 (len−1) / 跨越年数。len−1 不能省:跨度只覆盖 n−1 个间隔,漏掉会让 63 根的窗口读成 256(+1.6%)。
  2. 吸附到已知日历。 原始估计随窗口抖动(90 根折:244–258)。返回带小数的原始值会让每个 walk-forward 折拿到不同除数,折间夏普不可比。吸附回 {365, 2190, 8760, 252, 1638} 之一,同时保证 crypto 结果和以前逐字节相同(365.2 → 365)。
  3. 对不上就抛,绝不猜。 自动推断没有消灭静默失败,只是换了个地方:数据有洞(拼接/停牌/下载中断)会稀释估计。再加一道最大间隔检查 —— SPY 最大正常间隔 4 天 = 中位数的 4 倍,超过 10 倍即报错。光靠"离已知日历 >10%"抓不住小洞。

同一个常数还有第二个受害者:weight = target_vol / rv 里 rv 在分母,所以 365 跑股票会把仓位压小 17.0% —— 与夏普反向。更糟的是它在夏普上看不见(仓位同比例缩放,均值和标准差一起缩,比值不变)。实现见 practice/trading_calendar.py,自检 python trading_calendar.py。
