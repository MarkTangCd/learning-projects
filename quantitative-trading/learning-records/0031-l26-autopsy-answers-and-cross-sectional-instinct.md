# L26 尸检挑战:归因读法已扎实,横截面直觉自发涌现,证据/故事的边界仍需训练

用户完成 L26 的动手挑战 ②③④⑤,四题的表现分化明显,直接决定 L27 的切入点和详略。

## Evidence

**② KO 成本主凶 —— 完全正确。** 独立答出 `weight = target_vol / rv` → 低波动 → 大仓位 → 名义金额计费 → 账单最重。补充给他的是二阶项:`trade = position.diff().abs()` 作用在已乘 weight 的 position 上,所以 weight 自身漂动也产生换手,成本是"天天在付"而非只在信号翻转时付。

**③ MSFT +20.7bp —— 结论对,方法论滑坡。** 答案的实质(长牛中死叉筛出的是回调而非反转)方向正确,但他给出的机制是"低时间框架的人进场捡漏"——一个 OHLCV 数据里根本观测不到、无法证伪的叙事。**这是本轮最值得记录的缺口:能得出对的结论,但还不能自动区分"可测证据"与"合理故事"。** 已给出可证伪的替代版本:比较 conditional 均值(+20.7bp)与 unconditional 日均漂移,用以分辨"扳机无信息"vs"扳机有负 alpha"。此检验尚未执行。

**④ 检验方案 —— 空白。** 完全不知从何入手。根因是没有把 `holdout_stocks.py:91` 的 `SINCE = "2015-01-01"` 与"哪些数据还没被开过"联系起来。**"未开封数据是一种有限资源、要先盘点库存"这个心智模型尚未建立**,尽管 L25 的预注册流程他是走过一遍的。已补:2000-03 与 2007-09 两段长熊 + 五票在 2000 年均已存在 + 预注册骨架 + n=2 的天花板。

**⑤ 带去横截面的假设 —— 直觉正确,表述仍是时序的。** 自发写出"强势的股票只做多,弱势的股票只做空"——这是横截面动量的雏形,在没有任何提示的情况下产生。缺的三个词:**同一时刻**(横截面而非时序)、**排序**(相对而非绝对)、**两腿相消**(对冲掉气候而非叠加敞口)。

## Implications

对 L27 的直接影响:

1. **横截面的"为什么"不需要重讲。** 他已经自己论证到门口,L27 应该直接从"怎么做"开箱——排序、分层、两腿建仓——把课时省下来给机制细节。要做的只是把他⑤的表述当场拧成横截面版本,让他看见自己写的东西离答案只差三个词。
2. **需要一节专门训练"证据 vs 故事"的肌肉。** ③暴露的不是知识缺口而是**认识论习惯**:遇到现象先编机制,而不是先问"我手上的数据能不能测它"。横截面策略的因子解释(价值/动量/质量)是这个毛病的重灾区——每个因子都有一套动听的行为金融学故事。建议在 L27 或紧随其后植入一个小的判别练习。
3. **"数据库存"应显式化。** ④的空白说明预注册流程他会走,但"哪些数据还没开封"没有被当成一张需要主动清点的资产负债表。可考虑在 reference/ 加一张数据开封台账(哪个窗口、哪个标的、何时开的、开给谁),既服务这个盲点,也是后面横截面全市场取数时的必需品。
4. **待办的开放动作:** conditional vs unconditional 漂移的三行检验(③),以及在 `cmd_parts` 里加打 `weight.mean()` / `trade.sum()` 五票对比(上一轮提出,未执行)。两者都便宜,可作为 L27 的热身。
