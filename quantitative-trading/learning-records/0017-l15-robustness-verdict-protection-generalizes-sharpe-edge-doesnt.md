# L15 判决:下跌保护三资产全泛化,但"夏普 edge"没泛化;根因=只做多的天花板

用户于 2026-08-10 跑 `walkforward_robust.py`,冻结机器(GGRID/RGRID FROZEN)搬到 BTC/ETH/SOL,同 span 2022-01→2023-09。

## 三资产全指标对照(组合 vs 躺平)
| | BTC | ETH | SOL |
|---|---|---|---|
| Sharpe | −0.02 > −0.28 ✓ | −0.25 > −0.30 ✓ | **−0.91 < −0.61 ✗** |
| CAGR | −7.1% > −27.4% ✓ | −18.5% > −38.4% ✓ | −57.4% > −71.5% ✓ |
| MaxDD | −46% < −67% ✓ | −49% < −74% ✓ | −79% < −95% ✓ |

脚本的一行"形状判决"只看 Sharpe → SOL 破了。但**读全三列**:SOL 上组合仍少亏 14pt、回撤浅 15pt。**"破了"纯由 Sharpe 一个指标驱动**;夏普变差 = 组合进出把亏损打得更颠簸(波动),不是没保护本金。

## fold 尸检(累计收益按 regime 腿拆,scratch/diag_sol.py)
- BTC:trend 腿 −40% / range 腿 **+62%** → 回归腿扛住,净 −2.9%
- ETH:trend 腿 +5% / range 腿 −27% → 分工不同,净亏
- SOL:trend 腿 −51% / range 腿 −49% → **两腿全亏,无处可躲**

SOL 两腿都亏,因为两个子信号**都只做多**,而 SOL 2022 跌 −94%(FTX 重灾)。只做多在单边灾难里最好只能"少亏",剧烈死猫跳还让进出更颠簸 → Sharpe 被打穿。

## 诚实判决(分两层,别用二元 pass/fail)
1. **"下跌保护"身份:三资产全部泛化**(少亏 + 回撤更浅,连 SOL −94% 都成立)= 真的、可移植 = **不是 BTC 过拟合**。这是 L15 的实打实进步。
2. **"保护→夏普 edge":没泛化**。最暴力崩盘资产上风险调整优势翻车;且三资产 Sharpe 全 ≤ 0 = 承 [[0016-l14-verdict-regime-combo-beats-parts-but-drift-worse]] / [[0014-mean-reversion-verdict-downside-protection-not-edge]]:始终是下跌保护,非正收益 edge。

## 元教训(白捡)
别信脚本 Sharpe-only 的"形状破了";单指标 pass/fail 会藏真相 —— 读全三列(Sharpe/CAGR/MaxDD)。

## 根因锁定 → 下一步岔路
四课(L12-L15)夏普恒负的**同一个根因:所有信号只做多**。在多年 crypto 熊市里,long-only 的天花板永远是"少亏"。要突破:
- **A. 引入做空(perp/双向信号)**:直接打根因,可能首次产出正 Sharpe。代价:资金费率/perp 机制/双边过拟合面。← 老师首选(攻卡点)
- **B. 纸上交易(接 L9-11 执行层)**:把已验证的"下跌保护 overlay"在 BTC/ETH 上跑活的 signal→execution。是使命里程碑,但须诚实定位=**验管路,非上真钱**(策略仍无正 edge)。换换 texture(连做 4 课研究)。
- **C. 掉头股票赛道**:均值回归/配对在股票史更扎实;但 crypto 工作证明有可移植属性,全面掉头略早。
