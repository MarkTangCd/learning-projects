# L8 完成:纸上交易 tick 循环跑通 —— 三纪律经受住"无聊"检验

用户于 2026-08-06 跑通 `practice/paper_trade.py --loop 60`:SMA(10,30)、1d 周期、起始 $10,000。

## Evidence(用户亲眼看到)
- **冷启动建仓**:第一 tick `last_ts=None` → 有新收盘K线 → `fast>slow` 目标=1 → `BUY 0.154591 BTC @ $64,622.09`,现金清零。全链路 poll→signal→compare→act→persist 通。
- **纪律②工作**:之后每 60s tick 全部命中 `state["last_ts"] == bar_ts` 短路返回("无新收盘K线,持仓不变")。日线一天只收盘一根,60s 心跳看到的都是同一根 `2026-08-06 08:00:00` → 正确地"什么都不做"。用户内化"日线实盘的真实体感=绝大多数时间不动作"。
- **诚实成本**:equity $10,000 → $9,990,差额正好 = `10000 × 0.1% FEE`。进场即付买路钱。
- **持久化**:Ctrl-C 后 `paper_state.json` 记住 `position=1 / coin=0.1545911 / entry=64622.09`。

## 收尾压力测试:paper trading 抓到一个真 bug(L8 的高光)
用户切换 `--tf`(4h→1d)且未 `--reset`,`trades` 出现 **SELL 的 bar_ts(2026-08-05)早于 BUY 的 bar_ts(2026-08-06 08:00)**——loop"对着过去下了单"。诊断成立并复现:`08:00` 是 4h 收盘,`00:00` 是 1d 收盘。

**两个根因(都是回测永远看不到的活体 bug):**
1. **闸门太弱**:`state["last_ts"] == bar_ts` 只挡"完全相等",时间戳倒退时放行 → 误成交。修:改比时间序 `bar_ts_obj <= last_obj` → 持仓不变(既挡重复也挡倒退)。
2. **账本不分周期**:单一 `paper_state.json` 被跨 `--tf` 复用 → 4h 状态比 1d K线。修:`state_path(tf)` 按 `(symbol, timeframe)` 命名空间,切周期即换账本。

**验证(2026-08-06)**:1d 首跑持仓不变@$10k → 切 4h 独立账本 BUY@08:00 → 切回 1d 读回自己账本、`bar_ts≤last_ts` 挡住、不再误 SELL。两文件 `paper_state_BTCUSDT_1d/4h.json` 并存互不串味。补丁已进 `paper_trade.py`,参考卡加纪律④⑤。
用户由此内化:**paper trading 的核心价值 = 在接真钱前把时区/状态错乱抖出来**,而非验证策略赚钱。

## 已触发验证的支路
1. ✅ 进程重启不重复建仓(老师现场跑单 tick,读回 position 不动作)。
2. ✅ "新K线但目标=当前 → 不动作"(1d 首跑 `目标=0 与当前一致,不动作`)。
3. ✅ 一次 SELL(切周期误触发 → 反倒暴露了上面的 bug)。
