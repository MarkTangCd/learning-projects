## 实测数据(BTC/USDT:USDT, 0.0009 BTC 空单, 全仓)

```
notional      = -57.69271876      initialMargin = 2.88463594
maintMargin   =   0.23077087      entryPrice    = 64106.4
breakEvenPrice=  64080.75744      liquidationPrice = 5597190.24
isolatedMargin= "0"               crossWalletBalance = 4999.925
```

## 三个恒等式(本条记录的核心)

字段缺失 ≠ 信息缺失。ccxt 给的 `None` 只说明**那扇窗户**没这个字段。

| 想知道 | 恒等式 | 实测 |
|---|---|---|
| 杠杆 | `\|notional\| / initialMargin` | 57.6927 / 2.8846 = **20.0x** |
| 起始保证金率 | `initialMargin / \|notional\|` = 1/杠杆 | **5.00%** |
| 维持保证金率 | `maintMargin / \|notional\|` | **0.400%**(爆仓线参数) |
| 已付开仓费 | `\|entryPrice − breakEvenPrice\| × 数量` | 25.64 × 0.0009 = **$0.0231** |

`breakEvenPrice` 那条尤其有用:**不用翻订单历史就能拿到已付手续费**。空单的盈亏平衡价
**低于**开仓价(必须买得更便宜才回本),多单则高于——差额永远朝着不利方向,那就是费。

## 爆仓价是"仓位 + 抵押品"的属性,不是仓位的属性

$5,597,190 的爆仓价看着像 bug,其实是全仓:`isolatedMargin=0`、`crossWalletBalance=4999.93`
——整个钱包在给这张 $57 的空单垫背。$4999.93 / 0.0009 BTC ≈ $5.56M 可承受涨幅,
加上开仓价 64,106 ≈ **559 万**。对得上。

同一张单换成逐仓(只放 2.88U 保证金),涨约 5% 就爆。**仓位没变,风险变了。** → L21 的入口。

## 方向做对了,依然是亏的

| 项 | 金额 |

| 毛盈亏(价格朝我走了 $3.30) | +$0.0030 |

| 平仓费 | −$0.0231 |

实测 taker 费率 = 0.0231/57.69 = **4.00 bp 单边**,来回 **8 bp 固定门槛**。

**信号必须先赚够 8 bp 才开始赚钱。** 这是 L4"诚实的回测"里手填的摩擦参数的真身,
现在是实测值,不是猜测。放进 L18 的波动率目标 + L19 的调仓节奏里,它按**换手率**线性放大。

## 我犯的错(值得记)

第一版 `cmd_close` 标注了"未计开仓费"却照样印出 bp 数,把成本**报少了一半**(−3.49 vs
真实 −7.49)。**一个标了免责声明的错误数字,仍然是错误数字**——它会被直接抄进回测参数。
教训:成本只有**双边**才有意义,单边数字不该以同样的格式印出来。已修。
