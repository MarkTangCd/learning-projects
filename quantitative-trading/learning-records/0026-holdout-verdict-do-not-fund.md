# 0026 — 留出集判决:不上钱。以及一个二次复现的真发现

- **日期**: 2026-08-11
- **数据**: 2023-10-01 起的 1000 根日线,测试段 2024-09-30 → 2026-06-21(7 folds)。
  **此前 22 课的所有数字都测在 2021-01-01 → 2023-09-27,这段从未被打开过。**
- **机器在开数据前焊死**:GGRID(L14 冻结)+ 方法③高原选参 + fee 4bp(L20/21 实测)
  + vol 目标 20%(L18)+ funding 1bp/日。**只跑一次,不重跑。**
- 脚本: `practice/holdout.py`

## 判决(判据在开数据前和用户共同确认)

| 预注册区间 | 解读 | 实际 |
|---|---|---|
| BTC Sharpe > 0.4 且 CAGR > 0 | 真信号,可小资金上线 | |
| **BTC Sharpe 0 ~ 0.4** | **大概率是 2021–23 的产物,不上钱** | **← 命中(0.17)** |
| BTC Sharpe < 0 | 之前的 0.67 是多重检验产物 | |

**BTC 方法③:Sharpe 0.17 / CAGR +1.4% / MaxDD −26.9%。**

样本内那段是 0.67 → 留出集 0.17,**掉了 0.50**。这正是多重检验预测的衰减幅度。
**结论:不上钱。**

## 更该记的:我在 L22 称为"本课交付物"的东西没有复现

L22 的核心结论是"方法③(高原选参)是唯一三资产全改善的方法"。留出集上:

| | BTC | ETH | SOL |
|---|---|---|---|
| ① 挑最好 | −0.17 | −0.64 | **+0.39** |
| ② top3 平均 | **+0.24** | −0.21 | −0.06 |
| ③ 高原(判据) | +0.17 | **−0.77** | +0.18 |
| ④ 全等权 | −0.17 | **−0.05** | −0.26 |

**四种方法的排序在三个资产上完全打乱**,③ 在 ETH 上还是最差的一个。
"③ 永不变差"本身就是 2021–23 那段样本的产物。

**教训:方法层面的结论和策略层面的结论一样会过拟合。** 我当时用"三资产一致"
作为稳健性证据(L15 的判据),但那三个资产共用同一段时间——**换资产不等于换样本**,
共同的时间段就是共同的运气。真正的独立检验是**换时间**。

## 二次复现的真发现:下跌保护,不是 edge

对比买入持有(全部为留出集、从未见过的数据):

| | 方法③ CAGR | 买持 CAGR | 方法③ MaxDD | 买持 MaxDD |
|---|---|---|---|---|
| BTC | +1.4% | −2.0% | **−26.9%** | −51.2% |
| ETH | −17.3% | −22.6% | **−40.3%** | −67.5% |
| SOL | +1.5% | −36.4% | **−26.9%** | −76.3% |

**三个资产、全新数据上,CAGR 和 MaxDD 双双优于买入持有。** 回撤大约砍掉一半到三分之二。

这和 [[0017]](L15)的结论逐字相同:**下跌保护泛化,夏普 edge 不泛化**。
当时是三资产同期复现,现在是**跨时间**复现——两种独立的复现方式都指向同一句话。

所以这套系统的真实身份不是 alpha 来源,是**风险削减 overlay**:
它不能帮你赚钱,但能把持有 crypto 的回撤砍掉一半。这是一个**真实但不同**的产品。

夏普没跟上的原因见 [[0025]]:算术 edge 太薄,顶不住波动率拖累。

## 元教训:这次失败是系统正常工作的证据

22 课搭出来的东西,正确地输出了一个**否定结论**,而且是在钱进场之前。
一台只会输出"可以上钱"的研究机器毫无价值。判据先定、数据后开、结果照收——
这套流程本身才是这门课的资产,不是那个 0.67。
