# L16 判决:做空打穿"只做多"天花板(BTC 首次正 Sharpe),但不免费、不泛化

用户选路线 A(引入做空)。承接 [[0017-l15-robustness-verdict-protection-generalizes-sharpe-edge-doesnt]] 锁定的根因:L12-L15 夏普恒负 = 所有信号只做多,熊市天花板 = "少亏"(上限 0)。

## 改动(向后兼容,旧课复现)
- `strategy.py`:三个信号加 `long_short` 开关(默认 False = 旧 long/flat 行为逐字不变;验证:双边跑出的只做多列与 L15 一字不差)。双边=SMA `fast<slow` 做空、回归"太贵"做空,**对称复用同一 entry 不加新旋钮**(守奥卡姆)。
- `backtest.py`:加 `funding` 项,`cost = trade*fee + |position|*funding`。回测**天生**支持做空:`position*ret` 对 −1 自动取反,`diff().abs()` 对多空翻转自动算 2 倍换手 = **L1 接口红利第 6 次**,引擎零改。
- `walkforward_shorts.py`:双边组合 vs 只做多组合 vs 躺平,BTC/ETH/SOL × 三列,带 funding 敏感性。

## 结果(funding=1bp/天)
| | Sharpe | CAGR | MaxDD |
|---|---|---|---|
| BTC 双边 | **+0.12** | −6.7% | −36.8% |
| BTC 只做多 | −0.02 | −7.1% | −46.2% |
| ETH 双边 | −0.36 | −39.2% | −64.0% |
| ETH 只做多 | −0.25 | −18.5% | −49.2% |
| SOL 双边 | −0.46 | −62.5% | −84.6% |
| SOL 只做多 | −0.91 | −57.4% | −79.3% |

**BTC +0.12 = 全课首个正样本外 Sharpe**,回撤历来最浅。

## funding 敏感性(用户已亲跑三档确认)= edge 很薄
`funding 0 → +0.18` | `1bp → +0.12` | `3bp → +0.01`(基本被资金费吃光)。
**funding 对双边是单调惩罚**:ETH −0.32→−0.36→−0.45、SOL −0.44→−0.46→−0.52,越加越差且加速——双边"永远在市场里",做错方向还一直付碳税,两头挨打。"永远在场"=双刃剑(买来做空上限,也买来无空仓可躲的持续成本)。

## 三层诚实判决
1. **天花板真被打穿——在 BTC 上**。做空让熊市能真赚而非只少亏,机制成立,首次正 Sharpe。实打实突破。
2. **edge 薄且怕 funding**。热门行情 funding 到 3bp/天就归零。**做双边必做 funding 敏感性**,否则收益是幻觉——本课新诚实项。
3. **没泛化,反更不稳**。ETH 双边 −0.36 < 只做多 −0.25(永远在市场+熊市反弹=空头被扫损/挤压);SOL 夏普改善但 CAGR/回撤更糟。**读全三列**:用"上限打开"换来"稳健性下降"。承 [[0017-l15-robustness-verdict-protection-generalizes-sharpe-edge-doesnt]] 的跨资产纪律。
