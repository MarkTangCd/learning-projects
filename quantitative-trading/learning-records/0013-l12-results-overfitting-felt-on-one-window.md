# L12 动手结果:用户亲手在单窗口上"调"出了过拟合

用户于 2026-08-08 跑 `reversion.py`,三次运行(改 entry / lookback)。窗口 2025-07 → 2026-08(**熊市**:买入持有 Sharpe −0.90 / CAGR −37.2% / MaxDD −53%)。

## 关键证据
- **全员负夏普,全员亏钱**。只做多/空仓策略在单边下跌里最好结局只是"少亏",不可能真赚:
  - 均值回归 z<−1.0 lb=20:Sharpe −0.83 / CAGR −28.0% / MaxDD −43.9% / 26 笔
  - 均值回归 z<−1.5 lb=20:Sharpe −0.62 / CAGR −21.6% / 22 笔
  - 均值回归 z<−1.0 **lb=10**:Sharpe **−0.58** / CAGR −21.2% / MaxDD −33.7% / 48 笔
  - SMA(20,60):Sharpe −0.99 / CAGR −20.8% / MaxDD −31.3% / 9 笔
- **用户三次运行把夏普从 −0.83 拧到 −0.58(改善 ~30%),全在同一窗口**——过拟合面从抽象警告变成了屏幕上的具体数字。这是本课最值钱的体验。

## 内化的点
1. 负夏普 = 无 edge(这一窗口)。均值回归"跑赢"买入持有只是"少割手",不是 edge。
2. **单窗口 + 可调旋钮 = 一挑就过拟合**。谁的"最优"都是样本内的。
3. **"L13 拿哪组参数进样本外"这个问题本身是陷阱**——walk-forward 的意义就是每个训练窗自己重选参数,人不能手挑,一挑就污染。我们只给候选范围。
4. 这只是**一个熊市 regime**。只做多的趋势/回归在单边下跌天生发挥不出;公平判决需多 regime 样本外(L13 用 since=2021 的 bull+bear+recovery 跨度)。
