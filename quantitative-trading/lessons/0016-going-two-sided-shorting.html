打穿天花板:让信号做空

L12→L15 有一条贯穿始终、甩不掉的坏消息:样本外夏普永远 ≤ 0。BTC、ETH、SOL,趋势、回归、regime 组合,换资产复现——全都负。这不是策略不够聪明,是一个结构性天花板。这一课我们拆掉它。

坏消息的根因只有一句话:你所有的信号都只会"做多或空仓"。 在一段跌了两年的市场里,一个只能做多的策略,最好的结局只能是"少亏"——它可以躲开崩盘(空仓),但永远没法在下跌里赚钱。数学上,少亏的天花板就是 0,再往上够不到。

解法朴素得惊人:允许仓位取 −1 到目前为止 position ∈ {0, +1}(空仓 / 做多)。只要放开到 {−1, 0, +1}——下跌趋势里做空,而不是干坐着——策略就能在熊市里真正赚钱,而非只是少亏。天花板就被抬走了。

回测引擎一行都不用改(L1 红利,第 6 次)

还记得 L4 那个向量化回测吗?它当初就写得足够通用,天生支持做空:

df["strat_ret"] = df["position"] * df["ret"]   # position=-1 → 收益自动取反(跌 = 赚)
df["trade"]     = df["position"].diff().abs()  # +1 → -1 翻转 = 2 倍换手(平多+开空)

把 -1 乘进去,做空收益自动算对;多空翻转的双倍手续费也自动被 diff().abs() 抓到。信号照样吐一列 position,照样进同一台冻结的 gauntlet——它甚至不知道信号学会了做空。我们只在信号里加一个 long_short=True:趋势腿 fast<slow 时从"空仓"改成"做空",回归腿"太贵"时从"空仓"改成"做空"(不加新旋钮,对称复用同一个 entry,守住奥卡姆纪律)。

但做空不是免费午餐:资金费率

现货没法直接做空,你用的是永续合约(perp)。持有 perp 要周期性支付/收取资金费率(funding rate)——这是让做空不免费的那笔成本。只做多的回测把它当 0 忽略了;一个永远在市场里的双边策略,必须每根 bar 都为持仓付这笔碳税:

# backtest 新增一项:按 |position| 收持仓成本
df["cost"] = df["trade"] * fee + df["position"].abs() * funding
新增的三个风险,不止一个旋钮 做空打开了上限,也打开了新的坑:①资金费率会持续啃收益;②永远在市场里=双倍暴露=震荡里被来回扫损(whipsaw);③空头挤压——熊市里的暴力反弹专治做空,亏损无上限(做多最多亏 100%,做空理论上无限)。所以判断做空到底值不值,必须把 funding 建进回测,并读全三列指标。
你的双边策略回测夏普 +0.3,很漂亮。上线前第一件该做的诚实检查是?
对。做空的收益极易被资金费吃掉——尤其热门行情里 funding 会飙到 0.3%/天。把 funding 从 0 扫到偏高值,看夏普掉多少:如果一加真实成本就从 +0.3 塌到 ~0,那这个 edge 是幻觉。正夏普必须在保守 funding 假设下依然站得住才算数。
危险。做空最容易骗人的地方就是零成本假设。永续合约的资金费率会持续啃收益,热门行情里能到 0.3%/天。一个 funding=0 时 +0.3 的夏普,加上真实 funding 可能只剩 0。上真钱前必做 funding 敏感性。

真实结果:天花板被打穿了,但只在 BTC 上

把双边组合喂进和 L15 一字不改的冻结 gauntlet(BTC/ETH/SOL,funding=1bp/天):

资产 / 策略SharpeCAGRMaxDD
BTC 双边(做空)+0.12−6.7%−36.8%
BTC 只做多(L15)−0.02−7.1%−46.2%
ETH 双边(做空)−0.36−39.2%−64.0%
ETH 只做多(L15)−0.25−18.5%−49.2%
SOL 双边(做空)−0.46−62.5%−84.6%
SOL 只做多(L15)−0.91−57.4%−79.3%

BTC 双边 Sharpe +0.12 = 全课 12 课以来第一个正的样本外夏普,回撤也历来最浅。ETH 上做空反而更差;SOL 上夏普改善但 CAGR/回撤更糟。

funding 敏感性一扫,BTC 那个正夏普的脆弱就暴露了:

funding = 0 → Sharpe +0.18 CAGR −3.9% funding = 1bp/天 → Sharpe +0.12 CAGR −6.7% funding = 3bp/天 → Sharpe +0.01 CAGR −12.1% ← edge 基本被资金费吃光
做空让 BTC 首次正夏普,却让 ETH 比只做多更差。最诚实的一句话总结是?
对。三列一起读:BTC 打穿天花板(真突破),但 ETH 双边被熊市反弹扫损、反而更差,SOL 夏普改善却回撤更深。你用"上限打开"换来了"稳健性下降"。做空是把双刃剑,不是免费升级——这跟 L15 的教训一脉相承:任何提升都要跨资产验证。
"更高级所以更强"正是陷阱。数据不支持:ETH 上双边(−0.36)明显差于只做多(−0.25),因为永远在市场里 + 熊市反弹 = 空头被反复扫损。做空打开了上限,也打开了新风险。它是双刃剑,ETH 不是例外而是提醒:必须跨资产读全三列。
