第 4 课 · 工位 03 回测

诚实的回测

给策略装一杆秤:把收益和成本一起算清。这一课决定你信不信自己的策略。

L3 你有了一列 position(1=持有,0=空仓)。今天挂在 工位 ③「回测」:算出这个策略本来会走出的收益曲线,并把手续费和滑点扣进去。看得见的胜利——两个数字:策略含成本总收益 vs 买入持有总收益。

这是新手死亡区 L1 说过:大多数"稳赚"策略都死在这一步。今天我们学的是怎么不骗自己——诚实回测有三条纪律:① 不用未来信息 ② 扣掉交易成本 ③ 和"什么都不做"比。

第一步:一根 K 线赚多少?

先把价格变成收益率——这是回测的原子单位:

df["ret"] = df["close"].pct_change()   # 今天相对昨天的涨跌幅

pct_change() = (今天收盘 / 昨天收盘) − 1。比如 100 → 105,ret = 0.05(涨 5%)。

第二步:策略赚多少?

关键洞察:你只在"持有"的那些 K 线上,吃到市场的涨跌。空仓时(position=0)你赚 0。用乘法一步搞定:

df["strat_ret"] = df["position"] * df["ret"]
  • 持有(position=1):strat_ret = 1 × ret → 完整吃到当根涨跌。
  • 空仓(position=0):strat_ret = 0 × ret = 0 → 场外,涨跌与你无关。
前视偏差已经防好了 这里的 position 是 L3 里 shift(1) 过的——用已收盘的 K 线算信号、下一根才持仓。所以这个乘法天然不含未来信息。L3 那一步的价值,在这里兑现。

第三步:扣掉交易成本(诚实的核心)

每次 position 发生变化(0→1 进场,或 1→0 离场),就是一笔真实交易,要付手续费 + 滑点。用 diff() 抓住"变化":

FEE = 0.001                              # 单边 0.1%:手续费 + 滑点的粗估
df["trade"] = df["position"].diff().abs()  # 换手:进/出各记 1
df["cost"]  = df["trade"] * FEE
df["strat_ret_net"] = df["strat_ret"] - df["cost"]   # 净收益 = 毛收益 − 成本

这正是你上节课 9/6/11 悬念的答案所在:交易越频繁,被扣的 cost 越多。进场 11 次的那组,要先多赚出这些成本才谈得上更好。

第四步:滚成收益曲线,并和"躺平"比

收益率靠复利累积:每根 K 线把本金乘以 (1+当根收益)。cumprod()(累积乘积)把它们连乘起来:

df["equity_net"]  = (1 + df["strat_ret_net"].fillna(0)).cumprod()  # 策略(含成本)
df["equity_hold"] = (1 + df["ret"].fillna(0)).cumprod()            # 买入持有基准

total_strat = df["equity_net"].iloc[-1] - 1
total_hold  = df["equity_hold"].iloc[-1] - 1
print(f"策略(含成本)总收益: {total_strat:.1%}")
print(f"买入持有总收益:     {total_hold:.1%}")
真正的及格线 "策略赚了钱"根本不够——问题永远是:它有没有跑赢"无脑买入并持有"? 一个跑不赢躺平的复杂策略,只是用更高的风险和成本,换来更差的结果。equity_hold 就是你每个策略必须先迈过的那道坎。

你刚做的,就是一次"向量化回测"

注意全程没有一个 for 循环——全是整列的数学运算。这叫向量化回测(vectorized backtest):快、简洁、适合快速试参数。它是简化版,做了几个假设(按收盘价成交、成本固定、无部分成交)。等策略成型,再上 freqtrade / vectorbt 这类专业引擎处理更真实的细节——但核心原理就是你今天这四步。完整配方见 向量化回测配方 →

随手一测

判断一个策略好坏,最该拿它去比较的基准是?
对。跑不赢"买入持有"的策略,等于用更高成本和风险换更差结果。equity_hold 是每个策略必须先迈过的坎。
应该比"买入持有(equity_hold)":跑不赢躺平的策略毫无意义。这是回测里最诚实的一把尺。
df["position"].diff().abs() 这一列在回测里代表什么?
对。position 变化(0→1 或 1→0)= 一次买或卖,diff 抓住这个跳变,乘以费率就是这笔交易的成本。
diff() 抓的是 position 的"变化":从 0→1 或 1→0 就是一次交易换手,要按费率扣成本。
