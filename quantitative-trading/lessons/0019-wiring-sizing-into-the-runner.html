把风险旋钮焊进系统

L18 你给出了一个风险决定(vol 目标 ~20–22%,给 30% 红线留缓冲)。L17 你有了一条能下真单的活循环。这一课把两者焊在一起:runner 的下单量不再是硬编码的 $20,而是由你的风险目标 + 当下市场波动实时算出来。

signal(0/1) × weight = vol目标 / 当前波动 × 配给资本 = 目标敞口 $ 目标敞口 − 当前持仓 = 差额 → 过闸门下单补齐(小于最小额就不动)

下注大小第一次由三样东西决定:信号方向、你的风险目标、市场此刻有多狂。市场波动飙升时,同一个"做多"信号会自动对应更小的仓位——这正是 L18 里把回撤从 −59% 砍到 −25% 的那台机制,现在长在了活系统里。

三个焊接时冒出来的新决定

1. 从"翻转 0/1"升级到"向目标再平衡"。 L17 的 runner 只会全进/全出。现在每根 bar 都算一个目标敞口,和当前持仓比,只交易差额。这一步是关键:只在入场时定一次大小不够——vol 定量削减回撤,靠的是持仓期间波动一涨就减仓,那必须每根 bar 重新对齐目标。

你已持有多头。三天后市场波动翻倍(信号仍看多)。"每根 bar 向目标再平衡"会做什么?
对。波动翻倍 → weight = 目标/波动 减半 → 目标敞口减半 → 和当前持仓的差额是"卖一半",系统主动减仓。这就是 vol 定量削回撤的发动机:危险变大时不等信号翻转,先把暴露收回来。只在入场定大小会漏掉这一整份保护。
"入场定一次就不管"恰好丢掉了 vol 定量最值钱的部分。L18 里回撤从 −59% 砍到 −25%,靠的不是入场大小,而是持仓中波动一涨就减仓。波动翻倍 → 权重减半 → 目标敞口减半 → 系统卖掉一半。不每根 bar 再平衡,这份保护就没了。

2. 不动区间(no-trade band)。 每根 bar 都可能算出一个略微不同的目标,若每次都去交易那几毛钱的差额,会被手续费churn 死。规则:差额小于交易所最小下单额(或一个你设的带宽)就不动。省下的是无谓的过路费——呼应 L11 学的"急迫成本/换手是有代价的"。

3. 对着「配给资本」下注,不对着全部身家。 你给这个策略划一小块资本(demo 里 $40),目标敞口 = 权重 × 配给资本。这既让单量落在 L9 $50 闸门之下(闸门仍是硬后备,永不撤除),也符合真实做法:一个策略只动它被分到的那一份钱。

现货的天花板:权重被截到 1.0 某天市场很平静(年化波动 25%),而你的 vol 目标是 30% —— 公式想要 weight = 30/25 = 1.2(120% 仓位)。但现货买不了超过 100% 的仓(那要借钱/杠杆),所以权重被截到 1.0。含义:平静市里,现货够不到高 vol 目标——想要就得上 perp 永续合约(能杠杆,连着 L16 的资金费率)。截断本身也是保护:它挡住了系统在平静期悄悄加杠杆。
你把下单量对着"配给资本 $40"算,而不是测试网账户里的几万假钱。为什么这样更对?
对。仓位管理是对着分配给这个策略的资本做的,不是对着你的全部身家——真实组合里你会把钱分给多个策略/资产。用配给资本还有个附带好处:单量小、稳稳落在 L9 的 $50 闸门内,而闸门作为独立的硬后备永不撤除(sizing 算错了它还能兜住)。
问题不在余额真假。核心是:一个策略只该动分给它的那一份资本,而不是账户里的全部钱——否则任何单个策略都能押上你的全部身家。对着配给资本下注,单量自然落在 L9 闸门内,而闸门作为独立硬后备始终在兜底。
动手挑战:让系统按你的风险目标下第一张「算出来的」单 strategy_runner.py 已把 vol_target_weight 焊入,单量 = 信号 × 权重 × 配给资本:
① python strategy_runner.py --reset --target 1 --vol 0.22 —— 强制做多,用你的 22% 目标。看它打印当前波动 → 权重 → 目标敞口 $,然后过闸门下一张大小算出来的市价单(不再是 $20)。
② 紧接着 python strategy_runner.py --target 1 --vol 0.22 再跑 —— 目标敞口≈当前持仓,差额落进不动区间,应不调仓。
③ --target 1 --vol 0.10 vs --vol 0.30 —— 同一个多头信号,看目标敞口随 vol 目标缩放;留意 0.30 在平静市里权重是否被截到 1.0。
④ --target 0 平掉,再 python strategy_runner.py(不带 target)让真实信号 + 当下波动自己决定。
把 ①③ 的输出贴给我 —— 我们确认:你的风险决定,现在真的在驱动系统的下单量。
