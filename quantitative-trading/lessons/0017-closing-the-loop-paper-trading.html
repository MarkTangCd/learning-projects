闭环:让信号亲手下单

你的系统一直是两个半边,分居两地:大脑(L12–L16 的信号)在离线 gauntlet 里被证明;手(L9–L11 的执行管路)靠手动命令一个个演练。它们从没握过手。这一课把它们接通——一次 tick,串起你到目前为止造的每一个零件。

这是一堂 capstone:它不教新概念,它把旧零件焊成一台机器 strategy_runner.py 的一次决策循环,依次触发:L12–L16 信号 → L8 三纪律 → L9 风控闸门 → L10 幂等钥匙 → L11 回读对账 → 账本。这是你使命里"从回测推进到纸上交易"的那一步,第一次真正闭合。
  1. BRAIN · L12–L16
    拉最新收盘K线 → regime_switch_signal → 目标仓位 target ∈ {0,+1}。信号在最后一根已收盘 bar 上读出,就是回测里 shift(1) 的实盘形态。
  2. L8 · 三纪律
    丢掉正在形成的 bar(只用收盘);只在严格更新的 bar 上动作(挡住重复/倒退触发);目标==当前就不下单(账本即真相)。
  3. L9 · 风控闸门
    把仓位变化翻译成一张订单,发送前必过 guarded_create:名义上限 / 最小额 / 急停,任一不过即拒单,账本不变。
  4. L10 · 幂等钥匙
    cid = run-{side}-{bar}——钥匙来自意图(哪根 bar)而非时钟。崩溃重启后重跑同一根 bar,交易所认出同一 cid、拒绝重复 → 永不下重单。
  5. L11 · 回读对账
    绝不信 create() 的回执。fetch_order 读回真相,拿到实际成交 filled 与均价。
  6. 账本 · L11 铁律
    账本记实成 filled,不是意图 intended。持仓 = 交易所真给你的,不是你以为下出去的。
诚实的边界:现货测试网不能做空 L16 里做空是主角,但 Binance 现货测试网只能 long/flat。所以这座桥先跑 {0,+1}——真正执行双边(做空)需要 perp 永续测试网(连着 L16 的资金费率,留给后面一课)。这不削弱本课:这一课的主角是「管路」,不是「edge」。 我们要证明的是——真订单能不能安全地、幂等地、对完账地走完全程。
runner 刚发出买单就崩溃了,你重启后在同一根日线上又跑了一次。什么挡住了重复下单?
对。cid = run-buy-{bar} 是意图的纯函数(哪根 bar + 买还是卖),不含时钟。重启重跑同一根 bar,cid 一模一样,交易所认出重复直接拒单(L10)。再加 L8 的"只在更新 bar 上动作",双保险。靠的是设计,不是运气。
靠运气就等着某天双倍下单。真正挡住它的是幂等钥匙:cid 由(bar + side)算出、不含时钟,重跑同一根 bar 必得同一 cid,交易所拒绝重复(L10)。异步世界里"发出去没回执"是常态,幂等是唯一可靠的防重手段。

纸上交易在验的是「管路」,不是「会不会赚钱」

L16 给了你 BTC 上 +0.12 的样本外夏普——但那个 edge 薄且怕资金费。所以要说清楚这一课不在做什么:跑几天纸上交易,无法确认这个 edge 真能赚钱(样本太小,且这里还是 long/flat 版)。纸上交易验的是另一件同等重要、且与 edge 无关的事:

我的信号,能不能安全地、幂等地、对完账地,驱动真实订单走完全程——在真钱进场之前,把时区/精度/端点/竞态/重复单这些管路 bug 全撞一遍。

这正是使命要的:先让系统可靠,再谈策略赚钱。两者分开验,别混。

纸上交易跑了两周,账户小赚。下面哪个结论是诚实的?
对。两周、long/flat、样本极小——只够验管路(订单有没有安全走完、账本对不对、幂等灵不灵),远不够验edge。L15/L16 反复教的:小样本上的漂亮结果最会骗人。管路 OK 是真进展,但它和"策略会赚钱"是两件事。
这就是把"管路能用"误读成"策略能赚"。两周纸上交易样本太小,且这里跑的是薄 edge 的 long/flat 版——它能证明订单管路可靠,证明不了策略盈利。混淆这两者,正是 L15/L16 警告的小样本自欺。上真钱前两者都要单独立住。

动手挑战:让信号打出你系统的第一枪

用 L9 的同一套测试网密钥,信号第一次接管下单 strategy_runner.py 已写好(复用 execution.py 的 connect/guarded_create + strategy.py 的信号):
① python strategy_runner.py --reset --target 1 —— 手动覆盖目标为"做多",逼管路点火:看它过风控闸门 → 发市价买单 → fetch_order 回读 → 账本按实成 filled 更新。这是你系统"大脑接手手"的第一枪。
② 紧接着 python strategy_runner.py --target 1 再跑一次(不 reset)—— 目标已==当前,应不下单(幂等/账本即真相)。
③ python strategy_runner.py --target 0 —— 平仓卖出,回读对账,账本归零。
④ 最后 python strategy_runner.py(不带 target)—— 让真实信号决定当下该 0 还是 1,看它自己的判断。
⑤ 急停演练:python execution.py kill 后再 --target 1 —— 风控该拒单;execution.py unkill 解除。
把 ①③⑤ 的输出贴给我,我们一起确认:六个零件是不是真的焊成了一台机器。
