拿到你的第一批真实行情

流水线的第一段。今天结束时,你会把真实的 BTC K 线握在手里——装进一张干净的表。

这一课挂在 L1 的工位 ①「数据」上。目标只有一个、看得见的胜利:从交易所拉到真实的 BTC/USDT 小时 K 线,清洗成一张规整的 pandas 表格。没有策略、没有回测——先把地基的第一块砖砌好。

我们用 CCXT:一个用同一套代码访问 100+ 交易所的开源库。学会它,你就不被任何单一交易所绑死——这正是好架构该有的样子。

先看地区可达性 Binance 国际站(binance.com)的 API 在美国、中国大陆等地区被地理封锁,直连会连接超时(不是代码错)。若你在这些地区,把交易所换成全球可达的 ccxt.kraken()(支持 BTC/USDT)、或 ccxt.coinbase()(用 "BTC/USD")、ccxt.binanceus()。这本身就是 L1 说的"交易所怪癖"——可达性因地区而异,是量化的真实工程现实。本课示例默认用 Kraken。

第 2 步:拉数据(完整可运行)

新建 fetch_ohlcv.py,粘贴运行:

import ccxt
import pandas as pd

# 1) Pick an exchange. No API key needed for public market data.
#    binance.com is geo-blocked in the US / mainland China — use kraken there.
exchange = ccxt.kraken()

# 2) Fetch OHLCV candles: symbol, timeframe, how many.
#    Returns a list of [timestamp, open, high, low, close, volume].
raw = exchange.fetch_ohlcv("BTC/USDT", timeframe="1h", limit=500)

# 3) Load into a pandas DataFrame — a labeled table.
df = pd.DataFrame(raw, columns=["ts", "open", "high", "low", "close", "volume"])

# 4) The timestamp is Unix milliseconds. Turn it into real UTC datetimes,
#    then make it the row index so every row is stamped in time.
df["ts"] = pd.to_datetime(df["ts"], unit="ms", utc=True)
df = df.set_index("ts")

print(df.tail())          # last 5 rows
print(df.shape)           # (rows, columns)

清洗:三件必须警惕的事

「数据脏,后面全脏」(L1)。拿到 K 线后,永远检查:

  • 时区:交易所时间戳基本是 UTC 毫秒。上面第 4 步已用 utc=True 显式标注——别让本地时区悄悄混进来。
  • 缺口/重复:偶尔会缺 K 线或重复。检查:df.index.duplicated().sum() 应为 0;df.index.is_monotonic_increasing 应为 True(时间严格递增)。
  • 最新那根未收盘:最后一根 K 线可能还在跳动(未收盘)。做信号时通常丢掉最后一根,只用已收盘的 K 线——否则就埋下了前视偏差的种子。
