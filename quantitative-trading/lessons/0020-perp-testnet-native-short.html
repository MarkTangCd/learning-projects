你的第一张原生空单

L16 你在回测里证明了做空能把 BTC 的样本外夏普顶成全课首个正值;L17–L19 你把一条能按风险下注的活循环焊上了现货测试网。但现货有一堵拆不掉的墙:你只能持有币,不能欠币——余额永远 ≥ 0,物理上做不了空。这一课换到 perp 永续合约测试网,把那堵墙拆掉。

现货(spot) BTC 余额 = ≥ 0 只能"有多少卖多少" —— 做空不可能 perp 合约 持仓 = −0.001 / 0 / +0.001 空 / 平 / 多 —— 一个带符号的数 ──────────────────────────────────────────────── flat 时 SELL = 开空(你从此"欠"BTC) 平空 = BUY(reduceOnly) flat 时 BUY = 开多 平多 = SELL(reduceOnly)

核心心智切换:现货上你想的是"我有多少币",perp 上你想的是"我的持仓是正是负"。fetch_positions() 读回的不再是一个币余额,而是一个带符号的持仓——这就是 L9 那条铁律"别假设,读回来对账"在 perp 上的样子,只不过读回的真相多了一个符号位。

换到 perp,三样东西是新的

1. 新 venue,新密钥。 perp 测试网是 testnet.binancefuture.com,和 L9 的现货测试网 testnet.binance.vision 是两套完全独立的账户——密钥不通用。ccxt 里用 binanceusdm 客户端,交易对是 BTC/USDT:USDT(USDT 保证金的线性永续),不是现货的 BTC/USDT。

2. 你抵押保证金,不再持有币。 perp 账户里躺的是 USDT 保证金;你并不真的拥有 BTC,只是持有一个"对 BTC 价格的带符号敞口"。开空 = 卖出建立负敞口;价格跌 → 负敞口赚钱。平仓永远是反方向的 reduceOnly 单:平空要买回,平多要卖出。reduceOnly 保证这张单只能缩小持仓,绝不会手滑反向开新仓。

3. 最小下单额大得多。 perp 的 BTC 最小名义 ≈ $50,现货只要 ~$5。所以 perp 单子"块头很大",L9 那个 $50 名义闸门在这里会卡死每一张单——本课把闸门按 venue 重新标定到 $200(闸门的形状没变,只是校准值随场子换)。

你现在持有一个空头仓位(−0.001 BTC)。要把它平掉,你该发一张什么单?
对。空头是负持仓,要回到 0 得往正方向推 → 买。reduceOnly 让这张买单只能缩小空头、不会一不小心买过头变成开多。平多才是卖。记住:平仓方向 = 持仓符号的反方向。
直觉"平仓=卖掉"是现货脑子。perp 上空头是负持仓,你要把它推回 0 就得往正方向走 = 买入(买回你"欠"的那份)。平空=买、平多=卖。方向永远是持仓符号的相反。
你的 perp 账户里一个 BTC 都没有(只有 USDT 保证金)。你发了一张市价卖单。会发生什么?
对。这正是 perp 拆掉的那堵墙。flat 时的 SELL 不是"卖掉手里的币"(你没有币)——它是开空:凭 USDT 保证金建立一个负敞口。价格跌你就赚。现货做不到这件事,因为现货余额不能为负。
这是现货的规则(没币不能卖)。perp 不一样:你抵押的是 USDT 保证金,卖单在 flat 时是开空——建立一个负持仓,等于"借 BTC 来卖"。这就是本课的整个重点:perp 允许负持仓,所以能做空。
两个最容易栽的坑 ① 密钥用错场子。 perp 测试网密钥必须在 testnet.binancefuture.com 生成;把 L9 的现货测试网密钥填进来会报 Invalid API-key(它俩是两套账户)。
② $40 配给在 perp 上 1 倍杠杆下不出单。 perp 最小名义 ≈ $50 > 你 L19 的配给资本 $40。含义:perp 上杠杆不是"可选加速",而是小账户能下单的前提——这正是下一课 L21 的入口。本课先用 $60 的演示单(略高于最小额)把空开出来,杠杆按测试网默认值(通常 20x),不去碰它。
动手挑战:开出你的第一张原生空单,读回一个负持仓 先在 testnet.binancefuture.com 生成密钥并 export(见 perp.py 顶部),然后按顺序:
① python perp.py balance —— 确认能看到 perp 测试网的 USDT 保证金(和现货是两套钱)。
② python perp.py funding —— 看当前资金费率:L16 里那笔"碳税"现在是真的了,持仓期间每 8h 收/付一次(本课只预览,L22 再让它真扣)。
③ python perp.py short —— flat 时市价卖出开空 $60,过闸门 → 回读订单 → 读回一个负持仓(现货永远打印不出这一行)。
④ python perp.py position —— 盯住那个 仓位=−… 和未实现盈亏随价格跳动。
⑤ python perp.py close —— reduceOnly 买回平仓,持仓回到 0。
把 ③⑤ 的输出贴给我 —— 我们确认:你真的在真实撮合上开了一张现货物理上下不出的单,并且干净地平回了 flat。
