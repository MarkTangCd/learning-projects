量化交易系统的解剖

在写任何一行策略代码之前,先看清整台机器长什么样。

你的使命是亲手搭一套量化交易系统。系统这个词听起来庞大,但它其实是一条流水线(pipeline):数据从一端进来,订单从另一端出去,中间经过几个界限清晰的工位。

今天唯一的目标:记住这五个工位,以及它们各自回答的那个问题。之后每一节课都会挂在这张地图的某个工位上——所以这是你最该反复回看的一课。

五段式流水线

01 · DATA
数据
拿到干净、对齐、可信的行情。
「我看到了什么?」
02 · SIGNAL
信号 / 策略
把数据转成买/卖/持有的决策。
「我该做什么?」
03 · BACKTEST
回测
在历史上诚实地检验这个决策。
「这想法值钱吗?」
04 · EXECUTION
执行
把决策变成真实的下单与成交。
「怎么把单打进去?」
05 · RISK
风控
在所有环节之上,防止你爆仓。
「怎么才能不死?」

① 数据 Data

一切的地基。你要从交易所 API 拿到价格/成交量,清洗它:时间对齐、去重、处理缺口,还要知道每个交易所的怪癖(最小价格变动 tick size、手续费结构)。数据脏,后面全脏。Crypto 的好处是数据基本免费、开放——这也是我们从它切入的原因。

② 信号 Signal / 策略 Strategy

系统的大脑:一段把数据映射成仓位决策的逻辑。可以简单如"价格上穿 20 日均线就买",也可以复杂如一个机器学习模型的输出。注意——信号只回答"做什么",不回答"下多少、怎么下",那是后面工位的事。

③ 回测 Backtest

在历史数据上模拟运行你的策略,看它本来会赚还是会亏。这是新手最容易自欺欺人的一环。一个诚实的回测必须计入手续费、滑点(slippage),并严防前视偏差(look-ahead bias)——即用了当时根本拿不到的未来信息。术语见词汇表 →

新手死亡区 绝大多数"稳赚"策略都死在回测这一步:它们不是找到了真规律,而是过拟合(overfitting)了历史噪声。一条能通过诚实回测的普通策略,远胜一条曲线漂亮却造假的策略。

④ 执行 Execution

把"买 0.5 BTC"这个决策,变成真正打进交易所的订单,并跟踪它的状态:部分成交、撤单、持仓对账。这一步是"交易系统"和"交易实验"的分水岭——能自动、可靠地下单管单,系统才算活了。

⑤ 风控 Risk

不是流水线的一个环节,而是笼罩在所有环节之上的守门人:单笔最大亏损、最大仓位、单日止损、以及一键"急停(kill switch)"。信号负责让你赚钱,风控负责让你活到能赚钱的那天。

一个关键洞察:两个循环,一份信号

这条流水线其实跑成两个循环:

  • 研究循环:数据 → 信号 → 回测 →(改进)→ 再回测。你 90% 的时间花在这里。
  • 实盘循环:数据 → 信号 → 风控/仓位 → 执行。真金白银在这里流动。
工程原则 两个循环里的「信号」应该是同一份代码。如果回测用的策略逻辑和实盘用的是两套代码,你回测出来的结论对实盘就毫无意义。一份信号,两处运行——这是好架构的第一条戒律。

随手一测

一条历史曲线极其漂亮的策略,最该让你警惕的问题是什么?
对。漂亮曲线的头号嫌疑就是过拟合——策略"背下"了历史噪声,换到未来就失灵。诚实回测的意义正在于此。
再想想:曲线越完美,越可能是过拟合了历史噪声,而非发现了真规律。这是回测环节的头号陷阱。
"回测赚钱和实盘用的是同一份信号代码"——这条原则属于哪个工位的关切?
对。这是贯穿"研究循环"和"实盘循环"的架构原则:一份信号、两处运行,否则回测结论对实盘无效。
这是一条架构原则:研究循环和实盘循环必须共用同一份信号代码,否则回测无法代表实盘。
