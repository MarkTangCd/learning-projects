Regime 过滤:让两个半吊子互补

L13 的判决里,最值钱的是 fold 5:均值回归在那段强反弹里输给了躺平。那不是 bug——那是均值回归该输的地方(单边上涨是趋势的主场)。既然两者的软肋正好错开,能不能让它们各打各的天时?

回顾 L13 给你的两句话,拼起来就是这一课:

  • 均值回归:震荡市 + 下跌里表现好(空仓躲崩盘,回撤 −46% vs 躺平 −67%),但单边上涨里跑输(fold 5)。
  • 趋势(SMA):单边趋势市是主场,但震荡市里反复挨割(L7 里它整体跑输)。

两者的强项和弱项互为镜像。Regime 过滤的思路:先判断"当下是趋势市还是震荡市",再决定这一刻开哪个信号——趋势市用 SMA,震荡/下跌市用均值回归。一个信号的职责,变成了"挑另一个信号"。

怎么判断"趋势 or 震荡":Efficiency Ratio

需要一个数来量化"当前有多像趋势"。用 Efficiency Ratio(ER,效率比)——它问一个极朴素的问题:过去这段路,价格走的总路程里,有多少是"净前进"?

net   = (close - close.shift(window)).abs()        # 净位移:起点到终点的直线距离
total = close.diff().abs().rolling(window).sum()   # 总路程:每天挪动的绝对值之和
ER = net / total                                   # 0 ~ 1 之间
ER → 1：一路单边走,净位移 ≈ 总路程 → 趋势市,交给 SMA ER → 0：来回震荡,走了很多路却没净进展 → 震荡市,交给均值回归

直觉:从家走到 1 公里外的公司,如果直线走,总路程≈1 公里,ER≈1(高效、有方向);如果在原地来回踱步走了 1 公里但没离开家门,净位移≈0,ER≈0(瞎忙、没方向)。价格也一样——ER 高 = 有趋势,ER 低 = 在震荡。它纯 pandas 就能算,不需要新库。

某段行情里 Efficiency Ratio 长期很低(接近 0),regime 过滤该开哪个信号?
对。ER 低 = 价格走了很多路却没净进展 = 震荡市 = 没有趋势可追,追进去只会反复挨割。这种行情正是均值回归("偏离就拉回")的天时。ER 高才轮到趋势 SMA。
方向反了。低 ER = 没有净方向 = 震荡市,趋势信号在这里会被反复假突破割死(L7 的教训)。低 ER 该交给均值回归;高 ER(单边)才交给趋势。

组合信号:同样吐一列 position

关键设计:regime 过滤不发明新的下单逻辑,它只是个"路由器"——用 ER 选择用趋势信号的输出还是回归信号的输出。所以它照样吐一列 position,照样进同一台 gauntlet(L1 接口红利,第四次):

er = efficiency_ratio(df["close"], er_window)
trend_sig  = sma_crossover_signal(df, fast=20, slow=60)["signal"]   # 子信号:趋势
revert_sig = zscore_reversion_signal(df, lookback=20, entry=1.0)["signal"]  # 子信号:回归
is_trend = er > er_thresh
df["signal"]   = np.where(is_trend, trend_sig, revert_sig)   # 按 regime 路由
df["position"] = df["signal"].shift(1)   # 一次干净的 shift,防前视(同 L3 纪律)
警报:你刚给过拟合面又添了柴 组合信号现在有 6 个旋钮:子信号的 fast/slow/lookback/entry + 新的 er_window/er_thresh。参数越多,越容易在历史上拟合出一条假的漂亮曲线。纪律:把两个子信号钉死在各自族的默认值,只让 gauntlet 调 regime 的那 1–2 个新旋钮。 每加一个旋钮都要在样本外自证其值——加了参数却没换来样本外的提升,就是纯过拟合。

唯一的判据:组合能不能打赢它的"零件"?

一个组合信号看起来总更聪明(它两头的好处都想要)。但唯一诚实的问题是:它样本外的成绩,能不能同时超过趋势单飞、回归单飞、和躺平? 如果不能——如果它打不过 L13 里回归单飞的 Sharpe −0.18——那多出来的机器没有挣到自己的饭钱,该被砍掉(奥卡姆剃刀:复杂度必须换来更好的样本外表现,否则复杂度就是负债)。

所以还是同一台裁判:把 regime 组合喂进和前两课一字不差的 walk-forward,只优化 regime 那一维,拿拼接样本外曲线去比。

regime 组合样本外 Sharpe −0.20,而 L13 回归单飞是 −0.18。怎么判?
对。组合更复杂(多 2 个旋钮 = 更大过拟合面),却没换来样本外提升,反而略差。奥卡姆剃刀:复杂度必须自证其值。打不过更简单的零件,就该砍掉——"更全面"是幻觉,真金是样本外数字。
"更全面"是组合信号最诱人的自我催眠。真相:它多了 2 个旋钮(更易过拟合)却连更简单的回归单飞都没打赢。复杂度没自证其值 = 负债。样本外打平或更差 → 选更简单的那个。
