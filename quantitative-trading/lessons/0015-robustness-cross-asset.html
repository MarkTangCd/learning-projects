换资产复现:这套 edge 是真的,还是只在 BTC 上过拟合?

L14 里 regime 组合成立了——样本外 Sharpe −0.02,同时打赢回归单飞(−0.18)和躺平(−0.28),还把命门 fold 5 从输 2.0 补成只差 0.04。真正的胜利。但请立刻按住兴奋:一个资产、一段行情,只是一次抽样。

量化里最吓人的失败模式,不是"策略亏钱"——是策略在历史上很漂亮,一上真钱就死。原因几乎总是同一个:你以为找到的 edge,其实只是拟合了 BTC 2021–2023 那段具体波纹的形状。参数漂移刚刚变差(7 个 fold 选了 5 种参数)正是这个警报在响。

这一课要证伪自己 我们不是来给组合"再加分"的。我们是来努力把它搞死的:换一个它从没见过的资产,看那套"组合 > 零件 > 躺平"的关系还成不成立。搞不死,才敢往下走。

稳健性检验:冻结机器,换一块市场

做法极简单,纪律极重要:把整台机器原封不动搬到另一个资产上再跑一遍。 同样的 folds、同样的参数网格、同样钉死的子信号默认值——一个数都不许为新资产重调。

纪律:不许为 ETH 重新调参 如果你看 ETH 结果不好,就去把网格改一改、把 ER 阈值挪一挪,直到 ETH 也好看——那你只是把 asset #2 也过拟合了一遍,啥也没证明。稳健性检验唯一有效的前提,就是机器全程锁死。这也是为什么代码里 GGRID / RGRID 标了大写注释 "FROZEN"。

而且这几乎不花力气——还记得 L2 起 fetch_ohlcv 就带了 symbol 参数吗?换资产真的只改一个字符串(L1 接口红利,第 5 次兑现):

price = fetch_ohlcv(symbol="ETH/USDT", since="2021-01-01", limit=1000)  # 唯一改动
# 下面 folds / GGRID / RGRID / score / sharpe_key 一字不改地 import 进来

怎么读:看形状,不看数字

换资产后,绝对数字一定不一样(ETH 那几年比 BTC 摔得更狠)。所以判据不是"Sharpe 是不是还等于 −0.02"。判据是形状(相对排名)有没有保持:

组合 > 回归单飞 且 组合 > 躺平 → 形状保持:互补关系不是 BTC 独有 = edge 更可能是真的 组合 ≤ 任一条 → 形状破了:BTC 那次八成是过拟合穿了件花衣裳
你在 ETH 上跑组合,Sharpe −0.25,比 BTC 的 −0.02 差远了。这说明 edge 假吗?
对。不同资产/行情的绝对 Sharpe 天生不同(ETH 那几年摔得更惨,躺平都更负)。稳健性看的是相对形状:只要组合在 ETH 上仍然 > 它的零件、> 躺平,那套"互补"关系就泛化了,edge 更可信。绝对值下滑不等于 edge 破。
你被绝对数字骗了。ETH 2022 崩得比 BTC 更狠,所有策略的 Sharpe 都会更负——躺平自己也更差。该问的不是"数字掉没掉",而是"在 ETH 这块新市场上,组合还是不是同时打赢它的零件和躺平"。形状保持才是重点。

为什么这一步值这么多

每多测一个资产、多试一组参数,你都在做一次多重检验(multiple testing):试的次数越多,纯靠运气蒙出一条漂亮曲线的概率越大。这正是 López de Prado 等人反复警告的回测过拟合——"在足够多的尝试里,总有一个组合在历史上完美,却对未来一无所知"。

对抗它的唯一武器,就是样本外 + 换资产的诚实复现:一个真 edge 应该在它没被调过的市场上、依然保住形状。这一步不产出更漂亮的数字,它产出的是你敢不敢往下走的底气。

组合在 ETH 上保住了形状(仍 > 零件 > 躺平),但绝对 Sharpe 还是负的。下一步最诚实的姿态是?
对。形状泛化 → 互补是真的,不是 BTC 独有,这是实打实的进步。但两个资产的样本外 Sharpe 都 ≤ 0 意味着它的本质仍是少亏/下跌保护,不是"会赚钱"。可以推进到下一阶段(纸上交易验管路),但绝不能把"形状保持"误读成"稳赚"。
刹车。"保住形状"证明的是互补关系泛化,不是"稳赚"。两个资产的样本外 Sharpe 都还 ≤ 0——它仍是下跌保护,不是正 edge。上真钱前必须分清这两件事,否则你是在给一个"少亏"策略满仓下注。

动手挑战:亲手证伪,再加一块试金石

同一台冻结的机器,换市场 已写好 walkforward_robust.py(GGRID/RGRID 全部 FROZEN,symbol 走命令行参数):
① python walkforward_robust.py —— 默认 ETH/USDT。它并排打印 regime 组合 / 回归单飞 / 买入持有 三条拼接样本外曲线 + 形状判决 + 参数漂移。看"形状保持"还是"破了"。
② python walkforward_robust.py BTC/USDT —— 复现 L14 的 BTC 锚点,确认脚本和你上一课的数字对得上(组合 −0.02 > 回归 −0.18 > 躺平 −0.28)。
③ 先预测,再验证:在跑之前,写下你猜 SOL/USDT 会不会保住形状,然后 python walkforward_robust.py SOL/USDT。第三块试金石,也是你自己的一次"样本外"——你的直觉准不准。
把三个资产的输出贴给我,我们一起判:那套互补关系,到底是真泛化,还是只认识 BTC。
推荐精读(首选来源)

Bailey, Borwein, López de Prado & Zhu · Pseudo-Mathematics and Financial Charlatanism: The Effects of Backtest Overfitting on Out-of-Sample Performance(Notices of the AMS, 2014)—— 这一课的思想源头。用数学讲清:试的组合越多,越容易蒙出一条"样本内完美、样本外崩盘"的曲线。读完你会明白为什么"换资产复现"不是可选项,是必修课。

QuantStart · Successful Backtesting of Algorithmic Trading Strategies —— 稳健性、样本外、多重检验的实操清单(L13 已推,这一课重点看它讲 robustness 的部分)。
