均值回归:反过来押一把

SMA 是趋势信号——赌"涨的继续涨"。它在 BTC 日线上扛不过滚动前进验证(L7),没有 edge。趋势的反面是均值回归:赌"偏离的会拉回"。这一课换一个信号族,重新过同一套 gauntlet。

两种信号是相反的赌注。同一根 K 线,趋势派和回归派会下反向的单:

趋势 / 动量(SMA)均值回归(本课)
核心假设价格有惯性,会延续价格围绕均值摆动,偏离即回归
价格猛涨时追进去(买)觉得"贵了",等回落(不买 / 卖)
价格猛跌时止损离场(卖)觉得"便宜了",接一手(买)
什么行情吃香单边趋势市(强牛/强熊)震荡盘整市(区间来回)

哪种对?取决于市场处在什么状态(regime)——你在 L5 已经撞见过这件事:同一组参数,牛市和熊市成绩天差地别。没有"永远对"的信号,只有"这段行情里对"的信号。所以我们不预设立场,让数据和 gauntlet 来裁。

把"贵 / 便宜"变成一个数:z-score

要押"偏离会拉回",先得量化"偏离多少"。裸价格没法比("跌了 3000 刀"是多是少?)。做法是标准化:算价格离它滚动均值差了几个标准差——这个数就是 z-score。

mean = df["close"].rolling(lookback).mean()   # 近 lookback 根的均值 = "正常价"
std  = df["close"].rolling(lookback).std()    # 近 lookback 根的波动 = "一个标准差"
z = (df["close"] - mean) / std                # 现价离均值几个标准差

z 把不同价位、不同波动的市场放到同一把尺子上:z = -2 永远意味着"比正常便宜两个标准差",不管币价是 6 万还是 600。均值回归规则就写在这把尺子上:

z: -2 ────── -1 ────── 0 ────── +1 ────── +2 ↑ 异常便宜 均值(公允) ↑ 异常贵 z ≤ -1 进场做多 ──持有──▶ z ≥ 0 回到均值,出场

"跌破 −1 个标准差就买、涨回均值就走"。只做多 / 空仓两态,于是它和 SMA 信号输出同一列 position——这正是关键。

持仓状态怎么向量化:ffill 技巧

"进场后一直持有到出场"是个有状态的规则,天真写法要 for 循环。pandas 的做法:只在进场/出场那几根标记 1 和 0,中间留空(NaN),再前向填充让决策"保持到下一次改变":

raw = pd.Series(index=df.index, dtype="float64")  # 全 NaN
raw[z <= -entry] = 1        # 便宜 -> 标记进场
raw[z >= 0]      = 0        # 回到均值 -> 标记出场
df["signal"]   = raw.ffill().fillna(0)   # 中间的 NaN 前向填充 = "保持上次决策"
df["position"] = df["signal"].shift(1)   # 下一根才生效 —— 防前视偏差(同 L3 纪律)
ffill = 无循环的状态机 "标记事件点 → 前向填充 → 事件之间保持不变" 是把有状态逻辑向量化的通用套路。你会在无数策略里再见到它。shift(1) 那行和 SMA 信号一字不差:信号只用已收盘 K 线算,下一根才行动。
同样是价格大跌,趋势信号和均值回归信号分别怎么做?
对。这是两者相反下注的本质:趋势派把下跌读成"惯性向下"→ 离场;回归派把下跌读成"跌过头了、变便宜"→ 接一手。谁对取决于当下是趋势市还是震荡市(regime)。
方向正好相反。均值回归在大跌时买入(z 变得很负 = 异常便宜),赌价格拉回均值;趋势信号才是止损离场。两者是相反的赌注,不是快慢之分。

白捡的红利:整套 gauntlet 原样复用

新信号 zscore_reversion_signal 和 sma_crossover_signal 有完全相同的接口:吃一张价格表,吐一列 position。于是你 L4–L7 造的每一件工具——backtest()、scorecard()、oos.py、walkforward.py——一行不改就能评这个新信号。这就是 L1 "一个信号,处处复用"当初埋下的红利:换策略 = 换一个函数,裁判台不动。

# reversion.py —— 同一窗口,回归 vs 趋势 vs 买入持有
from strategy import zscore_reversion_signal, sma_crossover_signal
df = backtest(zscore_reversion_signal(price, lookback=20, entry=1.0))
scorecard(df, "均值回归")     # 同一个 scorecard,新信号直接进
别急着庆祝:单窗口成绩是冒烟测试,不是判决 就算这一窗口回归信号打赢了买入持有,也什么都还没证明——你在 L6/L7 已经学过:单窗口的漂亮数字最会骗人。更糟的是,lookback 和 entry 是两个新旋钮 = 一片新的过拟合面,你可以在一个窗口上把它们拧到最好看。真正的判决,是让这个信号过和 SMA 一模一样的样本外 + 滚动前进 gauntlet(下一课 L13)。 同样的怀疑,同样的裁判,只换信号。
均值回归信号在某一个历史窗口上跑赢了买入持有。正确的解读是?
对。单窗口 = 冒烟测试,只证明"信号能跑通",不证明"有 edge"。而且 lookback/entry 是新的过拟合旋钮。判决权在 OOS + walk-forward(L13),标准和当初否掉 SMA 时完全一致——否则就是双重标准。
这正是 L6/L7 反复敲打的陷阱:单窗口跑赢极可能是这段行情(regime)的运气 + 参数过拟合。你当初就是用 walk-forward 否掉 SMA 的;对新信号必须用同一把尺子,不能因为它是"新宠"就放水。

动手挑战:让反向赌注上台

同一窗口,三方对比 已写好 strategy.py 里的 zscore_reversion_signal 和跑分脚本 reversion.py:
① python reversion.py —— 同一窗口下打印均值回归 / 趋势 SMA(20,60) / 买入持有三张成绩单(MaxDD / Sharpe / CAGR + 成交笔数)。
② 读三件事:回归信号的成交笔数比趋势多还是少?它的最大回撤更浅吗(均值回归常以"小赢多次"换"回撤更浅")?夏普谁高?
③ 拧旋钮找找手感:把 ENTRY 改成 1.5(更挑剔,交易更少)或 lookback 改成 10(更灵敏)。注意你有多容易把某个窗口的数字调好看——这份"太容易了"的不安,正是下一课要用 gauntlet 收拾的东西。
