# NOTES — 读书线教学工作笔记

## 用户明确要求(2026-08-18,最高优先级)
- **不关联实战线**:课程与 `../quantitative-trading` 完全独立,备课与授课都不引用那边的课号/教训/代码。样式资产(styles.css/quiz.js)是唯一沿用物,仅为视觉一致。
- **课堂即教学**:每课直接教授书中该章的内容——课不是"检验阅读",而是"讲这一章"。不布置课前阅读。
- **课下温习**:用户自己在课后翻原书对应章节复习,课要在结尾标明温习范围(书名+章节/页码)。
- **节奏**:每天至少 1 小时 → 按"一天一课,每课≈1 小时(讲授+练习)"编排。

## 用户画像
- Python 熟练;数学一般(统计/概率需白话+数字例子先行,公式后置)
- 中文讲解,代码/注释英文;简洁直接,不铺垫
- 每课短、单一目标、有一个"看得见的胜利"
- quiz 选项等长,不从格式泄漏答案;要求预测时把已知数字列在题面里
- **词汇纪律**:未教过的术语不得在提问中出现。B1.9 之前禁用 t 值/p 值/标准误,
  显著性一律白话表述(「纯属巧合的可能性小于万分之一」)。2026-08-18 犯过一次,用户看不懂题。

## 课程结构约定
- 课号规则:`B<书序>.<课序>`(如 B1.3);lesson 文件按全局流水号 `0001-` 起
- 每课结构:**本章核心问题 → 讲授(书的内容,白话+例子)→ 检索练习(quiz)→ 课下温习范围 → 参考卡沉淀(如有)**
- 大章拆多课、小章可合并,以"1 小时能吃下"为准;总纲是地图不是铁轨,可随实际掌握度增删
- 每本书完结:一张全书压缩参考卡(`reference/`)+ 一条 learning record + 词汇表更新
- 词汇表:本工作区自建 `reference/glossary.html`(首个术语出现时创建),不依赖外部

## 书籍版本备注
- Chan《Quantitative Trading》= 2008 第 1 版(例子用 MATLAB;讲课时由老师补 Python 对照,方法论不变)
- Narang = 2013 第 2 版;AFML epub 的 TOC 首条 "UnKnown" 是元数据缺陷,内容完整
- APM = 2000 第 2 版扫描件,无书签;正文 PDF 页 ≈ 书页 +7(书 p1 = PDF 第 8 页);随书附录 C 是数学急救包
- 页码引用约定:PDF 书用 PDF 页码,EPUB 用章节名
