学习方法论

术语英文含义与本课程用法
四条线Four StrandsPaul Nation 提出的时间分配框架：意义输入、意义输出、语言聚焦、流利度各约 25%。本课程每日计划据此切分。来源
意义输入meaning-focused input为了理解内容而听、读。材料里 95–98% 的词应已认识，否则不算这条线。
意义输出meaning-focused output为了传达内容而说、写。注意力在"把事说清楚"，不在语法。
语言聚焦language-focused learning刻意研究语言本身：背词、练解码、看语法点、纠音。
流利度练习fluency development用已经完全懂的材料追求速度：重复听、重复读、4/3/2 口语。目标是"更快"，不是"更多"。
可理解输入comprehensible input (i+1)Krashen：略高于当前水平、但能听懂大意的输入是习得的必要条件。来源
泛听extensive listening大量、轻松、以理解为目的地听容易材料。Renandya & Farrell 主张中低水平者优先泛听而非"听力策略训练"。来源
精听intensive listening短片段反复听，逐词听写、对照文本、找出听不出来的位置。本课程主要的解码训练手段。
窄听narrow listening围绕一个话题（如编程、某个播客主持人）大量听。话题词复现率高，天然接近 98% 覆盖。
覆盖率coverage材料里你认识的词所占比例。听懂需 ~98%（每 50 词 1 个生词）；95% 不够。来源
词族word family一个词及其规则变形与派生（help, helps, helped, helpful, unhelpful 算一族）。词汇量统计以此为单位。
检索练习retrieval practice先回忆、再核对，而非重看。Dunlosky 等评为最高效用学习技术。来源
间隔重复spaced repetition把复习分散到越来越长的间隔上。Anki 即此原理。
影子跟读shadowing音频播放的同时几乎同步地跟着说。练的是节奏与连读的肌肉记忆，不是理解。
4/3/24/3/2 techniqueNation 的口语流利度练习：同一话题分别讲 4 分钟、3 分钟、2 分钟，内容不变，被迫越说越快。
流畅感 vs 存储强度fluency vs storage strength刚学完"感觉会了"是流畅感；一周后还能提取才是存储强度。本课程只认后者。

听力解码

术语英文含义与例子
解码decodingJohn Field：把声音流切成词并识别出来的自下而上过程。母语者里听不出词边界，问题多在这一层而非词汇量。来源
意义构建meaning-building解码之后，用语境、常识、话题知识把词拼成意思。解码失败时语境只能"猜"，救不回来。
语块chunk听者实际感知的单位。I don't know 听起来是一个音团 /aɪdəˈnoʊ/，不是三个词。
弱读weak form功能词在句中失去重音、元音变 /ə/：to→/tə/，for→/fə(r)/，can→/kən/，and→/ən/。听不懂母语者的头号原因。
连读linking词尾辅音接词首元音：an apple→/əˈnæpl/；turn it off→/tɜːrnɪˈtɔːf/。
省音elision音被吞掉：next day 的 /t/ 消失；probably→/ˈprɒbli/。
同化assimilation相邻音互相影响而变：don't you→/ˈdəʊntʃə/；good boy 中 /d/ 变得像 /b/。
闪音flap /t/美音中元音间的 /t/ 读成近似 /d/：water→/ˈwɑːɾər/，a lot of→/əˈlɑːɾəv/。
缩约contraction / reductiongoing to→gonna，want to→wanna，I'm going to→/aɪmənə/。
内容词 / 功能词content / function words名动形副承载意义、被重读；冠词介词助动词代词连词弱读。你能听到的"零散单词"基本都是内容词。
听写transcription / dictationNation 推荐的解码训练：听 1–2 句，写下来，对照原文，标出错的位置并归类（弱读/连读/省音/生词）。
