Lesson 0009 · 阶段 1 · 约 25 分钟

因式分解：把乘法倒着放

上一课你把 (x+3)(x+6) 乘开成 x² + 9x + 18。这一课做反向工程：拿到 x² + 9x + 18，还原出它是谁乘谁。为什么值得学？因为"乘积 = 0 就意味着某个因子 = 0"——这是解二次方程的钥匙，也是下一课的全部剧情。而且它自带完美验算：分解完乘回去，必须一字不差还原。

第一招：提公因式（永远先试这招）

ab + ac = a(b + c)　（分配律从右往左读）
6x² + 9x = 3x(2x + 3)　（每一项都含 3x，提出来）
验算：乘回去 3x·2x + 3x·3 = 6x² + 9x ✓
找"每一项都有的东西"：系数找最大公因数（6 和 9 → 3）， 字母找最低次幂（x² 和 x → x）。提干净为止——提成 3(2x² + 3x) 就是没提干净，括号里还藏着 x。

第二招：公式逆用

这一招不需要"想"，只需要认。但要认得出来，先得知道公式是怎么来的—— 下面这两个公式没有一条是新知识，全是上一课你亲手乘出来的结果，倒着抄一遍而已。

先看它从哪来：上一课的结果，掉个头

上一课（乘开，从左往右）这一课（分解，从右往左）
(x + 5)(x − 5) = x² − 25x² − 25 = (x + 5)(x − 5)
(x − 3)² = x² − 6x + 9x² − 6x + 9 = (x − 3)²
等号是双向的。你上一课验算 (x−3)² 时，白纸黑字算出了 x² − 6x + 9； 那么看见 x² − 6x + 9，它只能是 (x−3)² 变来的。 所谓"公式逆用"，就是把上一课的答案当成这一课的题面。 不确定的时候，永远可以乘回去自证——这是本课唯一需要的验算。

公式 A · 平方差：a² − b² = (a + b)(a − b)

先给这个公式一张图。把 a² 看成边长 a 的正方形，减去 b² 就是从角上抠掉一个边长 b 的小正方形：

怎么用——三步，全是机械动作：

  1. 数项数：只有两项，中间是减号 → 进入平方差流程。（三项就不是它，去看公式 B）
  2. 各开一次平方根：问"第一项是谁的平方？"→ 那就是 a；"第二项是谁的平方？"→ 那就是 b。
  3. 套模板：写成 (a + b)(a − b)，然后乘回去对照原式。
同一套动作，三个难度
x² − 25：a² = x² → a = x；b² = 25 → b = 5 　→　(x + 5)(x − 5)
9x² − 4：a² = 9x² → a = 3x；b² = 4 → b = 2 　→　(3x + 2)(3x − 2)
x⁴ − 16：a² = x⁴ → a = x²；b = 4 　→　(x² + 4)(x² − 4)　⚠ 还没完
第二例的关键：a 不一定是单个字母。9x² 是 (3x)²，所以 a = 3x，不是 x。 乘回去验：(3x)² − 2² = 9x² − 4 ✓
第三例的关键：分解完每个括号都要再看一眼。x² − 4 又是一个平方差 → 最终 x⁴ − 16 = (x² + 4)(x + 2)(x − 2)。
你的场景：涨 3% 再跌 3%，乘数是 1.03 × 0.97 = (1 + 0.03)(1 − 0.03) = 1 − 0.03² = 0.9991。 不用算乘法，直接看出亏 0.09%——而且立刻知道亏损值 = 波动幅度的平方。 上一课的"涨跌不对称"，本质就是这个公式在从右往左跑。

公式 B · 完全平方：a² ± 2ab + b² = (a ± b)²

这个公式认起来比平方差难，因为三项里只有两项帮你找 a 和 b，第三项是用来验货的。 流程如下：

  1. 看两头：首项和尾项必须都是完全平方，且都是正的。开方拿到 a 和 b。
  2. 算 2ab：用刚拿到的 a、b 自己算一遍 2 × a × b。
  3. 对照中间项：算出来的 2ab 和原式中间项一致（可以差一个负号）才成立。 中间是 + → (a + b)²；中间是 − → (a − b)²。
走一遍 x² − 6x + 9
① 两头：x² → a = x；9 → b = 3
② 算 2ab = 2 · x · 3 = 6x
③ 中间项确实是 6x，符号是减号 →　(x − 3)²
验算：(x − 3)² = x² − 6x + 9 ✓
再走一个 a 不是单字母的：4x² − 12x + 9。 ① 4x² → a = 2x；9 → b = 3。② 2ab = 2 · 2x · 3 = 12x。 ③ 中间正好是 12x、减号 → (2x − 3)²。
注意第 ② 步不能跳。跳了就只是"两头是平方"，那是凭感觉， 而第 ② 步是凭计算——这就是本节唯一一处需要动笔的地方。
三个最常见的误判

① x² + 25 —— 分解不了。 平方差只认减号。两个正数相加，无论如何拆不出 (x+5)(x+5)（那是 x² + 10x + 25） 也拆不出 (x+5)(x−5)（那是 x² − 25）。看见"平方 + 平方"，直接写"不能分解"。

② x² − 6x + 8 —— 两头看着像，中间不对。 首项 x²、尾项 8……8 根本不是完全平方，第 ① 步就该出局。就算尾项换成 9 以外的完全平方， 比如 x² − 6x + 4：a = x、b = 2、2ab = 4x ≠ 6x，第 ③ 步出局。 这两种都不是完全平方，交给第三招十字相乘处理。

③ x² − 4x − 4 —— 尾项是负的。 完全平方展开后，b² 必然是正的（负数的平方也是正数）。尾项带负号 → 一定不是完全平方，别硬套。

认脸 30 秒自测

下面 4 题只判断该用哪一招，不用分解出结果——先把"认"练成条件反射，"算"才不会乱。

第三招：十字相乘（x² + bx + c 专用）

找两个数：相乘 = c，相加 = b
x² + 9x + 18：找相乘 = 18、相加 = 9 的两个数 → 3 和 6
所以 x² + 9x + 18 = (x + 3)(x + 6)
x² − 5x + 6：相乘 = +6、相加 = −5 → −2 和 −3 → (x − 2)(x − 3)
为什么找"乘 = c、加 = b"？因为上一课 (x + p)(x + q) 乘开就是 x² + (p+q)x + pq——中间系数是两数之和，常数项是两数之积。 十字相乘就是把这个展开过程倒着猜。
符号侦察：c > 0 → 两数同号（跟 b 走）；c < 0 → 两数异号。 x² − x − 12：乘 = −12（异号）、加 = −1 → 3 和 −4 → (x + 3)(x − 4)。

组合拳：先提公因式，再套招

2x² − 8 = ?
先提 2：2(x² − 4)　→　括号里是平方差：2(x + 2)(x − 2)
顺序固定：① 提公因式 → ② 看项数认脸（两项想平方差、三项想 完全平方或十字相乘）→ ③ 每个括号检查还能不能继续分 → ④ 乘回去验算。
