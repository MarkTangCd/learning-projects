分数运算：三条规则全搞定

你自测里错的第 1 题，根源就在这一课。分数是收益率、仓位、赔率的语言——量化里到处都是它。

规则一：加减 → 先通分

分母相同才能加减
1⁄2 + 1⁄3 = 3⁄6 + 2⁄6 = 5⁄6
为什么？分母是"切成几块"，分子是"拿了几块"。半张饼和三分之一张饼没法直接加—— 块的大小不一样。都切成 6 块（公分母），大小统一了才能数：3 块 + 2 块 = 5 块。

规则二：乘法 → 直接乘

分子乘分子，分母乘分母
1⁄4 × 1⁄2 = 1⁄8
"×1⁄2" 就是"取一半"。四分之一的一半，自然是八分之一。 量化场景：剩余资金的 1⁄4，再拿其中一半买入某标的 → 占总资金 1⁄8。

规则三：除法 → 乘倒数

除以分数 = 乘以它的倒数
1⁄2 ÷ 1⁄4 = 1⁄2 × 4⁄1 = 2
除法问的是"里面装得下几个"。半张饼里能装下几个四分之一张？2 个。 所以答案会比原数大——除以小于 1 的数，结果反而变大。这个直觉在算 "收益倍数"时天天用。

动手验证（可选，2 分钟）

打开 Python 直接验证：from fractions import Fraction; Fraction(1,2) / Fraction(1,4) → 输出 Fraction(2, 1)。以后每道分数题都可以这样自查。
