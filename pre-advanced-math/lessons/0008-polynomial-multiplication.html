多项式乘法：分配律的批量版

你已经会 −2(3x − 5)——括号前一项，乘给里面每项。这一课只升级一步：括号前不止一项时怎么办。答案还是那条分配律，乘完之后会自然长出两个值得记住的"快捷键"：平方公式和平方差。复利里 (1+r)² 为什么不等于 1 + 2r，答案就在这。

规则：每项 × 每项，一个不漏

(a + b)(c + d) = ac + ad + bc + bd
(x + 2)(x + 3) = x·x + x·3 + 2·x + 2·3
= x² + 3x + 2x + 6 = x² + 5x + 6
把 (a + b) 看成一个整体 M，那就是老朋友：M(c + d) = Mc + Md， 再把 M 拆开分配一次。两项 × 两项 = 4 个小积，**乘完必数一遍够不够 4 个** ——漏项是这里的头号错误。最后照旧合并同类项、化到最简。

快捷键一：平方公式

(a + b)² = a² + 2ab + b²　（中间那个 2ab 别丢）
(x + 3)² = x² + 6x + 9
(a − b)² = a² − 2ab + b²　（(x − 3)² = x² − 6x + 9）
最常见的错：(a + b)² = a² + b² ❌。用数字立刻证伪：(3 + 4)² = 49， 而 3² + 4² = 25。少掉的 24 正好是 2ab = 2·3·4。 交易版：(1 + r)² = 1 + 2r + r²——两年复利比"单利 × 2"多出的 那块 r²，就是利滚利本身。

快捷键二：平方差

(a + b)(a − b) = a² − b²　（中间项恰好抵消）
(x + 5)(x − 5) = x² − 25
速算：21 × 19 = (20 + 1)(20 − 1) = 400 − 1 = 399
展开看为什么：ac − ad + bc − bd 里，−ab 和 +ab 对消，只剩两头。 交易版：先涨 x% 再跌 x%，总乘数 (1 + x)(1 − x) = 1 − x²—— 永远小于 1。你在阶段 0 就发现的"涨跌不对称"，这就是它的代数证明。
