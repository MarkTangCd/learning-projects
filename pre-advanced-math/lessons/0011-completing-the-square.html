Lesson 0011 · 阶段 1 · 约 25 分钟

配方法：十字相乘凑不出来的时候

试试解 x² + 6x + 4 = 0：十字相乘要找相乘 = 4、相加 = 6 的两个数——1 和 4 加起来是 5，2 和 2 是 4，凑不出来。不是你不会，是这个方程的根根本不是整数，十字相乘天生只会猜整数。这一课的新招对任何二次方程都好使，而且它是下一课"求根公式"的亲爹。

先补一个零件：直接开平方，记得 ±

(某东西)² = 数　→　某东西 = ±√数
(x − 2)² = 16　→　x − 2 = 4 或 x − 2 = −4　→　x = 6 或 x = −2
为什么有 ±：4² = 16，(−4)² 也 = 16——平方把负号吃掉了， 开回去时两种可能都得还回来。只写 x − 2 = 4 就丢了一半的根， 和上一课"除以 x 丢掉 x = 0"是同一类罪。验：x = −2 代回 (−2 − 2)² = (−4)² = 16 ✓，它是货真价实的解。

核心动作：把 x² + bx 配成完全平方

先看它从哪来：完全平方公式倒着用

(x + a)² = x² + 2ax + a²　→　中间系数是 2a，尾巴是 a²
看见 x² + 6x + ▢：中间 6 = 2a → a = 3 → 尾巴该是 a² = 9
规则：补的数 = (中间系数的一半)²

直观：字面意义上的"补一个角"

配平方 15 秒自测

只填"该补几"，不用解方程——这个动作练熟，配方法就成功了一半。

流程：五步，走一遍 x² + 6x + 4 = 0

  1. 常数搬去右边：x² + 6x = −4（+4 过河变 −4，给左边腾出配方的位置）。
  2. 两边同加 (中间系数一半)²：(6 ÷ 2)² = 9 → x² + 6x + 9 = −4 + 9 = 5。天平原理：左边加 9，右边必须也加 9。
  3. 左边认脸写成平方：(x + 3)² = 5。括号里的数就是"中间系数的一半"。
  4. 两边开平方，写 ±：x + 3 = ±√5。
  5. 解出两根，代回原式验算：x = −3 + √5 或 x = −3 − √5。
无理根怎么验算：小数近似代回原式
√5 ≈ 2.236 → x ≈ −0.764
原式左边：(−0.764)² + 6(−0.764) + 4 ≈ 0.584 − 4.584 + 4 = 0.000 ✓
带根号的根代回去硬算容易乱，就用小数近似：代回原式， 结果应该 ≈ 0（差个 0.001 级别的尾数是四舍五入造成的，正常）。 裁判照旧是原式——这条规矩不因为根变丑而打折。

同一套动作，四个难度

阶梯：从"半成品"到"无解预告"
ⓐ (x + 1)² = 9　已配好 → 直接第 ④ 步 → x + 1 = ±3 → x = 2 或 −4
ⓑ x² − 6x + 5 = 0　→ (x − 3)² = 4 → x = 5 或 1（十字相乘也能做，两招互验）
ⓒ x² + 6x + 4 = 0　→ (x + 3)² = 5 → x = −3 ± √5（十字凑不出，配方法专属）
ⓓ x² + 2x + 5 = 0　→ (x + 1)² = −4 → 无实数解
ⓑ 注意中间是 −6x：一半是 −3，补的数是 (−3)² = +9—— 补的数永远是正的（平方嘛），括号里跟着符号走：(x − 3)²。
ⓓ 是新面孔：任何实数的平方都 ≥ 0，不可能等于 −4，所以这个方程 在实数里无解。对回抛物线图：曲线整条悬在横轴上方，压根不穿轴。 下一课的判别式就是把"到底穿不穿轴"做成一个公式。
三个最常见的翻车点

① 开平方不写 ±。 (x − 2)² = 16 只写 x − 2 = 4 → 只剩 x = 6，把 x = −2 扔了。 这是"丢根"的新形态（上一课是除以 x 丢根）。检验办法就是老规矩： 二次方程解完只有一个根，先怀疑自己。

② 只给左边加数。 x² + 6x = −4 配方时左边 +9、右边忘了 +9，等式当场断掉。 天平原理没有例外：两边同时做同一件事。

③ 右边是负数还硬开平方。 (x + 1)² = −4 写成 x + 1 = ±√(−4) 就越界了——实数平方不可能为负。 正确写法：此方程无实数解，收工。

你的场景：两年翻倍要多少年化？解 (1 + r)² = 2 → 1 + r = ±√2 → r = √2 − 1 ≈ 41.4%（另一根 r = −√2 − 1 ≈ −241% 在 收益率场景直接舍去——数学负责给出全部根，业务负责筛掉没意义的）。 这就是配方法第 ④ 步"直接开平方"的日常版，复利年限倒推全靠它。

动手验证（可选，2 分钟）

from sympy import symbols, solve; x = symbols('x'); solve(x**2 + 6*x + 4, x) → [-3 - sqrt(5), -3 + sqrt(5)]。机器也认这两个无理根—— 十字相乘凑不出整数不代表方程没解，只是解不长成整数的样子。
