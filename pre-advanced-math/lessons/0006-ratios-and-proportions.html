比与比例：按"份"思考

set-2 的探路题"10 万按 3 : 2 分给股票和债券"没做出来，这一课就补它。比的本质只有一句话：把总量切成若干等份。经典的 60/40 股债组合、仓位再平衡，全是这一招。

核心：比 = 份数

a : b 的意思是"总共 a + b 份"
每份 = 总量 ÷ (a + b)
甲得 a 份 = 每份 × a　　乙得 b 份 = 每份 × b
就是探路题的解法：10 万按 3 : 2 分，总共 3 + 2 = 5 份， 每份 100000 ÷ 5 = 20000 元。股票 3 份 = 6 万，债券 2 份 = 4 万。 验算：6 万 + 4 万 = 10 万，且 6 : 4 约分后正好是 3 : 2。

比可以约分，和分数一样

两边同乘 / 同除一个非零数，比不变
6 : 4 = 3 : 2　（同除 2）　　60 : 40 = 3 : 2　（同除 20）
所以"60/40 组合"和"按 3 : 2 分"是同一句话

比例式：两个比相等

a : b = c : d　⇔　a × d = b × c（交叉相乘）
3 : 2 = x : 8　→　3 × 8 = 2x　→　x = 12
为什么成立？a : b = c : d 就是分数式 a⁄b = c⁄d，两边同乘 bd 就得到 ad = bc。它不是新规则，是你已会的"两边同乘"换了个外衣。

交易例子：再平衡

组合目标 3 : 2，涨完变成股票 7.2 万、债券 4 万，怎么调？
总额 = 7.2 + 4 = 11.2 万，仍按 5 份切：每份 11.2 ÷ 5 = 2.24 万
目标：股票 3 份 = 6.72 万，债券 2 份 = 4.48 万
操作：卖出股票 7.2 − 6.72 = 0.48 万，买入债券
再平衡 = "总量变了，份数规则不变，重算每份"。 机构组合每季度做一次的就是这个小学算术。

动手验证（可选，2 分钟）

Python 验算按份分配：total = 100_000; parts = [3, 2]; unit = total / sum(parts); print([unit * p for p in parts]) → [60000.0, 40000.0]。手算为主，机器只做验算。
