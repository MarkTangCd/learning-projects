Lesson 0010 · 阶段 1 · 约 25 分钟

一元二次方程：让"乘积为零"替你干活

上一课你把 x² + 8x + 15 拆成了 (x + 3)(x + 5)。这一课回答"学分解到底图什么"：图的就是解方程。x² + 8x + 15 = 0 看着无从下手，(x + 3)(x + 5) = 0 却一眼能读出答案。因式分解是钥匙，这一课是它开的锁。

原理：为什么偏偏是 0

先看它从哪来：拿数字试

两数相乘 = 0 ⟹ 至少有一个是 0
a × b = 0　→　a = 0 或 b = 0（没有第三种可能）
自己试着凑：找两个都不是 0 的数，乘出 0 来——凑不出来。 3 × 0.0001 = 0.0003，再小也不是 0；负数也一样，(−5) × 2 = −10。 只要两个因子都不为 0，乘积就绝不为 0。反过来说：乘积是 0， 就逼着其中至少一个是 0。这是 0 独有的霸道性质。
对照：换成别的数就不灵

a × b = 12 能推出 a = 12 或 b = 12 吗？不能—— 3 × 4、2 × 6、24 × 0.5……无穷多种拆法，谁也逼不出来。 这就是为什么解方程第一步永远是把右边清成 0： 只有 0 才有"逼供"能力。

直观：解就是曲线穿过 0 的地方

把 y = (x − 2)(x − 6) 的值随 x 变化画出来，是一条 U 形曲线。 "解方程 (x − 2)(x − 6) = 0"翻译成图形语言就是：曲线在哪儿恰好碰到横轴？

这也回答了"为什么二次方程常常有两个解"： U 形曲线下去再上来，最多穿轴两次。阶段 2 讲函数图像时， 这张图会成为主角；现在先记住"根 = 穿轴点"这个画面。

流程：五步，全是机械动作

  1. 移项：把所有东西搬到左边，右边清成 0。
  2. 因式分解左边：完全用第 9 课的流程——先提公因式，再认脸。
  3. 每个含 x 的因子分别 = 0：写成"___ = 0 或 ___ = 0"。
  4. 解出全部根：几个因子几个根，一个都不许丢。
  5. 两个根都代回原方程验算：验一个不算验完。
走一遍 x² = 5x − 6
① 移项：x² − 5x + 6 = 0
② 分解：十字相乘，乘 = 6、加 = −5 → −2 和 −3 → (x − 2)(x − 3) = 0
③ 拆开：x − 2 = 0 或 x − 3 = 0
④ 两根：x = 2 或 x = 3
⑤ 验算：2² = 5·2 − 6 → 4 = 4 ✓；3² = 5·3 − 6 → 9 = 9 ✓

同一套动作，四个难度

阶梯：从"白送"到"组合拳"
ⓐ (x + 1)(x − 4) = 0　已经拆好 → 直接第 ③ 步 → x = −1 或 x = 4
ⓑ x² + 8x + 15 = 0　十字相乘 → (x + 3)(x + 5) = 0 → x = −3 或 x = −5
ⓒ x² = 4x　移项提公因式 → x(x − 4) = 0 → x = 0 或 x = 4
ⓓ 2x² − 50 = 0　先提 2 → 2(x + 5)(x − 5) = 0 → x = −5 或 x = 5
ⓑ 用的正是你 set-6 亲手分解过的式子——分解结果一字不改，只是后面多走两步。
ⓒ 是本课最大陷阱，看下面反例清单第 ② 条。
ⓓ 里数字因子 2 永远不为 0，不产生根；含 x 的因子有两个，所以还是两个根。
三个最常见的翻车点

① 右边不是 0 就开拆。 (x − 3)(x + 2) = 14 不能写 x − 3 = 14 或 x + 2 = 14—— 乘积等于 14 逼不出任何因子的值（2 × 7 也是 14）。 正确做法：乘开、移项、整理成 x² − x − 20 = 0，重新分解。

② x² = 4x 两边除以 x。 除完得 x = 4，看着挺对——但 x = 0 代回原式：0 = 0 也成立！ 除以 x 等于偷偷假设 x ≠ 0，把一个根扔了。 永远移项提公因式：x(x − 4) = 0，两个根一个不少。

③ 只写一个根。 "x = 2 或 x = 3"里的"或"不是二选一走过场，两个都是货真价实的解。 第 ⑤ 步要求两个根分别代回，就是防这个。

你的场景：某策略的日利润随下单手数 x 变化：利润 = −x² + 8x − 12（手数太少摊不平成本，太多冲击成本吃掉利润）。 问"下多少手保本"就是解 −x² + 8x − 12 = 0 → 两边乘 −1 → x² − 8x + 12 = 0 → (x − 2)(x − 6) = 0 → x = 2 和 x = 6 之间是盈利区。 上面那张抛物线图上下翻个面（乘 −1 不改变根的位置）就是利润曲线—— 两个根框出了你的生存区间。
