简单不等式：从"等于多少"到"至少 / 至多"

方程回答"x 等于多少"，不等式回答"x 在哪个范围"。风控规则几乎全是不等式：单笔亏损 ≤ 账户的 2%、保证金 ≥ 130%、回撤 < 10%。这一课只有一条新规则，其余全是你已经会的方程流程。

四个符号，一句话读法

解不再是一个点，而是一段范围
x < 4　（小于，不含 4）　　x ≤ 4　（至多，含 4）
x > 4　（大于，不含 4）　　x ≥ 4　（至少，含 4）
"最多买 400 股"是 n ≤ 400——400 也行。"涨幅超过 5% 才追"是 x > 5%—— 正好 5% 不算。含不含边界，交易规则里差别很大，读题时先抓这个词。

解法 = 方程的老流程，加一条新规则

两边同乘 / 同除以负数时，不等号方向要翻转
3x + 5 ≤ 20 → 3x ≤ 15 → x ≤ 5　（同除正数 3，方向不变）
−2x < 6 → x > −3　（同除以 −2，< 翻成 >）
为什么要翻？拿真数验证：2 < 5 成立。两边同乘 −1 得 −2 和 −5， 这时 −2 反而大于 −5（离 0 更近）。乘负数把整条数轴镜像翻转， 大小关系跟着反过来。加减、乘除正数都不翻，只有乘除负数才翻。

交易例子：止损定仓位

账户 5 万，单笔最大亏损不超过 2%，每股止损亏 2.5 元，最多买几股？
亏损上限：50000 × 2% = 1000 元
2.5n ≤ 1000 → n ≤ 400　（同除正数 2.5，方向不变）
答：最多 400 股
这就是仓位管理公式的原型：仓位 = 单笔风险额 ÷ 每股止损额。 翻译过程和方程应用题一模一样——只是把"="换成了"≤"。

动手验证（可选，2 分钟）

Python 验算：from sympy import symbols, solve; x = symbols('x'); solve(10 - 2*x < 4, x) → (3 < x) & (x < oo)，即 x > 3。规矩不变：手算为主，机器只做验算。
