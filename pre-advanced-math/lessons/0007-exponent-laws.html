幂的运算律全套：从一条规则长出四条

你刚拿到"同底数幂相乘，底数不变，指数相加"的 3/3 毕业证。这一课把剩下的运算律一次配齐：除法、乘方、零指数、负指数。它们不是四条新规则要背，而是从"乘法 = 指数相加"顺理成章推出来的。复利公式 (1+r)ⁿ 的一切变形都靠它们。

已知：乘法 = 指数相加

aᵐ × aⁿ = aᵐ⁺ⁿ　（你已毕业的那条）
2⁴ × 2² = 2⁶　（4 个 2 连乘，再接 2 个，共 6 个）

推论一：除法 = 指数相减

aᵐ ÷ aⁿ = aᵐ⁻ⁿ
2⁵ ÷ 2² = (2·2·2·2·2) ⁄ (2·2) = 2·2·2 = 2³
分子 5 个 2，分母 2 个 2，约掉 2 个，剩 5 − 2 = 3 个
除法是乘法的撤销，所以指数从相加变相减。不用背， 写开约分一次就信了。

推论二：乘方 = 指数相乘

(aᵐ)ⁿ = aᵐⁿ
(2³)² = 2³ × 2³ = 2³⁺³ = 2⁶　（"3 个 2"整体拿 2 次）
对比记忆：2³ × 2² = 2⁵（相加）　vs　(2³)² = 2⁶（相乘）
交易场景：月收益乘数 1.02，一年就是 (1.02)¹²；三年就是 ((1.02)¹²)³ = (1.02)³⁶。"年化"来回换算就是这条规则。

推论三：a⁰ = 1（不是 0！）

任何非零数的 0 次方 = 1
看阶梯：2³ = 8 → 2² = 4 → 2¹ = 2 → 2⁰ = ?
每降一级就 ÷2，所以 2⁰ = 2 ÷ 2 = 1
也可用除法律：2³ ÷ 2³ = 2³⁻³ = 2⁰，而任何数除以自己 = 1

推论四：负指数 = 倒数

a⁻ⁿ = 1 ⁄ aⁿ
阶梯继续降：2⁰ = 1 → 2⁻¹ = 1⁄2 → 2⁻² = 1⁄4
验证：2³ × 2⁻³ = 2⁰ = 1，所以 2⁻³ 必须是 2³ 的倒数
交易场景：复利公式 FV = P(1+r)ⁿ 问"现在要存多少"时反过来： P = FV × (1+r)⁻ⁿ。折现因子就是负指数——它不是什么新东西， 就是"除以 (1+r)ⁿ"的紧凑写法。

一张总表（背这张，别背四条）

口诀：乘→加，除→减，乘方→乘，0 次→1，负号→倒数
aᵐ × aⁿ = aᵐ⁺ⁿ　　aᵐ ÷ aⁿ = aᵐ⁻ⁿ　　(aᵐ)ⁿ = aᵐⁿ
a⁰ = 1　　a⁻ⁿ = 1⁄aⁿ　　（a ≠ 0）

动手验证（可选，2 分钟）

Python 一行看阶梯：print([2**k for k in range(3, -3, -1)]) → [8, 4, 2, 1, 0.5, 0.25]——0 次方是 1、负指数是倒数，一目了然。 手算为主，机器只做验算。
