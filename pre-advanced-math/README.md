# 高等数学预备课程（Pre-Advanced-Math)

> 目标：从小学数学水平出发，补齐必要基础，顺利过渡到高等数学（微积分），
> 最终服务于量化交易、量化金融与统计学的学习。

## 为什么不能直接学高数

微积分研究的对象是**函数**（研究函数怎么变化、变化多快、累积了多少）。
而理解函数需要熟练的**代数运算**能力。依赖链条是：

```
数与运算 → 代数 → 函数 → 三角函数/数列 → 极限 → 微积分（高数）
```

小学数学只覆盖了第一环，所以中间必须补，但**不需要补完整个初高中数学**：
平面几何证明、立体几何、解析几何大部分内容对量化目标用处很小，全部跳过。
本课程只保留通往高数的最短路径。

## 量化金融需要的数学全景（先知道方向）

| 数学分支 | 在量化中的用途 | 学习顺序 |
|---|---|---|
| 微积分 | 期权定价、连续复利、优化 | 本课程的直接目标 |
| 线性代数 | 组合优化、因子模型、协方差矩阵 | 微积分入门后并行 |
| 概率与统计 | 一切量化的核心：收益分布、假设检验、回归 | 微积分入门后开始 |
| 随机过程/计量经济 | 布朗运动、时间序列、GARCH | 前三者之后 |

## 学习方法（比学什么更重要）

1. **做题为主，看视频为辅。** 数学是练出来的，不是看会的。看懂 ≠ 会做。
   每个知识点看完讲解后必须独立做 10 道以上的题。
2. **用编程辅助理解。** 你会写代码，这是巨大优势：每学一类函数就用
   Python (matplotlib) 把它画出来，改参数看图像怎么变。抽象概念立刻变直观。
3. **卡住超过 20 分钟就求助。** 把题目发给 AI，要求"只给提示不给答案"，
   自己完成最后一步。
4. **每阶段结束做自测。** 每个阶段文件末尾有自测清单，达不到 80% 正确率
   就回头补，不要带着窟窿前进——数学的窟窿会滚雪球。
5. **允许遗忘。** 忘了就查、就复习，这是正常的。螺旋式前进优于线性完美。

## 推荐资源

- **可汗学院 (Khan Academy)**：主线教材，免费，从算术到微积分全覆盖，
  有中文版（khanacademy.org / 可汗学院中文站）。每节课配练习题，最适合自学。
- **3Blue1Brown《微积分的本质》**（B 站有官方中文）：进入阶段 5 前后观看，
  建立直觉的最佳视频，没有之一。
- **同济《高等数学》**：阶段 5 的正式教材（中文经典）；英文可选
  Thomas' Calculus，更啰嗦但更友好。
- **《普林斯顿微积分读本》**：比教材友好得多的高数辅助读物，强烈推荐。
