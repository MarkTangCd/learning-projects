## 提示卡（先自己做，卡住再看）

- 括号前是负数：每一项都要变号（−2(x − 3) = −2x + 6）
- x 在两边：先两边同加减，把 x 收拢到一边（允许出现负数解）
- |a| 是"距离 0 多远"，永远非负；先算绝对值里面，再取绝对值
- 10⁸ = 1 亿；涨 x% 乘 (1 + x%)，跌 x% 乘 (1 − x%)
