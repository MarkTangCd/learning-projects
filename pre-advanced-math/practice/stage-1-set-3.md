## 提示卡（先自己做，卡住再看）

- 比 = 份数：先算总份数，再算每份，最后乘份数
- 再平衡：总额不变，按目标比重切份数，新目标减现值就是要买卖的量
- 移项后系数是负数？除过去时方向翻转，且注意同号得正、异号得负
- 验算示范：解出 x ≤ 3 → 代 x = 3 和 x = 0 回原式，都成立才放心
