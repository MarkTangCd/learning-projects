# 高等数学预备 Resources

## Knowledge

- [可汗学院中文版（Khan Academy）](https://zh.khanacademy.org/math)
  主线教材：算术 → 代数 → 函数 → 三角 → 微积分全覆盖，每节配练习题。
  Use for: 每个知识点的讲解视频 + 课后练习（阶段 0–4 的主教材）。
- [可汗学院英文版 — Arithmetic](https://www.khanacademy.org/math/arithmetic)
  中文站内容不全时的备份。Use for: 分数、负数、指数根式章节。
- [3Blue1Brown《微积分的本质》（B 站官方中文）](https://space.bilibili.com/88461692)
  Use for: 进入阶段 5 前后建立微积分直觉，全网最佳，没有之一。
- 书：同济大学《高等数学》（第八版）
  Use for: 阶段 5 的正式教材，中文经典，配套习题多。
- 书：《普林斯顿微积分读本》（人民邮电出版社中译版）
  Use for: 高数学不懂时的友好替补讲解，比教材口语化得多。

## Wisdom (Communities)

- [r/learnmath](https://reddit.com/r/learnmath)
  高质量的数学自学社区，对成年人从零补数学非常友好。
  Use for: 卡住的概念、学习路线疑问。
- [Quantitative Finance Stack Exchange](https://quant.stackexchange.com)
  Use for: 进入阶段 5 之后，量化数学的实际应用问题（现在先不用）。
