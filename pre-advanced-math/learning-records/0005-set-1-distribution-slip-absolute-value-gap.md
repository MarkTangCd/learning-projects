# 阶段 1 第一组练习 4/8：去括号变号"懂了但没自动化"，绝对值零基础暴露

2026-08-24 批改 practice/stage-1-set-1.md。方程主流程已稳（第 2、3、4 题全对，
含负数解和应用题建模），但第 1 题 5x − 2(x − 3) 写成 5x − 2x − 6——
−2·(−3) 忘了变号。值得注意：**就在做题前他刚问过 −(x − 4) 为什么等于
−x + 4，概念上完全讲得通**。这是典型的"流利度 ≠ 存储强度"：单独盯着
括号时会变号，混在多步化简里就滑回旧习惯。需要靠重复练习自动化，
不需要重新讲概念。
