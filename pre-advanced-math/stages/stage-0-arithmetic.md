# 阶段 0：数与运算补强（1–2 周）

> 目标：把小学数学中生疏的部分磨快，并补上小学没教的"数的扩展"。
> 这是纯打磨阶段，如果测试发现你已经会了，直接跳到阶段 1。

## 知识点清单

- [ ] 分数四则运算（通分、约分、除以分数 = 乘以倒数）
- [ ] 小数与分数互换、百分数（金融里天天用：收益率、利率）
- [ ] **负数**及其四则运算（数轴上理解；亏损就是负收益）
- [ ] 绝对值的含义
- [ ] **指数（幂）**：a² 、a³ 、aⁿ 的含义；10 的幂与科学计数法
- [ ] **平方根**：√ 的含义，√2 ≈ 1.414 这类估算
- [ ] 运算优先级（先乘方、再乘除、后加减，括号最优先）
- [ ] 比与比例（仓位分配的语言）
- [ ] 估算与数量级感觉（1.05¹⁰ 大概是多少？——复利直觉）

## 与量化的联系

- 百分数与复利：本金 × (1 + r)ⁿ 就是这一阶段的指数运算。
- 负数：收益率序列里一半是负数，正负号运算必须条件反射般准确。

## 推荐路径

可汗学院「算术」→「负数」→「分数」→「指数与根式入门」章节，
只做练习题，正确率高的章节快速跳过。
