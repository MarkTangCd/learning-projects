# 阶段 1：代数基础（4–6 周）

> 目标：学会"用字母代替数"并熟练变形。这是数学从算术升级为工具的一步，
> 也是后面一切内容的运算功底。本阶段要练到"手熟"，不能只是看懂。

## 知识点清单

### 第 1–2 周：代数式与一元一次方程
- [ ] 用字母表示数：什么是变量、什么是代数式
- [ ] 合并同类项、去括号（分配律）
- [ ] 一元一次方程：移项、求解（如 3x + 5 = 20）
- [ ] 用方程解应用题（把文字翻译成方程——建模能力的起点）
- [ ] 简单不等式：x > 3 这类符号与数轴表示

### 第 3–4 周：多项式与因式分解
- [ ] 幂的运算律：aᵐ·aⁿ = aᵐ⁺ⁿ，(aᵐ)ⁿ = aᵐⁿ，a⁻ⁿ = 1/aⁿ，a⁰ = 1
- [ ] 多项式乘法、平方公式：(a+b)² = a² + 2ab + b²，(a+b)(a−b) = a² − b²
- [ ] 因式分解：提公因式、公式法、十字相乘
- [ ] 分式的化简与运算

### 第 5–6 周：二次方程与方程组
- [ ] 一元二次方程：因式分解法、配方法、**求根公式**
- [ ] 判别式 b² − 4ac 与根的个数
- [ ] 二元一次方程组：代入法、消元法
- [ ] 根式运算：√(ab) = √a·√b，分母有理化
- [ ] 分数指数：a^(1/2) = √a（把根式和指数统一起来，高数常用写法）

## 与量化的联系

- 解方程 = 反推问题："要多少年翻倍？"就是解 (1+r)ⁿ = 2。
- 消元法解方程组是线性代数的前身（以后的矩阵运算就是它的批量版）。

## 推荐路径

可汗学院「代数 1 (Algebra 1)」主线，按顺序刷。
