# 阶段 3：三角函数（3–4 周）

> 目标：掌握 sin / cos / tan 的定义、图像与基本恒等式。
> 说明：三角函数在高数教材里大量出现（求导、积分的例题主力），不学会
> 高数课本读不下去；在量化里它出现在傅里叶分析、周期性建模中。
> 本阶段只学"够用"的部分，不钻竞赛难度的恒等式变形。

## 知识点清单

### 第 1 周：定义
- [ ] 角度制与**弧度制**（高数只用弧度！π = 180°，务必习惯）
- [ ] 直角三角形定义：sin = 对/斜，cos = 邻/斜，tan = 对/邻
- [ ] **单位圆定义**（更重要）：cos θ 是 x 坐标，sin θ 是 y 坐标
- [ ] 特殊角的值：0、π/6、π/4、π/3、π/2 的 sin/cos 值

### 第 2 周：图像与性质
- [ ] y = sin x、y = cos x 的波形图，周期 2π
- [ ] y = tan x 的图像，周期 π
- [ ] y = A·sin(ωx + φ)：振幅、频率、相位（周期信号的语言）
- [ ] sin/cos 的正负号在四个象限的分布

### 第 3–4 周：基本恒等式与逆运算
- [ ] 核心恒等式：sin²x + cos²x = 1（就是单位圆方程，不用死记）
- [ ] tan x = sin x / cos x
- [ ] 诱导公式的思路：sin(−x) = −sin x，cos(−x) = cos x，sin(x+π) = −sin x
      （在单位圆上看图理解，不背表格）
- [ ] 和角公式 sin(a±b)、cos(a±b)（知道存在、会查会用即可）
- [ ] 反三角函数 arcsin、arccos、arctan（知道是逆运算即可）
