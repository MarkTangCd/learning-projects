> 高等数学 = 研究函数的学问，这一阶段的扎实程度直接决定高数学得顺不顺。

## 知识点清单

### 第 1–2 周：函数的概念
- [ ] 什么是函数：输入 → 规则 → 唯一输出（和编程里的纯函数是同一个思想）
- [ ] 函数记号 f(x)：f(x) = 2x + 1，求 f(3)、f(a+1)
- [ ] 定义域与值域
- [ ] 平面直角坐标系与函数图像：图像就是所有 (x, f(x)) 点的集合
- [ ] 从图像读信息：升/降、最高/最低点、与坐标轴的交点

### 第 3–4 周：一次函数与二次函数
- [ ] 一次函数 y = kx + b：**斜率 k 的含义（变化率！）**、截距 b
- [ ] 斜率 = Δy/Δx —— 这就是导数的前身，务必吃透
- [ ] 二次函数 y = ax² + bx + c：抛物线、开口方向、顶点、最值
- [ ] 二次函数与二次方程的关系（图像与 x 轴的交点 = 方程的根）
- [ ] 函数图像的平移与伸缩：f(x)+c、f(x+c)、a·f(x)

### 第 5–6 周：指数函数与对数函数（量化重点）
- [ ] 指数函数 y = aˣ：指数增长与指数衰减的形状
- [ ] **e ≈ 2.718 的来历：连续复利**（这是金融数学的心脏）
- [ ] 对数是指数的逆运算：log₂8 = 3 意思是 2³ = 8
- [ ] 对数运算律：log(ab) = log a + log b，log(aⁿ) = n·log a
- [ ] 自然对数 ln 与 eˣ 互为反函数
- [ ] 用对数解指数方程：翻倍要几年 → n = ln2 / ln(1+r)

### 第 7–8 周：函数的组合与性质
- [ ] 复合函数 f(g(x))（对应编程里的函数嵌套调用）
- [ ] 反函数的概念
- [ ] 幂函数 y = xⁿ、y = 1/x、y = √x 的图像
- [ ] 分段函数（期权的收益图就是分段函数！）
- [ ] 单调性、奇偶性（了解即可）

## 与量化的联系

- **对数收益率** ln(P₁/P₀) 是量化中最常用的收益定义，学完对数你就懂为什么。
- 斜率 = 变化率：价格曲线某点的"斜率"就是趋势强度，导数由此而来。
- 期权到期损益图 = 分段线性函数。

## 推荐路径

可汗学院「代数 2 (Algebra 2)」+「函数」相关章节。
**编程辅助（本阶段必做）**：每学一类函数就用 matplotlib 画图，
拖动参数观察变化，例如画出 y = 2ˣ、y = eˣ、y = ln x 在同一张图上对比。

```python
import numpy as np, matplotlib.pyplot as plt
x = np.linspace(0.1, 5, 200)
plt.plot(x, np.exp(x), label='e^x')
plt.plot(x, np.log(x), label='ln x')
plt.legend(); plt.grid(True); plt.show()
```
