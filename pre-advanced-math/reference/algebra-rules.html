代数式整理

规则公式 / 例子易错点
合并同类项 7x − 3x = 4x 4x + 2 不能再合并；x 与 x² 不是同类项
分配律（去括号） a(b + c) = ab + ac 括号前是负数时，每一项都要变号：−2(x + 5) = −2x − 10
负号开括号 −(x − 4) = −x + 4 前面省略的是 −1，照样分给每一项

绝对值（阶段 1 热身补测）

规则公式 / 例子易错点
|a| = a 到 0 的距离 |−7| = 7，|7| = 7，|0| = 0 结果永远 ≥ 0；|a| 只是"把符号扒掉"
先算里面，再取绝对值 |3 − 8| = |−5| = 5 不是 |3| − |8|；括号一样，里面是一个整体
交易场景：绝对值就是"不看方向的幅度"。一天 −7% 和一天 +7%， 波动幅度都是 |±7%| = 7%。风控里说"单日波动超过 5% 就报警"， 用的就是 |涨跌幅| > 5%——只关心离 0 多远，不关心涨还是跌。

解一元一次方程（固定流程）

步骤动作例：4(x − 3) = 2x + 6
1去括号4x − 12 = 2x + 6
2x 收拢到一边（两边同加减）2x − 12 = 6
3常数挪到另一边2x = 18
4两边同除系数，孤立 xx = 9
5回代验算（或 sympy）4(9−3) = 24 = 2·9 + 6 ✓
核心只有一句：方程是天平，两边同时做同一件事。 每一步都在"撤销"x 旁边的一个运算——先撤销加减，再撤销乘除。

简单不等式（第 5 课）

规则公式 / 例子易错点
解法同方程流程 3x + 5 ≤ 20 → 3x ≤ 15 → x ≤ 5 解是一段范围，不是一个点
乘除负数翻转方向 −2x < 6 → x > −3 只有乘除负数才翻；加减、乘除正数都不翻
边界词翻译 "不超过 / 至多"= ≤；"至少"= ≥；"超过"= > ≤ 含边界，< 不含；风控规则里差一股就是差别
交易场景：仓位管理就是不等式。单笔风险 ≤ 账户 2%、每股止损亏 a 元 → a·n ≤ 风险额 → n ≤ 风险额 ÷ a。"最多买几股"永远这么算。
不等式验算：两点法做法（以 4 − 5x < 19 → x > −3 为例）它抓什么错
① 范围点 在解集里挑个好算的数（x = 0）代入原式：4 − 0 = 4 < 19 ✓ 成立 方向翻错了，这一步立刻不成立
② 边界点 代边界 x = −3：4 + 15 = 19，19 < 19 不成立 → 边界不算数，与 >（不含等号）一致 ✓ 边界数字算错、≤ 和 < 混用
方程验算代一个数，不等式的解是一段范围，所以代两个： 范围里一个（该成立）+ 边界一个（</> 该恰好不成立；≤/≥ 该恰好取等号）。 两点都对，方向和边界就都验住了。

幂的运算律（第 7 课）

规则公式 / 例子易错点
乘 → 指数相加 aᵐ × aⁿ = aᵐ⁺ⁿ　（2⁴ × 2² = 2⁶） 底数必须相同；底数不变
除 → 指数相减 aᵐ ÷ aⁿ = aᵐ⁻ⁿ　（3⁷ ÷ 3⁴ = 3³） 别错用成相加
乘方 → 指数相乘 (aᵐ)ⁿ = aᵐⁿ　（(5²)³ = 5⁶） 与"乘 → 相加"对比记：2³×2² = 2⁵ vs (2³)² = 2⁶
0 次方 = 1 a⁰ = 1（a ≠ 0） 不是 0！阶梯每降一级 ÷a：2¹=2 → 2⁰=1
负指数 = 倒数 a⁻ⁿ = 1⁄aⁿ　（2⁻³ = 1⁄8） 不产生负数；折现因子 (1+r)⁻ⁿ 就是"除以 (1+r)ⁿ"
交易场景：年化换算 ((1.02)¹²)³ = (1.02)³⁶ 用乘方律； 现值 P = FV × (1+r)⁻ⁿ 用负指数。复利公式的一切变形都在这张表里。

多项式乘法与平方公式（第 8 课）

规则公式 / 例子易错点
多项式相乘 (a + b)(c + d) = ac + ad + bc + bd 每项 × 每项，2×2 必须得 4 个小积——数一遍防漏项
平方公式 (a ± b)² = a² ± 2ab + b² (a+b)² ≠ a² + b²！(3+4)² = 49 ≠ 25，差的是 2ab
平方差 (a + b)(a − b) = a² − b² 中间项对消；速算 21×19 = 400 − 1 = 399
交易场景：(1+r)² = 1 + 2r + r²，多出的 r² 就是利滚利； (1+x)(1−x) = 1 − x²，来回波动一轮必亏 x²——涨跌不对称的代数证明。

因式分解（第 9 课）

招式公式 / 例子易错点
① 提公因式（永远先试） 6x² + 9x = 3x(2x + 3) 提干净：系数取最大公因数，字母取最低次幂
② 平方差逆用 a² − b² = (a + b)(a − b) 只认减号；x² + 25 分解不了
② 完全平方逆用 a² ± 2ab + b² = (a ± b)² 先验中间项是不是恰好 2ab
③ 十字相乘 x² + bx + c：找相乘 = c、相加 = b 的两数 c > 0 两数同号（跟 b）；c < 0 两数异号
固定流程：提公因式 → 看项数认脸 → 括号内查能否继续分 → 乘回去对照原式（因式分解自带完美验算）。
认脸判据怎么查结论
两项、中间减号 各开平方 → a、b（a 可以是 3x、x² 这种整体） (a + b)(a − b)
两项、中间加号 — 不能分解（x² + 25、4x² + 25）
三项，两头正且都是平方 算 2ab，与中间项对照（关键一步，必须动笔） 对上 → (a ± b)²；对不上 → 走十字相乘
三项，尾项为负 或 尾项非平方 直接跳过完全平方 十字相乘

一元二次方程 · 因式分解法（第 10 课）

步骤例：x² = 5x − 6易错点
① 移项，右边清成 0 x² − 5x + 6 = 0 不 = 0 时"乘积为零"不成立，(x−2)(x−3) = 6 推不出 x−2 = 6
② 因式分解左边 (x − 2)(x − 3) = 0 按第 9 课流程：先提公因式再认脸
③ 每个因子分别 = 0 x − 2 = 0 或 x − 3 = 0 是"或"不是"且"；有几个含 x 的因子就有几个方程
④ 解出全部根 x = 2 或 x = 3 二次方程通常两个根，只写一个 = 丢一半答案
⑤ 两个根都代回验算 2² = 10 − 6 ✓；3² = 15 − 6 ✓ 验一个根不算验完
核心原理只有一句：两数相乘 = 0，至少有一个是 0（0 以外任何目标值都没有这个性质）。 最大陷阱：x² = 4x 两边除以 x 会丢掉 x = 0 这个根—— 永远移项提公因式 x(x − 4) = 0，不要除未知数。

一元二次方程 · 配方法（第 11 课）

步骤例：x² + 6x + 4 = 0易错点
① 常数搬右边 x² + 6x = −4 过河变号
② 两边同加 (b/2)² (6÷2)² = 9 → x² + 6x + 9 = 5 两边都要加；补的数永远为正（是平方）
③ 左边写成平方 (x + 3)² = 5 括号里 = 中间系数的一半，符号跟着中间项走
④ 开平方写 ± x + 3 = ±√5 忘 ± = 丢一半根；右边为负 → 无实数解
⑤ 两根双验（代原式） x = −3 ± √5；近似 −0.764 代回 ≈ 0 ✓ 无理根用小数近似验
什么时候用它：十字相乘凑不出整数时（根是无理数）。 验算铁律：裁判是题目原式——代回自己分解 / 变形后的 式子是同义反复，永远通过，验不出错。
