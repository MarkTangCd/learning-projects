# NOTES

## 用户偏好
- 全程中文；代码注释英文；每课控制在 15~20 分钟内
- 先解决自己的问题（减重 + 痛风），再推广到亲友，最后才考虑考证
- 程序员思维：喜欢公式、可计算、可验证的东西；用"账本/校准/反馈环"这类比喻效果好
- 用户自己已察觉"两餐制导致午餐暴食"，教学时承认并利用这个洞察，不要说教

## 安全提醒（每课检查）
- 痛风：减重速度 ≤ 1 kg/周；不推荐断食/生酮；饮水 2000~3000 mL；限酒；药物与尿酸目标由医生决定
- 长时间跑步出汗多 + 饮水不足 = 尿酸风险，课程中反复提醒补水

## 课程路线图（随学习记录调整）
1. ✅ 0001 能量账本：BMR/TDEE、运动补偿、两餐制问题、痛风减重边界 → 本周任务：7 天晨重 + 腰围 + 3 天饮食拍照
2. 0002 读懂你的 3 天饮食记录：用《中国食物成分表》给包子/面条/饺子算账；主食换算
3. 0003 三餐重构：3:4:3 供能比、晚餐 17~19 点、进餐顺序、把 70 分钟跑步和晚餐的时间关系理顺
4. 0004 痛风食物地图：嘌呤分级、果糖、酒精、奶与豆制品的真相、汆煮
5. 0005 碳水的质量：精制 vs 全谷物、GI/GL、把包子饺子改成"合格版本"
6. 0006 蛋白质与饱腹：每餐蛋白质目标、久坐人群保肌
7. 0007 慢性炎症与饮食：证据有多强、什么是可做的
8. 0008 校准与平台期：用 2~4 周体重曲线反推真实 TDEE，调整赤字
9. 0009 给亲友做评估：BMI/腰围/病史问诊清单 → 一页纸建议模板
10. 0010 注册营养师路线：考试科目 ↔ 教材章节映射（兴趣确认后）
