术语表

所有课程统一使用这些词。每个词只给一句可操作的定义；来源见 RESOURCES.md。

一、记忆与学习科学

存储强度storage strength
一条记忆在长期记忆里"扎根"的深度。只会增加，不会减少；由有效的提取和使用积累。真正的学习目标。
提取强度retrieval strength
此刻能不能把它想起来。刚看完书时很高，几天后迅速下降。它会制造"我已经会了"的错觉。
流畅性错觉illusion of fluency / competence
因为"读起来很顺、看着眼熟"就以为自己掌握了。重读、划线、看讲解视频都会制造它。
提取练习retrieval practice / testing effect
合上书，从记忆里把内容拉出来（自测、闭卷回忆、讲给别人听）。比重读更费力，但对长期保留效果显著更好。
闭卷回忆brain dump / free recall
提取练习的最简形式：一张白纸，写下所有记得的东西，然后对照原文查漏。
间隔效应spacing effect
同样的复习次数，分散在多天比集中在一天记得更久。遗忘一点再复习，效果最好。
间隔重复spaced repetition (SRS)
把间隔效应自动化的软件系统（如 Anki）：答对的卡片间隔拉长，答错的缩短。
交错练习interleaving
把不同类型的题目混着练，而不是一类练完再练下一类。练习时更难、更慢，但辨别能力和长期保留更好。只用于技能练习。
理想难度desirable difficulty
学习时的某些"难受"（要费力想、隔很久再碰、混着练）恰恰是长期记忆的来源。区别于"无效的难"（材料本身讲不清）。
精细加工elaboration
给新知识追问"为什么""和我已知的什么有关""能举个例子吗"，把它接到已有网络上。
巩固consolidation
记忆在学习之后由不稳定变稳定的过程，主要发生在睡眠中。睡眠不足等于把白天学的扔掉一部分。
工作记忆working memory
当下能同时"端着"的信息量，很小（约 4 个组块）。无法通过训练扩容，只能通过组块化和外部化来绕开。
组块chunk
被打包成一个单元的一组信息（比如一个记熟的公式、一个套路）。专家不是工作记忆更大，而是组块更大。
元认知metacognition
对自己"懂不懂"的判断。它默认不可靠（见流畅性错觉），必须用自测结果来校准。

二、记忆术

记忆宫殿 / 位置法memory palace / method of loci
把要记的项目依次"放"在一条熟悉路线的固定位置上，回忆时沿路线走一遍。对有序列表类材料极强，需要几周练习。
联结图像mnemonic image
把抽象信息变成夸张、具体、可视化的画面。记忆术的基本动作。
编码encoding
信息进入记忆时被加工的方式。加工得越具体、越有意义、越有联系，越容易留下。

三、注意力

专注块focus block
一段事先定好时长、单一任务、手机不在身边、通知关闭的时间。本课程的注意力基本单位。
任务切换成本switching cost
在任务之间来回切换时损失的时间与准确率。多任务不是并行，而是高频切换。
注意残留attention residue
切换到新任务后，一部分注意力仍停留在上一个未完成任务上，导致新任务表现下降。
深度工作deep work
在无干扰状态下进行的、把认知能力推到极限的专业活动。与之相对的是浅层工作（回消息、杂事）。
番茄工作法Pomodoro
25 分钟专注 + 5 分钟休息为一个单位的计时法。好处是"开始"的门槛很低。
环境设计environment design
不靠意志力，靠改变环境来减少干扰（手机放另一个房间、关掉通知、固定的学习位置）。

四、拖延与行动

拖延procrastination
明知道推迟会更糟，仍然自愿推迟。核心是"逃避当下的不舒服"，不是时间管理问题。
情绪调节emotion regulation / short-term mood repair
拖延的机制：任务让人感到无聊、焦虑、挫败，于是用别的事来修复当下的心情，把代价留给未来的自己。
时间动机理论temporal motivation theory
动机 ≈（期望 × 价值）÷（冲动性 × 延迟）。截止日期越远、任务越无趣、越容易分心，越拖。每一项都是可以干预的变量。
执行意图implementation intention (if-then plan)
"如果【情境 X】，那么我就【做 Y】"。把决定提前做好，情境出现时自动触发，绕过当下的犹豫。
启动延迟start latency
从"打算做"到"真的开始"之间的时间。本课程追踪拖延的核心指标。
两分钟启动just get started
只承诺做两分钟。因为拖延的痛点在开始，而不在过程；开始之后情绪通常会好转。
自我宽恕self-forgiveness
对上一次拖延不自责。研究显示自责会增加下一次拖延，宽恕反而减少。
习惯自动化habit automaticity
一个行为在固定情境下不需要决定就会发生。形成时间个体差异很大（研究中为 18~254 天），漏做一次不影响进程。
