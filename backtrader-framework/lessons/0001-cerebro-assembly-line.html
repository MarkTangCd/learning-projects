Lesson 01 · backtrader 框架评估

Cerebro 装配线

八个零件、三条怪癖、一次跑通。 然后当场抓住这个框架替你做的第一个错误决定。

这节课的单一胜利 用 25 行代码跑完一个完整回测——数据、信号、下单、手续费、成绩单—— 一个指标、一个绩效公式都不用自己写。 然后回答一个你必须回答的问题:这些白送的东西,可信吗?

你已经手搓过这一切了(隔壁 L1–L23)。所以这节课的口吻不是"教你回测", 而是验收一个供应商:它交付的零件,和你自己车的那些,对得上吗?

一、装配线:八个零件

backtrader 的全部 API 挂在一个叫 Cerebro(西班牙语"大脑")的对象上。 八个零件,你只需要记住它们的接缝在哪:

① Cerebro
引擎。持有一切,跑事件循环。
② Data Feed
OHLCV → 可按 bar 索引的 line。
③ Strategy
你的逻辑。声明 + 决策两个钩子。
④ Indicator
惰性 line 运算,在策略里声明。
⑤ Sizer
下多少量。策略只说买卖,不说量。
⑥ Broker
现金、费率、撮合。钱在这里动。
⑦ Analyzer
成绩单。Sharpe / DrawDown / …
⑧ Observer
绘图轨迹。默认已挂,先不管。

对照你自己那套,接缝几乎一一对应——这是好消息,说明你的心智模型可以直接迁移:

backtrader你手搓栈里的差异
Data Feedfetch_ohlcv.py / fetch_stock()它吃 DataFrame,你的转接头照用
Strategy + Indicatorstrategy.py逐 bar 循环 vs 你的向量化
Sizersizing.py它把"下多少"独立成了一个可替换零件
Brokerbacktest.py 里的成本项它真的记账:现金、持仓、保证金
Analyzermetrics.py / oos.py白送十几个,但默认值是雷区

二、跑起来

脚本已经写好并实测过。先拉数据(BTC 日线走 ccxt + 你的本地代理,SPY 走 yfinance, 都会缓存成 CSV,之后可离线重跑):

cd ~/learning-projects/backtrader-framework/practice
./venv/bin/python l01_first_run.py data
./venv/bin/python l01_first_run.py run

核心装配就这些——注意没有一行在算指标或算夏普:

class SmaCross(bt.Strategy):
    params = dict(fast=10, slow=30)

    def __init__(self):                       # 声明一次
        fast = bt.ind.SMA(self.data.close, period=self.p.fast)
        slow = bt.ind.SMA(self.data.close, period=self.p.slow)
        self.cross = bt.ind.CrossOver(fast, slow)   # 上穿 +1 / 下穿 −1 / 否则 0

    def next(self):                           # 每根 bar 调一次
        if not self.position and self.cross[0] > 0:
            self.buy()
        elif self.position and self.cross[0] < 0:
            self.close()

cerebro = bt.Cerebro()
cerebro.adddata(bt.feeds.PandasData(dataname=df))
cerebro.addstrategy(SmaCross)
cerebro.addsizer(bt.sizers.PercentSizer, percents=95)
cerebro.broker.setcash(10_000.0)
cerebro.broker.setcommission(commission=0.0004)     # 4bp,你在 L20/L21 实测的
cerebro.addanalyzer(bt.analyzers.DrawDown, _name='dd')
strat = cerebro.run()[0]

我这边跑出来是这样(你的数字会因取数当天而略有不同):

BTC 那列值得看一眼:19 笔只赢了 5 笔,却赚了 28.7%——典型趋势跟踪的形状。 你在隔壁课程见过这个形状,所以你知道该问什么(单窗口不是判决,见你自己的 0026)。 本课不追这个问题,本课只验收零件。

三、三条必须先知道的怪癖

1. [0] 是现在,[-1] 是上一根 —— 跟 pandas 反着

self.data.close[0]     # 当前 bar 收盘价
self.data.close[-1]    # 上一根
# self.data.close[1]   # 不存在 —— 正数索引就是未来
这不是随便设计的 没有正数索引,意味着你在语法层面就写不出前视偏差。 pandas 里 df['close'].shift(1) 是一条你必须记得执行的人工纪律; 在这里它是结构性保证。这是 backtrader 最硬的一个卖点。

2. 参数走 params + self.p

params = dict(fast=10, slow=30) 声明,self.p.fast 读取, cerebro.addstrategy(SmaCross, fast=20) 覆盖。 这套机制后面会撑起参数优化(optstrategy)——也会在那里跟你 L22 的"选择方差"正面撞上。

3. 指标在 __init__ 里声明,不在 next() 里算

bt.ind.SMA(...) 不返回数字,返回一个惰性 line 对象。 声明一次,框架逐 bar 替你推进它。写进 next() 里就是每根 bar 新建一个指标—— 慢,而且状态是错的。

四、实验 A:它到底在哪根 bar、用什么价成交?

这是换引擎最关键的一个问题。你手搓栈的假设是收盘价成交。 它呢?别猜,跑一个每根 bar 价格都明显不同的玩具序列,让成交价自己说话:

./venv/bin/python l01_first_run.py fill
next()  bar#2  date=2023-01-02  close[0]=20.5  -> 调用 buy()
成交    bar#3  date=2023-01-03  成交价=30.0  (这根 bar 的 open=30.0, close=30.5)

信号在第 2 根收盘算出,成交在第 3 根开盘。 你决策时看到的那个价,永远买不到。

这对你意味着什么 你手搓栈用"次日收盘成交",backtrader 用"次日开盘成交"。 在 crypto 上差别不大;但你在隔壁 L23 刚测出来: SPY 隔夜跳空占了 62% 的收益,KO 占 92.5%。 在股票上,这两个假设根本不是同一个策略。对拍时数字对不上,先怀疑这里。

五、实验 B:三个都叫 "Sharpe" 的数

Analyzer 是这个框架最诱人的部分——addanalyzer 一行,夏普就有了, 不用碰 metrics.py。现在验收这个零件:

./venv/bin/python l01_first_run.py sharpe
同一个策略、同一段 BTC 日线,三种叫法都叫 'Sharpe':

  A 默认参数                          0.3130781174566167
  B annualize=True (不指定 factor)    0.3788
  C annualize=True, factor=365        0.4559

  B / C 的比值 = 1.2035
  sqrt(365/252) = 1.2035

0.31 到 0.46,差 46%。三个都不报错。拆开看:

发生了什么
A 默认 timeframe=TimeFrame.Years。它把 1000 根日线折成约 3 个年度收益, 然后对这 3 个数求均值/标准差。统计上毫无意义,但它给了你一个长得很像夏普的数。
更糟:数据不足两年时它静默返回 None——我用 300 根 bar 实测过。 同一段代码,数据长度一变,行为就变。
B 改成按日 + 年化,对了一半。年化因子没指定 → 框架查它自己的表, 拿到硬编码的 252(backtrader/analyzers/sharpe.py:128)。 BTC 一年 365 根 bar。
C 显式 factor=365。与我用 TimeReturn 导出的日收益手算的结果逐位相同。
你认识这个数 sqrt(365/252) = 1.2035。你在隔壁 0027 里刚把这个常数从自己代码里赶出去——你当时的结论是: "把一个静默的常数换成一个静默的估计量,不算修好。"

现在它在 backtrader 里,以默认值的身份等着你。 框架省掉的不是"写公式的时间",是"想清楚公式里每个常数的时间"—— 而后者才是你隔壁那 23 课真正学到的东西。

顺带,同一个 Analyzer 还有两个默认值会让你对拍失败: riskfreerate=0.01(默认扣 1%)和 stddev_sample=False (总体标准差,pandas .std() 默认是样本)。全在 API 地图的"必查清单"里。

六、检查一下

你在 next() 里读到 self.data.close[0] 并立刻 self.buy()。这笔单的成交价是——
对。你看到的价永远买不到——前视偏差被结构性堵死了。代价是:这跟你手搓栈"次日收盘成交"的假设不同,对拍时会差出一整个隔夜跳空。
是"下一根 bar 的开盘价"。next() 在 bar 收盘后被调用,订单进队列,下一根 bar 一开盘就撮合。跑 l01_first_run.py fill 亲眼看一次。
backtrader 的 SharpeRatio 在你的 crypto 日线上给出偏低的数,那个 1.2035 倍的根因是——
对。sharpe.py:128 那张表把 Days 映射到 252。注意另两个选项也是真的默认值(riskfreerate=0.01、stddev_sample=False)——它们同样会让你对拍失败,只是不产生 1.2035 这个特定比值。
是年化因子那条。1.2035 正好等于 sqrt(365/252),这个指纹只可能来自年化天数。你选的那条确实也是真实的默认值、也会让对拍失败——但它对不上这个比值。

八、评估栏

本课程每节的固定收尾。这两栏会一路累积成最终的框架评分卡。

省了

  • 前视偏差结构性消灭——没有正数索引,写不出来。比人工 shift(1) 可靠
  • 指标、Analyzer、Sizer 全是白送的零件,25 行跑完整条链路
  • 真·记账:现金、持仓、手续费逐 bar 结算,不是事后减一个成本项
  • 停更三年,但 Python 3.14 + pandas 3.0 上端到端跑通,含绘图,不用打补丁
  • 组件边界清晰(Sizer 可换、Analyzer 可插),你手搓栈的心智模型能直接迁移

坑了

  • Analyzer 默认值是雷区:同一个 Sharpe 能给出 0.31 / 0.38 / 0.46,不报错
  • 失败模式随数据长度改变——300 根返回 None,1000 根返回一个错的数
  • 成交假设与你手搓栈不同(次日开盘 vs 次日收盘),股票上差一整个隔夜跳空
  • 官方停更(最后一版 2023-04-19);官方论坛实测 HTTP 522 不可达
  • "省下写公式的时间"换来"必须去读源码确认常数"——净收益待定
本课的评估结论(暂定) backtrader 的执行模型比你手搓的更严谨(反前视 + 真记账),这是真价值。 但它的绩效层不能盲信——每一个 Analyzer 都要按你自己的 metrics.py 对拍过才能用。
可行的分工:用它跑执行,用 TimeReturn 把日收益导出来,用你自己的公式算分。 这个假设会在 L6 正式检验。
