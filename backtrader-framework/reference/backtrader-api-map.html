backtrader API 地图

八个组件、它们的接缝、以及框架替你做的每一个默认决定。 这张卡随课程增补——灰色的部分是还没上的课。

版本事实 本卡对应 backtrader 1.9.78.123(官方最后一版,发布于 2023-04-19)。 官方已停更,社区分支见 backtrader2。 实测环境:Python 3.14.2 / pandas 3.0.5 / numpy 2.5.2 / matplotlib 3.11.1 —— 全部跑通,无需打补丁。

一、组装顺序

八个组件挂在一个 Cerebro 上。除了 run() 必须最后调, 其余的 add* 顺序无关紧要。

import backtrader as bt

cerebro = bt.Cerebro()                                  # ① 引擎
cerebro.adddata(bt.feeds.PandasData(dataname=df))       # ② 数据源
cerebro.addstrategy(MyStrategy, fast=10, slow=30)       # ③ 策略(+ 参数覆盖)
                                                        # ④ 指标 → 在策略的 __init__ 里
cerebro.addsizer(bt.sizers.PercentSizer, percents=95)   # ⑤ 下单量
cerebro.broker.setcash(10_000.0)                        # ⑥ 经纪商:资金
cerebro.broker.setcommission(commission=0.0004)         #    经纪商:费率
cerebro.addanalyzer(bt.analyzers.DrawDown, _name='dd')  # ⑦ 成绩单
cerebro.addobserver(bt.observers.Broker)                # ⑧ 绘图轨迹(默认已加)

strat = cerebro.run()[0]                                # 事件循环转起来
print(strat.analyzers.dd.get_analysis())
cerebro.plot()
① Cerebro
大脑/引擎。持有一切,跑事件循环,返回策略实例。
② Data Feed
把 OHLCV 变成可按 bar 索引的 line 对象。可加多个。
③ Strategy
你的逻辑。__init__ 声明,next() 决策。
④ Indicator
惰性 line 运算。在 __init__ 里声明,逐 bar 求值。
⑤ Sizer
回答"这单下多少量"。策略只说买/卖,不说数量。
⑥ Broker
现金、持仓、手续费、滑点、保证金。撮合发生在这里。
⑦ Analyzer
成绩单。Sharpe/DrawDown/TradeAnalyzer/TimeReturn…
⑧ Observer
逐 bar 记录用于绘图的轨迹。默认已挂三个。

二、Strategy:两个钩子,别搞混

钩子调用时机该放什么不该放什么
__init__回测开始前一次 声明指标、算派生 line、存参数下单、读 [0] 的值做判断
next()每根 bar(指标就绪后) 读值、做判断、下单创建指标(每 bar 新建一次 = 慢且错)

其他常用钩子:

钩子何时被调
notify_order(order)订单状态变化:Submitted / Accepted / Completed / Canceled / Margin / Rejected
notify_trade(trade)一笔交易开仓/平仓时。trade.isclosed 时 pnl/pnlcomm 才有意义
start() / stop()回测开始 / 结束。stop() 里打印最终统计很顺手
prenext()指标还没攒够数据的那些 bar(next() 此时不会被调)

三、索引约定 —— 最容易翻车的一条

跟 pandas 反着 backtrader 的 line 里,[0] 是当前 bar,[-1] 是上一根, [-2] 是上上根。没有正数索引——正数就是未来,框架从结构上不给你。 pandas 里 s[0] 是第一行、s[-1] 是最后一行,含义完全不同。 
self.data.close[0]      # 当前 bar 的收盘价
self.data.close[-1]     # 上一根的收盘价
self.data.open[0]       # 当前 bar 的开盘价
self.datas[0]           # 第一个数据源(= self.data,也 = self.data0)
self.datas[1].close[0]  # 第二个数据源的当前收盘价
len(self)               # 已经走过的 bar 数(从 1 开始)
self.data.datetime.date(0)   # 当前 bar 的日期

四、订单

self.buy()                      # 市价买,数量由 Sizer 决定
self.buy(size=10)               # 覆盖 Sizer
self.sell()                     # 市价卖(空仓时下 = 开空)
self.close()                    # 平掉当前持仓,不管方向
self.order_target_percent(target=0.5)   # 调仓到净值的 50% —— 向目标再平衡

if self.position:               # 有持仓吗(Position 对象,布尔看 size != 0)
    self.position.size          # 正=多,负=空
成交时点 · 已实测 next() 里下的单,在下一根 bar 的 open 价成交 (默认 cheat_on_open=False)。你决策时看到的收盘价,永远买不到。 前视偏差被结构性消灭了——不需要手动 shift(1)。

五、框架替你做的默认决定(必查清单)

每一行都是"框架有个默认值,而它未必是你要的"。不报错,不警告。

位置默认值后果课
SharpeRatio(timeframe=) TimeFrame.Years (=8) 按年度收益算夏普。日线数据折不出几个年度观测 → 统计量无意义; 数据不足两年时静默返回 None L1
SharpeRatio(factor=) None → 查表得 252
analyzers/sharpe.py:128		 crypto 7×24 数据上年化因子错 → 夏普系统性虚低 sqrt(365/252)=1.2035。实测 0.3788 vs 0.4559 L1
SharpeRatio(riskfreerate=) 0.01 默认扣 1% 无风险利率。跟你手搓栈(通常设 0)不一致 → 对拍时数字对不上 L1
SharpeRatio(stddev_sample=) False 用总体标准差(ddof=0)。pandas .std() 默认 ddof=1 L1
broker 滑点 无 默认零滑点。要用 broker.set_slippage_perc() 显式加 L4
Cerebro(cheat_on_open=) False 次日 open 成交(好事)。改 True 可以拿当日 open 下单——那是给日内调仓用的,别乱开 L4
更多默认值随课程补入(滑点模型、成交量限制、保证金、持仓合并规则……)

六、Analyzer 全清单(v1.9.78.123 实测)

bt.analyzers. 下可用的全部:

名字给什么

七、查源码的姿势

文档说不清的时候直接读源码。这是本课程的核心手法,也是评估一个停更框架的唯一可靠方式。

# 找到本地安装位置
python -c "import backtrader, os; print(os.path.dirname(backtrader.__file__))"

# 看某个类的全部默认参数(不用翻源码)
python -c "
from backtrader.analyzers import SharpeRatio
for k, v in SharpeRatio.params._getitems(): print(f'{k} = {v}')"
通用招式 SomeClass.params._getitems() 对 backtrader 里任何带参数的组件都管用 ——Strategy、Indicator、Analyzer、Sizer、Broker。这是把"框架替你做的决定"一次性倒出来的最快办法。
