# 起点基线：零基础，目标管理自有资金，跨四市场

用户自述**零基础**（PE/PB、K线等名词需从头讲），目标是**独立管理自己的钱**，关注 **A股 / 美股 / 港股 / Crypto** 四个市场，每次学习 **15-20 分钟**碎片化。

为什么重要：
- 每节课必须极短、单点、可快速完成，并给一个明确"小胜利"——这是节奏硬约束。
- 市场范围偏广，教学策略定为"先教可迁移的通用方法论，再逐市场补差异"。Crypto 估值逻辑特殊，需单独模块（见 [[MISSION.md]] 与 RESOURCES.md 的 Gaps）。
- 因用真实资金，风险意识需贯穿每一课。

后续可能需引导用户先聚焦 1-2 个市场深耕，避免四线并进导致每样都浅。
