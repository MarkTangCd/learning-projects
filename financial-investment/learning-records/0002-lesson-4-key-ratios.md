# 第 4 课完成：三个关键比率 PE / PB / ROE

用户在完成第 3 课（三张财务报表）后，主动要求进下一课。按第 3 课预告与 ZPD，教了 **PE、PB、ROE** —— 把三张表压成三个数字，作为"读表 → 估值"的桥。

学到的关键点：
- **PE**=相对利润贵不贵；两个坑：低 PE≠便宜（价值陷阱）、PE 要配增长看。
- **PB**=相对账面家底贵不贵，重资产/周期股（银行等）优先用。
- **ROE**=净利润÷净资产=赚钱效率=生意质量；常年又高又稳是护城河的脚印（接第 2 课），但可被高负债撑高（回第 3 课看负债）。
- 铁律：**单个比率没意义，一切要比较**（自身历史/同行/增长）。目标=好公司+合理价格。

为什么重要 / 后续：
- 这一课把前三课串成了一条线（价值→护城河→财报→比率），继续强化"看证据"而非"听故事"。
- 预告下一课转向**技术分析入门（K线/均线）**，回应使命里"什么时候买"的一半。但也可以选择继续深挖估值（PEG、DCF 入门）——下次开课前确认用户想先补"择时"还是先深耕"估值"。
- 用户尚未用**真实个股**练过手。强烈建议下节课或穿插一节：让用户发一只自选股，用真实 PE/PB/ROE 数字实操一遍，把知识转成技能（storage strength）。
- 术语已进 [[glossary]]：PE、PB、ROE、价值陷阱、好公司+合理价格。
