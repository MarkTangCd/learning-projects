# Mission: 量化策略研究（Strategy Research）

## Why
用户在上一门课（`../quantitative-trading`，27 条学习记录）里建成了一台诚实的**策略评估机器**——回测、walk-forward、费用模型、预注册判据、留出集——并用它正确地否决了自己的第一个策略（"不上钱"）。现在的瓶颈在上游：**喂给评估机器的策略想法太少、来源太窄**。这门课要建的是**策略研究流水线**：发现 → triage（快筛）→ 复现 → 改造 → 送入评估机器。策略本身是流水线的产物，流水线才是资产。

## Success looks like
- 能画出策略想法的完整来源地图（学术论文 / 从业者博客 / 开源代码库 / 论坛社媒 / 中英文平台），并知道每类来源的信噪比和典型陷阱
- 能用一套 triage 清单在 10–15 分钟内判断一个公开策略"值不值得花一周去复现"
- 能独立复现一个公开策略（论文或开源代码），跑通自己的评估机器，并解释复现结果与原报告的差异来自哪里
- 能对一个已复现的策略做出**有依据的改造**（换资产、换周期、加过滤、改出场），并用留出集纪律验证改造是否真的更好
- 建立并持续维护一个个人**策略知识库**：分类图谱 + 已读文献 + 已复现策略 + 判决记录
- 最终能从"想法太少"变成"想法排队等待评估"——研究管道有持续的输入

## Constraints
- 主战场：**Crypto 优先**（复用已有数据管道与评估机器），A股 作为第二阶段迁移目标
- 一手文献阅读方式：**混合**——每篇先中文导读（结论+方法+陷阱），再带框架读原文关键段落
- Python 熟练，pandas 已在上一门课边用边学；数学一般，统计概念需按需补
- 中文讲解；代码与注释用英文；每课短小、单一目标、有一个看得见的胜利
- 上一门课的评估机器（`../quantitative-trading/practice/` 的 walkforward/holdout/fee 模型）是本课的标准测试台，不重建

## Out of scope（暂不涉及）
- 高频 / 做市 / 订单簿微观结构策略——数据与基础设施门槛超出个人范畴
- 付费数据源、付费策略订阅——本课只研究公开、开源、可验证的来源
- 深度 ML 策略研发（qlib 级别的因子工厂）——先掌握经典策略的发现与复现，ML 是后期分支
- A股 实盘对接——A股 阶段先做研究与回测迁移，不碰券商接口
