成交流卡：吃单、挂单、delta、CVD、盘口失衡

每一笔成交都有一个吃单方和一个挂单方。K 线的成交量把两者混在一起；成交流把它们拆开。

定义

词定义数据来源
吃单买 taker buy买方是吃单方的成交（主动买，打在卖一上）。Binance 字段 m（"Was the buyer the maker?"）= falseaggTrades 的 m；K 线的 taker_buy_volume
吃单卖 taker sell买方是挂单方的成交（= 卖方主动，打在买一上）。m = true成交量 − 吃单买
delta一根 K 线（或一个时间片）内：吃单买 − 吃单卖，USDflow.py 的 delta 列
CVDdelta 的累计。离线从 00:00 UTC 起，实时从开始录制起。绝对值无意义，只比两个摆动点之间的方向flow.py 的 CVD 列 / 下图
盘口失衡 imbalance买一到买五的挂单金额 ÷（买 + 卖）。0.5 平衡；偏离越大越一边倒。每秒都在变、可被撤单操纵，只当背景flow.py --live 的 imb 列（depth 接口）

四种组合

价格CVD读法偏向
HH也创新高推动有吃单跟进延续
HH没创新高涨得靠被动买单抬、吃单不足；或买单被上方挂单吸收推动偏弱，HH 易失败
LL也创新低下跌有吃单跟进延续
LL没创新低卖得靠被动挂单压、吃单不足；或卖单被下方挂单吸收推动偏弱，LL 易失败
不动在升主动买单被挂单卖方吸收（absorption）偏空
不动在降主动卖单被挂单买方吸收偏多

这些是描述，和 L6 的位置 / 深度 / 速度一样：写进 note 的 cvd= 字段，30 笔后看它分不分化。不是进场条件。

命令

python practice/flow.py --date 2026-10-10 --svg practice/flow.svg   # 历史：5m delta / CVD 表 + 图，自动标出摆动点处的背离
python practice/flow.py --live --minutes 30 --every 10              # 实时：每 10 秒一行，写 tape_log.csv

注意

  • CVD 只数吃单那一边。价格最终由两边决定，所以 CVD 与价格背离本身就是信息（挂单方在做什么）。
  • 一个交易所的 CVD。Binance 永续是 BTC 最大的单一场所，但不是全部；跨所相加没有意义（基准不同）。
  • 5 分钟 delta 噪声大，单根不读；读摆动点之间的方向。
  • 盘口：看得见的挂单随时可撤；冰山单看不见。Bookmap 学习中心（免费）有 Order Flow Phenomena 23 课讲这些现象。
