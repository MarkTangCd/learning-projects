短线交易知识地图：理论、数据、指标各回答什么问题

短线、超短线、剥头皮用到的东西分六层。每一层只回答一类问题；把它们混在一起，就是"指标越加越多、越看越乱"的来源。

关于"指标"的诚实说明 Grimes 在其书中用统计检验说明：脱离上下文的经典形态与指标信号大多没有可测的 edge；有 edge 的是"结构 + 位置 + 流"的组合判断。所以本课程把指标当作度量工具（ATR 量波动、VWAP 量均价、CVD 量净吃单），而不是买卖信号发生器。

常用指标速查：它量的是什么

指标量的是什么短线怎么用别这样用
EMA 9 / 20 / 50不同时间尺度的平均成本趋势方向与回调深度的参考线金叉死叉当信号（量化工作区 L5–L7 已证明无 edge）
VWAP当日成交量加权均价 = 多数人的持仓成本日内"贵 / 便宜"的基准；机构执行的参照隔夜 / 多日 VWAP 混用
ATR平均每根 K 线的波动幅度止损距离下限（< 1 ATR 大概率被噪声扫掉）、目标是否现实当方向指标
成交量 / 成交量分布哪些价位换手多（POC、价值区）找"有人在意"的价位与"真空区"孤立看单根放量
CVD / delta累计净吃单（买方吃单 − 卖方吃单）价格没动但 delta 大 = 吸收；价格动但 delta 没跟 = 弱跨交易所直接相加
RSI / 布林带价格相对近期区间的位置区间市里的"到边了"提示趋势市里逆势接刀

时间结构

  • 美盘开盘 13:30 UTC前后与伦敦开盘 07:00–08:00 UTC是 Crypto 波动最集中的窗口（L2 用数据验证）。
  • 资金费率结算 00 / 08 / 16 UTC 前后常有仓位调整。
  • 整刻钟效应：Binance 永续在 :00 / :15 / :30 / :45 有可测的成交量 / 波动脉冲（Kim & Hansen）。
  • 周末流动性薄，同样的吃单造成更大滑点。
