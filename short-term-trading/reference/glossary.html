短线交易术语词汇表

这是全课程的"官方术语表"。每节课的用词以此为准；一个词只有在你能正确使用之后才会被收进来。

度量

R / 1R R, one R
一笔交易进场前计划承受的最大亏损额：1R = |进场价 − 止损价| × 数量。它是短线交易的度量单位；每笔交易的结果都用"几个 R"表示。见 L1。 避免：用美元或百分比比较不同仓位的交易。
R 倍数 R-multiple
一笔交易的净盈亏除以它的 1R：结果 R = (毛盈亏 − 手续费) / 1R。被止损 ≈ −1R（加上手续费略多于 −1R）；按计划到目标 = 计划 R。来源：Van Tharp。
计划 R / 盈亏比 Planned R, reward-to-risk
进场前写下的目标距离除以止损距离：|目标 − 进场| / |进场 − 止损|。它是计划，不是结果。 避免："赔率"、"盈亏比 2:1"（口语可用，日志里统一写 2R）。
期望值 Expectancy
每笔交易平均赚几个 R：E = 胜率 × 平均盈利R − 败率 × 平均亏损R，等于所有结果 R 的均值。胜率单独没有意义，只有和盈亏比一起才决定期望值。
手续费拖累 Fee drag (in R)
来回手续费占 1R 的比例：手续费R = 2 × 单边费率 / 止损距离%。止损越近，拖累越大；这是剥头皮的结构性税。Binance 永续普通档：吃单 0.05%、挂单 0.02%（费率表）。
吃单 / 挂单 Taker / Maker
吃单 = 用市价单或穿越盘口的限价单立刻成交，付高费率；挂单 = 限价单停在盘口等别人来成交，付低费率但可能不成交。
行程 / 区间 Travel / Range (per hour)
行程 = 某小时内 1 分钟 |收益| 之和（价格走了多少路，机会）；区间 = 小时最高减最低（最远到了哪，目标装不装得下）。行程 ÷ 区间 = 来回程度。见 L2、时段卡。
合规率 Compliance rate
零违规交易占已平仓交易的比例，由 rules.py 计算。阶段 0 的过程目标（≥ 80%），与期望值并列报告。起点 20%。见 L3。

结构

摆动点 / HH HL LH LL Swing point
最高价为左右各 N 根里最高的 K 线是摆动高点（低点镜像），N = 3。与上一个同类摆动点比高低，得到 HH / LH（高点）与 HL / LL（低点）。结构就是这四个字母的序列。见 L4。
判决 Verdict (UP / DOWN / RANGE)
最近两高 HH 且两低 HL = UP；两高 LH 且两低 LL = DOWN；其他一切 = RANGE（含只确认了一半的趋势）。规则故意晚一腿。
推动 / 回调 Impulse / Pullback
推动 = 顺趋势方向的腿；回调 = 逆方向的腿且不超过推动的起点（Brooks）。健康趋势里推动比回调长，"usually in time, always in price"（Grimes）。
四格 Grimes' four categories
趋势延续（cont）/ 趋势终结（term）/ 支撑阻力守住（hold）/ 破掉（break）。同一结构里 hold 与 break 互为对手盘。只有 cont 被两位作者标为有可验证的统计优势；阶段 1 只练它。
ATR Average True Range
波动的单位：14 根真实波幅（含跳空）的 Wilder 平滑均值。BTC 5m 中位 13 bp（窗口 17 bp）。止损规则用它做锚：回调极值 − 4 × ATR。见 L5。

过程

交易计划 Trade plan
进场前写下的三个价格：进场、止损、目标，再加上 setup 名字。有了它，R 才存在。 避免："我心里有数"——没写下来就等于没有。
无计划交易 Unplanned trade
进场时没有写下止损的交易。它没有 1R，无法被衡量，因此无法被改进；日志统计把它单列并排除。"盈亏随机"的技术定义就是：无计划交易占多数。
交易日志 Trade journal
以 R 为单位记录每笔交易的计划与结果的表格（字段见 日志字段参考）。它是复盘的原材料，也是所有"方法有没有用"问题的唯一法官。
盯盘窗口 Session window
进场前写下的、唯一允许开仓的时段（当前：工作日 UTC 12–15，在场到 16）。之外的交易贴 outside-session 并单独统计，不是禁令。
时间止损 Time stop
进场前就定好的时刻（当前 UTC 16:00），到点仍未到止损或目标则市价平仓，贴 time-stop。与"等不下去了就平"的区别只在决定的时间点：进场前 vs 持仓中；前者可统计，后者不可。三种合法出场之一（止损 / 目标 / 时间止损）。
Setup / 剧本 Setup, playbook
一类有明确触发条件、进场、止损、目标规则的交易机会，有名字（如 pullback）。日志按 setup 分组算期望值，才能知道该多做什么、停做什么。来源：Bellafiore《The PlayBook》。
错误标签 Mistake tag
日志里给"违反计划"的交易贴的固定词汇（chased、no-stop、moved-stop、early-exit…）。标签统计出"哪种错误最贵"，这是复盘的第一产出。
