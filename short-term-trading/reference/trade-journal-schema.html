交易日志：字段、公式、每日复盘清单

practice/journal.py 的 14 个字段、note 的四段式与描述字段、错误标签，以及把它们变成 R 的四个公式。

字段

字段含义何时填
id自增编号自动
openedAt开仓时间（UTC），格式 2026-10-12 13:05；R2 / R4 / R5 都靠它自动（add）或手填
symbol品种，如 BTC/USDT:USDT（ccxt 永续写法）进场前
sidelong / short进场前
setup剧本名字（pullback、breakout…）；没有名字的交易是无计划交易的近亲进场前
entry计划进场价（成交后改为实际成交价）进场前
stop止损价。空着 = 无计划交易，不参与统计进场前
target目标价进场前
qty数量 = 1R ÷ 止损距离进场前
exit实际出场价（空着 = 持仓中）出场后
closedAt平仓时间（UTC），格式 2026-10-12 14:35；用于持仓时长与时间止损检查出场后
feeUsd来回手续费（Binance 从成交明细聚合，订单头里常为空）出场后
mistake错误标签（见下）；按计划执行则留空复盘时
note四段式 + 描述字段（见下表），之后可接一句话进场前写前四段

公式

dir       = +1 (long) | −1 (short)
1R        = (entry − stop) × dir × qty          # 进场前的计划亏损，USD
plannedR  = (target − entry) × dir / ((entry − stop) × dir)
resultR   = ((exit − entry) × dir × qty − feeUsd) / 1R
feeR      = feeUsd / 1R  ≈  2 × 单边费率 / 止损距离%
expectancy = mean(resultR)                       # 只统计有 stop 且已平仓的交易

note 字段：四段式 + 描述字段

格式：判决/格子/腿/进场 atr=17 k=4 stop=70bp depth=45% speed=0.6 htf=aligned。前四段用斜杠分隔，rules.py 检查前三段是否在词汇表里；斜杠后的 key=value 是描述字段，空格分隔，30 笔后用来分组。

段取值含义
① 判决UP上升趋势：最近两个摆动高点 HH 且最近两个摆动低点 HL（L4 规则）
DOWN下降趋势：最近两高 LH 且两低 LL
RANGE其他一切，包括只确认了一半的趋势（差一个 HL / LL）
② 格子cont趋势延续：顺趋势，在回调里进。你的 pullback。阶段 1 唯一允许的格子
term趋势终结：逆趋势赌它停。你的 channel reversal
hold支撑阻力守住：区间边缘赌弹回。你的 trading range reversal
break支撑阻力破掉：赌突破跟进。你的 breakout
③ 腿in-pullback当前腿是回调，且没有超过上一推动的起点。cont 的合法位置
after-impulse推动刚走完就进，等于在追
at-edge价格在区间的上沿或下沿
in-breakout突破进行中，已出区间但还没回调
④ 进场maker限价挂单成交（2 bp/边）
taker市价或穿越盘口的限价成交（5 bp/边）
missed挂了没成交。仍记一行：exit 留空、mistake 写 missed，stats 会排除，但能数出错过了几笔

自洽的组合：UP/cont/in-pullback、DOWN/cont/in-pullback、RANGE/hold/at-edge。逆 80% 的组合：RANGE/break/in-breakout、UP/term/after-impulse。阶段 1 只允许前两种。

描述字段写法含义 / 怎么得到
atratr=17进场时 5 分钟 ATR14，单位 bp。盯盘时跑 python practice/structure.py --live，第一行 "ATR14 now"
kk=4止损用的 ATR 倍数，规则 v1 固定 4
stopstop=70bp实际止损距离，bp。不低于 60
depthdepth=45%回调幅度 ÷ 前一推动幅度。超过 100% 就不是回调。structure.py --live 最后两行直接给出
speedspeed=0.6前一推动的速度 = 推动幅度 ÷ 根数 ÷ 当时的 ATR，单位"每根 K 线几个 ATR"。structure.py --live 的 xATR/bar 列（看回调之前那一腿）或最后一行 "For the note"。大于 1 = 高潮式推动，剧本标为"描述性不做"
htfhtf=aligned / against / range当天到此刻、structure.py --start 0 --end 12 --strength 8 的粗一级判决与交易方向是否同向
cvdcvd=confirm / diverge / flat回调期间 CVD 的样子：confirm = 回落但守住突破前水平；diverge = 跌穿突破前水平；flat = 看不出。flow.py --live 或 --date（L8）
levellevel=vwap / pdh / pdl / swing / none回调极值 1 ATR 内最近的价位。只描述，不作条件（L6）

描述字段不是条件，是为了 30 笔后能按它们分组看期望值。写不全不算违规；写错比不写更糟，不确定就不写。盯盘时一条命令拿到 atr / depth / speed：python practice/structure.py --live，复制最后一行 "For the note"，再补 htf 和 level。

错误标签起始词汇

标签含义
no-stop进场时没写止损（= 无计划交易）
chased价格已经走了才追进去，进场价离计划太远
moved-stop持仓中把止损往亏损方向挪
early-exit没到目标也没到止损就手动平掉
oversized数量超过 1R ÷ 止损距离
revenge上一笔亏损后 5 分钟内的非计划进场
outside-session在约定开仓窗口（UTC 12–15）之外开仓（R2）
time-stop不是错误：UTC 16:00 时间止损平仓的标记（R3 三种合法出场之一）
no-stop-order开仓后没在交易所挂止损单（R1）
missed不是错误：限价挂单没成交的标记，exit 留空

每日复盘（10 分钟，收盘后）

  1. 跑 python practice/journal.py stats，先看无计划交易数。今天的目标是它等于 0。
  2. 今天最好的一笔和最差的一笔：各用一句话说过程对错，不说盈亏。
  3. 给每笔违反计划的交易贴一个错误标签。
  4. 写下明天只改一件事。
  5. 把所有数字留给周复盘；单日样本太小，不下结论。

结构来自 Steenbarger 的自我教练法（TraderFeed）与 Bellafiore 的 PlayBook 复盘；"过程目标优先于结果目标"是这两家的共同点。
