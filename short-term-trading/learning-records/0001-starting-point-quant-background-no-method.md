# 起点：有量化基础，但主观短线"没有固定方法、盈亏随机"

用户（2026-10-09）自述目前在 Crypto 市场做交易但没有固定方法、盈亏随机，没有系统记录；目标是走向全职交易，执行方式选"手动交易 + 代码做工具"，每天可投入 2–4 小时。

## Evidence
- 本次会话问卷回答（目标 / 执行方式 / 现状 / 时间）。
- 量化工作区 L1–L27 的学习记录：已掌握回测、样本外、walk-forward、过拟合与多重检验、ccxt 执行、永续合约杠杆 / 保证金 / 强平价、资金费率、手续费按名义收（实测来回 8 bp 为确定性成本）、vol targeting、预注册与尸检。

## Implications
- **不必重教**：成本模型（手续费 / 滑点 / 资金费率）、杠杆与强平、夏普 / 回撤、过拟合与"没 edge 不上实盘"的纪律。可以直接引用这些概念并把它们换算成 R 的语言。
- **完全是新的**：主观交易的计划—执行—记录—复盘闭环、价格行为语言、盘口 / 成交流、刻意练习（回放）。用户在这些领域的 ZPD 从零开始。
- 用户对"随机"有量化直觉（知道噪声 vs 确定性），L1 可以借此把"没有事先定义的止损 = 无法用 R 衡量 = 随机"讲透。
- 全职目标 + 当前随机 + 97% 基础亏损率 → 课程须把"闸门"作为明线，每阶段以日志统计放行。
