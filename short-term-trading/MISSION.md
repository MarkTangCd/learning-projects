# Mission: 短线 / 超短线 / 剥头皮交易（Crypto 永续合约优先，后扩展外汇）

## Why
用户目前在 Crypto 市场做交易，但**没有固定方法、盈亏随机**。想系统学会短线交易（日内、超短线、剥头皮），最终**走向全职交易**——让交易成为主要收入来源。
路径必须诚实：学术证据表明坚持日内交易的人约 97% 亏损（Chague et al. 2020），所以"全职"不是起点而是一道**必须用账户数据通过的闸门**。课程的任务是把"随机"变成"可测量、可改进"的过程，并在每个阶段用日志统计决定是否前进。

## Success looks like
- 每一笔交易进场前都有写下的计划（进场 / 止损 / 目标 → R），进场后有日志，每日有复盘；连续 3 个月零"无计划交易"
- 拥有自己的 playbook：≥ 3 个有明确触发条件、被日志统计验证为正期望的 setup（≥ 100 笔样本、扣除手续费后期望值 > 0）
- 能读懂并使用短线交易的核心数据——盘口与成交流（order flow）、资金费率、未平仓量、清算分布、会话波动结构——并说清楚每个数据回答什么问题
- 用 Python 搭好自己的练习与复盘工具链：交易日志统计、历史行情回放练习（deliberate practice）、每日 / 每周复盘报告
- 有一套写下来的风险规则（单笔 R、日亏损上限、周亏损上限、连亏停手），日志证明执行率 > 95%
- 分阶段扩规模的闸门：回放 / 模拟 → 小资金实盘 → 按统计结果加仓；外汇扩展只在 Crypto 阶段通过闸门后开始

## Constraints
- 市场：Binance USDⓈ-M 永续合约为主（可做空、有杠杆、有资金费率）；外汇后期扩展
- 执行方式：**手动看盘下单，代码做工具**（统计 / 回放 / 复盘）；不做全自动策略（那属于量化工作区）
- 时间：每天 2–4 小时，须固定在一个高波动时段盯盘 + 复盘；课程短小、单一目标、可快速完成
- 背景：Python 熟练；已有量化基础（回测、样本外、walk-forward、ccxt 执行、永续合约杠杆 / 强平 / 资金费率）；数学一般
- 语言：中文讲解，代码与注释用英文；编辑器 Cursor，终端 zsh；本地代理 `http://127.0.0.1:1087`（拉数据需在 ccxt 显式设置）
- 资金安全优先：任何新方法先在回放 / 模拟中验证，实盘用小资金

## Out of scope
- 高频 / 做市 / 全自动策略开发（见量化工作区）
- 链上 / DeFi 交易、山寨币基本面、消息面交易
- 期权策略
- 股票日内交易的市场特有规则（美股 PDT、A 股 T+1 等）
